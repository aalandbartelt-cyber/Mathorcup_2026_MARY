### 实际输入关系

`run_e200_contract.py`直接读附件1、4以及8的两张sheet；`run_e204_constrained_migration.py`直接读附件1，并使用已审计的Q3契约表。其全量生成池每风格2000谱；`run_e205_sensory_audit.py`从池中每风格抽取300形成画像，固定Q1最终NNLS接口，复用Q2最终NNLS缓存，并重建已归档ElasticNet作为独立代理核验。

配置和代码明确`q2_top3_in_optimizer=false`。因此图中可以画“Q1最终感官接口/冻结预测器→Q3画像”，不应画“Q2正式Top-3排序→Q3生成优化”。Q2的模型缓存接口与Q2的最终化合物答案是不同对象。
