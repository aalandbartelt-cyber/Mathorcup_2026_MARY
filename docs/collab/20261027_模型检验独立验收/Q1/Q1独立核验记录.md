## 必须保留的证据边界

1. 残差校准使用其他重复中的同一批250款啤酒及其相同真值，故接近名义覆盖是样本内校准检查，不能解释为独立预测区间验证或保形保证。
2. ECE和逐目标可靠性使用mean-OOF；重复宏均值使用逐重复指标。两种口径都有效，但必须标注，不能让0.2564与逐目标R²均值混为一谈。
3. 三分位17/16/17是相对排序分层，不能直接写成17个目标达到固定实用可靠性标准。
4. 消融 manifest 的原始 `1.csv` 哈希为null，代码的路径构造导致未记录；本审计另行记录当前原始附件哈希。移除汇总字段、标签置换、留一风格均未保存原始预测，只能对照工作树CSV、运行日志和代码，不能宣称已从原始预测独立复算这些新增重训成绩。
5. 标签置换代码先对250款beer的目标整行全局置换一次，再执行固定外层CV，并非训练折内独立置换。正文应按实际写“单次目标置换负对照”，不能写“仅训练折内置换”。该检验也不能单独证明所有泄漏风险已排除。
6. 消融三种方案只使用重复0的3折，不包含10次重复重训不确定性；留一风格中的小样本风格只作压力测试。
