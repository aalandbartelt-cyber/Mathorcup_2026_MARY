# 技术路线图逻辑合同建议

本文件只定义送审图的逻辑、短文和箭头，不改模型或正式图，也不代表用户已经审图。依据现有冻结三问方案和原题，不照搬参考图中的方法与数字。

## 一、图必须一眼传达的逻辑

共同数据口径支持三问；问题一建立可复用的感官预测接口，问题二确定可重复的关键关联，问题三在风格与缺陷条件下构造统计画像和迁移候选。问题一的冻结预测器供问题二解释和问题三画像/代理使用。问题二的正式Top-3不进入问题三优化。

图中不展示模型性能数字，不罗列软件、全部参数和失败模型。整体信息量控制在约10个主要框，优先让“输入-方法-输出”可直接阅读。

## 二、推荐版式

推荐横向三泳道，每行对应一问，依次呈现“方法-检验/约束-交付”。左侧用一块共享数据基座，三条短箭头分别进入三行。行上方的Q1/Q2/Q3和短任务名用无底框粗体标签，避免再为任务名增加大框。

共同数据框加三行各3框，共10个主要框。另以一条细支线标明冻结感官接口的流向，接口标签不必再做大框。接口支线和求解主干必须用不同线型，图下方放真实线段图例。

可以将整体做成接近3:2的横幅。与示例的纵向长图相比，三问各占一行、共同口径只出现一次，读者无需在“研究框架/研究内容/研究方法”三列反复查找同一信息。

## 四、箭头合同

### 实线：本问求解主干

- A -> B1 -> C1 -> D1。
- A -> B2 -> C2 -> D2。
- A -> B3 -> C3 -> D3。

这些实线表示本问内部的数据/方法/交付推进，不要求三个任务之间串行等待。

### 细虚线：冻结模型接口

- C1 -> D2，箭头标签为“独立条件归因”。该支线进入解释证据所在的输出端，不进入B2“四路排序”。
- C1 -> C3，箭头标签为“感官代理”。
- C1 -> D3，箭头标签为“感官画像”。若两条Q3箭头使图拥挤，可合为一条带“画像/代理”标签的支线，终端落在C3-D3之间的明确接口端口；图注说明其分别用途。

三条虚线可共用一条外围分发线，采用直角折线与短分支，避开任何框内文字。接口必须从C1单独发出，不能画成D2 -> C3或D2 -> D3。若同一分发线从Q2旁经过，不要加箭头使其看起来像Q2结果继续流入Q3。

不建议给每条主干箭头再加“数据传递”等泛化标签。图例只保留“实线：本问求解”“虚线：冻结感官接口”两项。

## 五、四路排序和统一验证的口径

- 四路是总关联、分层自助、风格校正、留一风格；不是被否决的三证据等权融合。
- 监督预测及分布评测采用固定10次重复、每次3外折。NNLS在训练集内部使用3折基预测。图内可用“10次重复×3外折”作共同口径下的小字；不能写参考图的5×2。
- 分层bootstrap为500次，若图内留数字只用这一个实际次数；不照抄参考图的200次。
- 附件2为全量共表达描述/核验，监督图在训练折重算。不能写“6.csv作种子”“标签传播”或“1038条边”，这些不是正式方法。
- 共有250款、231个测量字段和50目标；可在共享数据框下用一行小字说明，不在每个任务框重复。
- “四类学习器”具体为ExtraTrees、HGB、秩高斯Ridge、PLS2；为简洁可在正文说明，不必全部挤在图框。
- Q2模型归因与Q3代理调用冻结模型及相关缓存，不能据此把所有Q2附件或正式Top-3都画成Q3输入。

## 七、视觉规范及送审检查

- R原生绘图，可用ggplot2的geom_rect、geom_segment、geom_text和grid箭头；无需Graphviz或AI图像生成。沿用theme_mcup，但路线图隐藏坐标轴。
- 白底，黑色细框；蓝/绿/橙与正文一致，颜色只区分Q1/Q2/Q3，不表达好坏。框背景仅用很浅的对应色或白色，避免大片深色和重阴影。
- 线条细且一致，主干箭头约0.45-0.55pt；禁止示例中的粗黑大箭头和多重虚线大容器。
- 中文宋体；任务标签和框内第一行可加粗。基准11-12pt，不能为塞字退回很小字号。窄边留白与框间距保持一致。
- 只使用ASCII“-”连接号；标签如“输入-方法-输出”和“0-6”也遵循本轮用户偏好。
- 70%缩放和灰度实际目检，确认文字可读、箭头不穿字、共享接口不会被读成Q2排序流入Q3。PNG300dpi，PDF/SVG矢量输出，并保留R源和节点/边表。
- 本图属于方法逻辑示意，无误差棒、无性能数字。证据正确性由方法/代码接口核对承担，不假装是一张实测数据图。
