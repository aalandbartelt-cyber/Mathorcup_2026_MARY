# A 题问题二详细分析与技术设计

> 状态：设计稿，尚未启动 Q2 训练与调参。本文先冻结任务口径、模型假设、候选路线、验证体系和交付合同；路线确认后再进入代码实现。

## 1. 任务本质与回答边界

问题二不是普通的相关性排序。题面要求利用 `2.csv` 构建化合物共表达图，结合 `1.csv` 的样本特征，为每个感官维度给出 Top-3 关键因素化合物，并证明结果在样本扰动或方法变化下稳定，同时说明化学上为什么合理。要完成“化合物—感官”映射，实际还必须使用 `4.csv` 的 50 个感官目标。因此本问的完整输入接口是：

1. `1.csv`：250 款啤酒的 231 个化学/理化预测量；
2. `2.csv`：231×231 的化学参数相关矩阵，用于构建图；
3. `4.csv`：250×50 的标准化感官目标；
4. `3.xlsx`、`5.csv`、`6.csv`、`8.xlsx`：分别用于目标语义、目标相关结构、后验相关核验、化学名称/单位/阈值/缺陷属性核验；
5. `7.csv` 与公开 Kaggle 数据：仅作可选的感官或风格层面旁证，不能进入主排名。

本问最终应交付 50×3=150 条逐目标结果。每条至少包含：感官维度、名次、字段代码、规范化学名称、因素类型、模型贡献方向、所属相关模块、bootstrap 入选频率、方法间一致性、化学证据、证据等级。正文统一称“稳定关键预测关联化合物”或“候选关键化合物”；没有加标或干预实验时不声称因果。

### 2.2 题面与附件冲突

题面称 `2.csv` 为 Pearson，附件 `数据说明.txt` 称 Spearman。逐元素复算结果为：

- `2.csv` 与 `1.csv` 的 Spearman 矩阵最大绝对误差为 $6.66\times 10^{-16}$；
- 与 Pearson 矩阵的最大绝对差为 1.1234，平均绝对差约 0.0873。

因此 Q2 统一按 Spearman 解释，并在论文中写明“题面文字与实际附件不一致，本文根据数据说明和逐元素复算采用 Spearman”。题面还把 `6.csv` 写成 46×50，实际为 44×50；题面首页把 226 个化学性质误写成 226 款啤酒，实际为 250 款啤酒。所有分析以实际文件为准。

### 2.3 小样本、共线与目标异质性

- 样本数 250、预测量 231，属于 $p\approx n$ 的高维小样本问题。
- 缺失共 73 个单元，分布在 63 行、9 个字段；沿用 Q1 的折内中位数填补和缺失指示。
- 化学预测量中，绝对 Spearman 不低于 0.8 的特征对有 39 对，不低于 0.9 的有 9 对，存在明显替代变量。
- `2.csv` 若按单一阈值二值化，图结构变化很大：

| 边条件 | 边数 | 密度 | 孤立点 | 最大连通分量 |
|---|---:|---:|---:|---:|
| $|\rho|\ge 0.2$ | 8323 | 0.3133 | 0 | 231 |
| $|\rho|\ge 0.3$ | 3918 | 0.1475 | 4 | 227 |
| $|\rho|\ge 0.4$ | 1660 | 0.0625 | 14 | 217 |
| $|\rho|\ge 0.5$ | 645 | 0.0243 | 48 | 175 |
| $|\rho|\ge 0.6$ | 266 | 0.0100 | 101 | 99 |

在 |ρ|≥0.5 时，645 条边中只有 16 条为负边。直接取绝对相关并硬阈值化会同时造成连通性突变和负相关结构丢失。

50 个感官目标同样存在结构：绝对 Spearman 不低于 0.5 的目标对有 64 对；15 组同类 Aroma—Flavour 目标相关均值约 0.697。但 Q1 已显示不同目标的可预测性差异很大，不能用一套无差别共享模型强迫所有目标选择相同化合物。

Q1 的 ExtraTrees 已给出可靠接口：10 次外层重复的宏平均 $R^2=0.2359\pm0.0058$、MAE 为 $0.3422\pm0.0011$、Spearman 为 0.4144；对每款啤酒汇总 10 次 OOF 预测后，50 个目标的宏平均 $R^2=0.2502$。Q2 应复用冻结划分和预处理，并把每个目标的 OOF 可预测性作为归因可信度门槛。

## 3. 候选“化合物”的资格口径

231 个字段混合了三类变量：

1. **单体化合物**：如乙酸乙酯、异戊醇、DMS、乳酸、乙醇；
2. **理化或组成指标**：如色度、pH、IBU 苦度、CO2 压力、糖、蛋白、β-葡聚糖、不可发酵物；
3. **派生聚合量**：热量、总酸、总酯、总酒花香气、总硫化合物。

题面写的是 Top-3“化合物”，若直接把 pH、色度或 `esters_sum` 放入主答案，会出现名义不合规；若完全忽略这些字段，又会丢失酸度、苦度、酒体等重要机制锚点。因此采用双口径：

- **主答案：严格单体化合物 Top-3。** 派生聚合量和纯理化代理不具备候选资格；
- **敏感性附表：全部测量因素 Top-3。** 允许 pH、IBU、色度、CO2 压力和聚合量进入，用来说明严格化合物结果是否被理化指标代理。

在正式运行前先生成 `q2_candidate_dictionary.csv`，逐字段给出 `factor_type`、`eligible_strict`、`eligible_all`、名称、单位、来源、是否校准、是否有阈值、是否为 aging/off-flavor。任何候选资格都以这张表为准。

## 4. 问题分析：难点与对策

### 难点一：相关图是全样本统计，直接进入交叉验证会泄漏

`2.csv` 使用了全部 250 款啤酒。虽然它不含目标值，但若模型的图结构、相关簇或特征筛选在验证前就由全体样本估计，验证样本已经参与表示学习，会使模型选择与稳定性略偏乐观。

**对策：** 全样本 `2.csv` 只用于数据核验和最终描述图；所有 OOF 性能、超参数选择、相关模块和模型重要性都在训练折内由 `1.csv` 重算 Spearman 图。最终 150 条答案再用全数据拟合一次，并用 bootstrap 量化其不确定性。

### 难点二：强共线使“单一字段第三名”高度不稳定

同源酯类、萜类、醇类常随风格和工艺共同变化。树模型可能随机把贡献分给其中一个代理变量，Lasso 也可能在一组强相关变量中任取一个。一次性 MDI、SHAP 或系数绝对值不能证明 Top-3 稳定。

**对策：** 同时报两种稳定性：

- **字段级稳定性**：某具体化合物进入 Top-3 的频率；
- **相关模块级稳定性**：该化合物所在强相关模块中任一成员进入 Top-3 的频率。

若模块频率高而字段频率低，应解释为“机制模块稳定、模块内代表可替换”，并列出候选替代物，不能硬说某一个字段具有唯一性。

### 难点三：边际相关、预测贡献和化学因果不是同一概念

Spearman 衡量单变量单调关联；图约束回归系数与置换重要性衡量给定其他变量时的预测依赖；化学机制还需要阈值、来源、气味描述或加标实验支持。

**对策：** 三层证据分别计算、分别呈现：

1. 边际层：Spearman ρ 与 `6.csv` 后验对照；
2. 预测层：折外条件/分组置换、图约束系数、PLS-VIP；
3. 化学层：名称、来源、阈值/OAV、off-flavor、文献和原论文加标证据。

只有三层一致时给高证据等级；任何一层缺失都必须降级说明。

### 难点四：啤酒风格可能制造伪重要性

某化合物和某感官维度可能都只是特定风格的标志。化学模型能预测风格，并不等于该化合物在风格内部仍决定感官差异。

**对策：** 同时拟合化学总关联模型和风格校正模型。后者将 22 类风格作为不受图惩罚的干扰项，或在训练折内对风格均值作交叉拟合残差化。再做 22 次留一风格删除分析。若候选只在化学总关联中出现，标为“风格驱动”；在风格校正和留一风格下仍稳定者，证据更强。

### 难点五：部分感官目标的预测能力较弱

若一个模型对某目标仅略优于均值预测，其 SHAP 或重要性排名即使数值完整，也缺少解释基础。

**对策：** 每个目标先过预测可靠性门槛，再解释 Top-3。题面要求每个维度都给结果，因此弱目标仍输出，但证据等级标为探索性，并突出较宽的不确定区间。

## 5. 模型假设与失效处理

1. **样本独立性。** 将 250 款商用啤酒视为相互独立的观测，技术重复已由原数据提供方汇总。若后续发现同品牌批次或重复产品，则按产品组进行 grouped bootstrap 和 grouped CV。
2. **Spearman 图的解释。** 化合物之间的秩相关代表共同变化模式，不等同于化学反应路径或调控关系。论文使用“共表达/共变化图”，不写成反应网络。
3. **缺失机制。** 在已观测化学特征和缺失指示条件下，少量缺失可由训练折中位数近似处理。若某字段缺失频率或缺失—目标关系显著，则单列缺失机制敏感性，不把填补值解释为真实浓度。
4. **测量尺度。** `1.csv` 已含原始量纲与 log10 字段；保持原尺度，不重复取对数。线性模型只在训练折内稳健标准化；树模型使用原尺度填补值。
5. **感官尺度。** `4.csv` 是标准化连续分数，Q2 的排名在该尺度上建立。Q1 的经验 0–6 映射只用于评分呈现，不反向参与 Q2 排名。
6. **观测支持。** 模型只能解释附件浓度范围内的变化；阈值外推、超高浓度和新风格结论均需降级。非线性效应若超出样本支持范围，不作化学定量推断。
7. **候选贡献。** Top-3 表示在当前样本、候选集合和模型体系中的稳定预测关联，不自动等于可干预的因果效应。

## 6. 共表达图设计

### 6.1 基础相关

对训练样本的每对预测量计算 pairwise-complete Spearman：

\[
\rho_{jk}=\operatorname{corr}\{\operatorname{rank}(X_j),\operatorname{rank}(X_k)\}.
\]

采用 pairwise-complete 是为了复现 `2.csv`；模型矩阵仍按 Q1 口径做训练折中位数填补和缺失指示。

### 6.2 软权有符号图

不使用单一硬阈值作为主图，而定义：

\[
a_{jk}=|\rho_{jk}|^{\beta},\qquad s_{jk}=\operatorname{sign}(\rho_{jk}),
\]

其中 β 在 `{1,2,4,6}` 中由内层交叉验证和 bootstrap 图稳定性共同选择。`a_jk` 保留关系强度，`s_jk` 保留正负方向。最终画图可以只显示稳定强边，分析过程仍使用连续权重。

对图拉普拉斯采用绝对度数 $d_j=\sum_k a_{jk}$，有符号平滑项为：

\[
\Omega_G(b)=\sum_{j<k}a_{jk}
\left(\frac{b_j}{\sqrt{d_j}}-s_{jk}\frac{b_k}{\sqrt{d_k}}\right)^2.
\]

正相关邻居倾向得到同向系数，负相关邻居倾向得到反向系数；归一化度数避免高连接节点仅因度数大而被过度惩罚。

### 6.3 图稳定性

在 bootstrap 中重算相关和软权。每条边记录相关方向一致率、强边入选频率和权重中位数；图参数在 `|ρ|` 效应阈值 0.25/0.30/0.35/0.40 及 β 候选上做敏感性。最终网络只把方向一致率和入选频率达到预设门槛的边标成“稳定边”。

社区用于解释和联合置换，不用于把所有社区成员都判为关键化合物。模块算法、随机种子和分辨率必须入配置文件，模块变化用 co-clustering 频率或调整兰德指数报告。

## 7. 三条技术路线

### 路线 A：相关图 + 单次树重要性

步骤是构图、对每个目标训练 ExtraTrees/GBR、按 MDI 或 SHAP 取前三。它最接近原始论文，也最容易快速形成结果。

**优点：** 实现快，非线性和交互捕捉能力强，与 Q1 最优 ExtraTrees 一致。

**缺点：** MDI 有偏；SHAP 在相关变量下会分摊或转移贡献；单次划分不能回答题面明确要求的稳定性；图只被用于展示，没有真正参与选择。该路线只作最低基线，不作为最终答案。

### 路线 B：图约束稀疏回归 + 非线性模块置换 + 稳定共识

这是首选主线，包含三个互补视角：

1. **有符号图约束 Elastic Net（主选择器）。** 对每个感官目标 $y_t$ 求解：

\[
\hat b_t=\arg\min_b
\frac{1}{2n}\|y_t-Xb\|_2^2
+\lambda_1\|b\|_1
+\lambda_2\|b\|_2^2
+\lambda_G\Omega_G(b).
\]

L1 产生稀疏选择，L2 缓和共线，图项使相邻化合物的贡献按相关方向平滑。该目标可通过图拉普拉斯平方根构造增广数据，再调用 sklearn Lasso/ElasticNet，无需安装新求解器。

2. **ExtraTrees + 折外模块置换（非线性验证器）。** 复用 Q1 的 ExtraTrees 预处理和冻结 CV。先联合置换一个相关模块，计算验证集 MAE 或 $R^2$ 的下降；再在重要模块内做残差条件置换，减少强相关代理造成的单变量低估。SHAP 只用于最终候选的局部方向和个体差异展示，不作为唯一排名。

3. **PLS/VIP（化学计量学对照）。** PLS 对高维共线化学数据常用，VIP 提供第三套连续排序。PLS 不决定最终答案，用于判断图约束和树模型是否只捕捉了某一种结构。

三种方法各自输出完整 231 维排名。共识使用中位秩或 Robust Rank Aggregation，不直接平均不同量纲的重要性。一个候选原则上需满足“至少两种方法进入 Top-10”或“主选择器 bootstrap Top-3 频率很高且有直接化学证据”；不满足者仍可进入前三，但证据等级下降。

### 路线 C：化合物图神经网络

将 231 个预测量作为节点、每款啤酒的浓度作为节点信号，以训练折相关图作为邻接，使用 1–2 层 GCN/GraphSAGE 预测 50 个目标，再用集成梯度或 GNNExplainer 排名。

**可能价值：** 能表达局部图传播和非线性交互，Q1—Q2 可用同一结构。

**主要风险：** 只有 250 个图样本；相关图并非反应机制图；解释器本身也不稳定；当前没有 PyTorch Geometric，安装会扰动环境。原始同源论文中 ANN 也未优于树模型。

因此 GNN 只在主线完成后作为 E110 消融：参数量严格受限，并且只有 OOF 性能、Top-3 稳定性和化学正对照同时改善才进入正文。深度克里金需要空间坐标与空间协方差，本题没有；强化学习需要序贯决策、状态和奖励，本问也没有，二者不作为 Q2 迭代方向。

## 8. 首选流程

### 8.1 数据与候选合同

1. 复用 Q1 的 `beer` 对齐、50 个目标字典和冻结 CV；
2. 建立候选资格表，冻结严格化合物与全部因素两套集合；
3. 每个外层训练折内完成填补、缺失指示、缩放、Spearman 构图、模块划分和调参；
4. `2.csv`、`5.csv`、`6.csv` 和附件 8 预计算重要性不得参与外层模型选择。

### 8.2 预测可靠性

每个方法先在冻结 OOF 划分上报告逐目标 $R^2$、MAE、Spearman 和校准。重要性只在验证折计算后聚合。若目标模型不优于风格收缩均值或置换标签基线，则其 Top-3 标为探索性。

另外做两个直接检验：

- **仅 Top-3 重训**：使用前三个化合物能保留多少全模型 OOF 表现；
- **删除 Top-3**：从全模型移除前三后，OOF 表现是否显著下降。

二者结合可防止“排名好看但不携带可复现预测信息”。

### 8.3 Bootstrap 稳定选择

先用 100 次试运行检查耗时和频率收敛，再做 500 次正式重采样。每次在 250 行中按风格分层有放回抽样，并从头重跑填补、构图、模型和排名。对第 $t$ 个感官目标与第 $j$ 个候选，记录：

\[
\hat\pi_{jt}=\frac{1}{B}\sum_{b=1}^{B}
I\{j\in \operatorname{Top3}_{t}^{(b)}\}.
\]

在最不确定的 π=0.5 处，B=500 的 Monte Carlo 标准误约为 0.022。除入选频率外，还报告中位秩、四分位距和方向一致率。

Top-3 集合稳定性按题面给 Jaccard：

\[
J(S_a,S_b)=\frac{|S_a\cap S_b|}{|S_a\cup S_b|}.
\]

因为集合大小只有 3，Jaccard 只能取少数离散值，需同时报告 Top-10 秩相关和机会校正的 Kuncheva 指数。方法间 Jaccard、bootstrap 间 Jaccard、模块级 Jaccard 分开列出，不能混成一个“稳定性分数”。

### 8.4 风格敏感性

每个目标比较三种结果：

1. 仅化学特征；
2. 化学特征 + 风格干扰项；
3. 22 次留一风格删除。

报告候选的总关联入选频率、风格校正入选频率和留一风格保留率。若某候选在删除一个风格后消失，应明确指出它主要反映该风格而非跨风格关系。

### 8.5 化学合理性证据链

每个 Top-3 候选按以下顺序核验：

1. **字段身份**：英文名、代码、单位、来源是否一一对应；
2. **直接锚点**：DMS、4VG、Diacetyl、trans-2-nonenal、乙醇等命名感官目标能否恢复相应化合物或其稳定模块；
3. **阈值与 OAV**：仅对附件 8 中有校准浓度、同单位阈值的字段计算 $\mathrm{OAV}=c/\tau$；log10 特征或未知单位不得直接计算；
4. **来源和气味描述**：酯、醇、萜、醛酮、硫化物、酸等类别是否与感官语义一致；
5. **方向/形状**：图约束系数、Spearman 与交叉拟合 ALE 是否一致。存在 U 型或阈值效应时标为“非单调”，不强行写正负；
6. **网络邻域**：相邻化合物是否来自相近原料、代谢或风味类别；
7. **独立文献**：优先原始论文、阈值研究和啤酒化学文献；CSDN、Kaggle 页面不作为化学机理依据；
8. **全量附件后验核验**：最后才与 `6.csv` 和附件 8 的既有结果比较一致性。

化学证据等级建议：

- **A**：预测可靠、bootstrap 稳定、至少两法一致、风格校正稳定，且有直接阈值/加标/强文献证据；
- **B**：预测与稳定性合格，有合理类别/方向证据，但缺少直接实验；
- **C**：模型或方法间分歧较大，仅具边际相关或模块级支持；
- **D**：目标可预测性弱或候选仅由单一风格驱动，作为探索性结果。

阈值 0.60/0.70/0.80 应做敏感性，不把 0.70 当作自然常数。

## 10. 正对照、负对照与失效诊断

### 10.1 正对照

利用目标字典中可直接对应的感官—化学锚点检查流程，例如：

- `dms` ↔ `DMS`；
- `diacetyl` ↔ `X2.3.butanedione`；
- `X4vg` ↔ `X4VG`；
- `t2n` ↔ `X.E..2.nonenal`；
- `alcohol`/`body` ↔ ethanol；
- `co2` ↔ CO2 压力代理；
- `bitternes` ↔ IBU/异 α 酸代理；
- `acidity` ↔ pH、乳酸和乙酸模块。

严格化合物表不要求 pH/IBU 成为答案，但应恢复相应酸类或酒花苦味化合物；全部因素表应能显示物理代理。

### 10.2 负对照

- 目标标签在训练折内随机置换，检查是否仍出现高入选频率；
- 加入随机噪声字段，检查其排名与频率；
- 随机选择 Top-3 化合物作为预测对照，比较真实 Top-3 的 OOF 增益。

若负对照也能得到高稳定性，说明模型或重采样流程存在泄漏或选择偏差，应停止解释。

### 10.3 失败模式

| 现象 | 可能原因 | 处理 |
|---|---|---|
| OOF 性能好但 Top-3 频率低 | 多个强相关代理互换 | 报模块稳定性和替代物，不硬定唯一字段 |
| 相关很高但条件重要性接近 0 | 关联被邻居或风格解释 | 归为边际关联，不列主 Top-3 |
| SHAP 高但删除后性能不变 | 贡献分摊或解释器偏差 | 降级，以折外删除/置换为准 |
| 方向在 bootstrap 中反复变化 | 共线或非单调关系 | 标为方向不确定/非单调，画 ALE |
| 仅一个风格支撑 | 风格混杂 | 标为风格特异，降低跨风格证据 |
| OAV 很高但模型不重要 | 变异不足或已接近饱和 | 解释为感官活性存在但无法解释样本间差异 |
| 模型重要但 OAV<1 | 阈值/单位/混合效应或代理变量 | 核对单位与矩阵效应，不直接否定或确认 |

- 代表目标 Top-3 与证据表。

## 14. 对历年优秀论文做法的吸收与修正

本地 40 篇优秀论文中，2022-6 使用 Spearman、VIF、逐步回归与 Lasso 交集处理影响因素；2022-8 使用 Spearman、LOFO 和多模型评估；2025-7 使用 OOF Stacking 和 SHAP。可迁移的是“多方法交叉验证、逐目标解释、结果数字与业务逻辑共同证明”。不能照搬的是全数据筛选、单次树重要性和把 SHAP 直接写成因果。本题比往年一般影响因素题多出一项明确要求：Top-3 本身必须在重采样或方法变化下可复现。

## 15. 外部资料结论

与附件同源的 2024 Nature Communications 论文使用 250 款啤酒、226 个化学性质和 50 个训练品评维度，比较 10 类模型并发现树模型总体最好；作者也观察到共相关变量会压低或分散 MDI/SHAP 重要性，并通过 100 次模型重复检查主要预测量。其 [Zenodo 官方仓库](https://zenodo.org/records/10653704) 提供训练、SHAP 与作图代码，但代码在划分前对全数据做均值填补，且附件 8 的 MDI/SHAP 对象是 RateBeer overall appreciation，不是本题 50 个目标。因此本文复用其化学语义和模型基线，重建严格折内、逐目标、稳定选择流程。

图构建参考 [WGCNA 原始论文](https://doi.org/10.1186/1471-2105-9-559) 的软权网络思想；图约束回归参考 [Li 与 Li 的 Grace](https://doi.org/10.1093/bioinformatics/btn081)；重采样依据 [Stability Selection](https://doi.org/10.1111/j.1467-9868.2010.00740.x)；相关变量解释参考 [Conditional Variable Importance](https://pmc.ncbi.nlm.nih.gov/articles/PMC2491635/)、[dependent-feature SHAP](https://doi.org/10.1016/j.artint.2021.103502) 与 [ALE](https://doi.org/10.1111/rssb.12377)。[scikit-learn 官方 permutation importance 文档](https://github.com/scikit-learn/scikit-learn/blob/main/doc/modules/permutation_importance.rst) 也明确要求先验证模型泛化能力，并提醒强相关特征会互相替代。

Kaggle 公开数据为 5558 款啤酒的风格、评分与评论词频，没有化学浓度，也无法与官方样本可靠连接，故不进入 Q2 主模型。GitHub 和 CSDN 的 WGCNA/SHAP 示例只用于核对实现习惯；任何固定阈值、默认参数或单次重要性结论都必须由本题数据重新验证。

## 16. 推荐结论

推荐采用路线 B：**有符号软权 Spearman 图 + 图约束 ElasticNet 主选择 + ExtraTrees 折外模块/条件置换 + PLS/VIP 第三视角 + 500 次分层 bootstrap + 风格校正 + 化学证据分级**。

它比“相关前三”多解决冗余和条件贡献，比“单次 SHAP”多解决泛化与稳定性，比 GNN 更适合 250 行的小样本，也能明确说明 `2.csv` 如何真正进入模型。下一步在用户确认该设计后，先执行 E100 数据/候选/图合同，再依次跑 E101—E105 小规模基线；主线稳定后才启动 500 次 bootstrap，暂不安装新包、不用 GPU。
