# Q2 E113 正式审计报告

E113 在 `q2-evidence-opt` 独立工作区完成30个固定外层折。运行前核对250款啤酒、231个输入字段、218个严格单体候选和Q1固定10×3划分；运行中每折写入带输入/源码/配置哈希的 checkpoint。`audit_e113.py` 对30个checkpoint逐一核验，错误数为0。

## 折内口径

每一折先在外层训练行内做中位数填补和经验高斯化；Graphical Lasso 的 alpha 由训练内3折 held-out Gaussian log-likelihood 的1-SE可行集、边Jaccard稳定性和较大alpha规则选择。偏相关边、Louvain模块和共聚类只由外层训练数据生成。30折的 `scope=outer_train_fold`；全量描述图单独标为 `full_data_descriptive`，没有进入折内结果。

## 决策

`q2_graph_decision_E113.json` 的 `promote_partial_graph=false`。原因是图/模块稳定性未超过预先登记参考；held-out likelihood 有限、scope隔离和字段覆盖均通过。E113 因此作为折内图证据与敏感性产物保留，不替换既有 Q2 统计主线，也不把全量图写入外折证据。

少数 alpha 候选出现 Graphical Lasso 收敛警告或内层失败，已按候选完整性规则排除；没有把未收敛矩阵写入正式折结果。E113 不涉及Q1重训，最终NNLS接口只用于后续需要的预测/归因适配。
