# Q3 参考思路再评估与下一轮候选

2026-10-26。E213 已完成固定 10×3 外折并保留原风格收缩 Copula。本文把 BZD、agent、agent2、agent3 和学长版的可吸收部分重新按当前数据瓶颈排序，不启动新实验。

## 1. 当前判断

Q3 仍有优化空间，但最高收益点已经从“换更复杂的生成器”转为“把小样本边缘、地板状态和迁移可行域建得更准确”。当前 Copula 的稳健 W1/energy 为 0.476168/0.581304，覆盖率 0.557988；它是经过同口径外折审计的主线，不代表已经达到方法上限。

E213 只检验了一个固定的小型去噪自编码器加残差噪声/曲率构造。神经候选相对 Copula 的稳健 energy 增加 0.035359、0/10 重复改善；PCA 残差噪声使 energy 降低 0.005033、8/10 重复改善，但平均局部坐标剪裁率为 20.33%，超过预登记的 15% 限制。神经残差协方差迹约为 PCA 残差的数百倍，神经局部坐标约 78.95% 越出训练风格范围。这个结果说明当前残差尺度和解码器稳定性不足，不能推广成所有深度生成路线都无效。

## 2. 参考思路的取舍

| 来源思路 | 可吸收内容 | 当前处理 |

| agent3 经验贝叶斯均值收缩、共享协方差 | 小风格均值向总体收缩；迁移时保留源样本个体偏差 | 适合做收缩迁移候选；严格使用源值上界和训练折参数 |
| agent3 Mahalanobis 可行域 | 沿联合协方差方向修改谱，减少逐列投影造成的结构破坏 | 只作为迁移候选；每个缺陷必须满足已知硬约束，未知项继续拒绝或降级 |
| BZD B/agent2 条件 VAE | 条件生成、显式约束、左删失状态建模 | 作为后备挑战者；已有参考结果存在约0.31的严格不恶化率或较高违反率，不能直接沿用 |

| 强化学习 | 多步策略优化的形式 | 静态 Kaggle 表没有动作、状态转移和反馈，继续不启动真实 RL |

## 3. 优先级排序

### 3.1 第一优先：地板/零膨胀感知的 Copula 边缘

4VG 在官方样本中有168/250款处于同一地板值，统一的秩正态边缘会把检测状态和连续浓度混在一起。下一候选应对每个有地板的字段拆为：

1. `z=0` 或观测地板状态的指示变量；
2. 在 `z=1` 的样本上拟合连续边缘；
3. 对指示变量使用风格收缩的 Bernoulli 概率，对连续部分使用经验分位数或带权秩变换；
4. 联合采样后恢复原存储尺度，并分别报告地板率、非地板 W1、总体 W1、energy、覆盖率和近复制率。

这条路线直接针对当前主模型的可见缺陷，模型复杂度也小于再次训练生成网络。必须把地板状态和真实零、缺失、未知 LOD 分开；它不能凭空恢复地板以下浓度。

### 3.2 第二优先：共享协方差和经验贝叶斯均值的严格迁移

把目标风格均值写成

`μ_s^* = a_s μ_s + (1-a_s) μ_0`，其中 `a_s=n_s/(n_s+κ)`，再用共享或风格收缩协方差构造目标端点。源谱迁移时保留源样本在目标风格中心下的个体偏差，使用 Mahalanobis 代价寻找候选。

候选必须同时满足：已知直接缺陷不高于源值、不超过已知阈值；未知/删失项不计为安全通过；源谱保持与 λ=0 的身份一致；逐源报告拒绝原因、改变量、目标距离和感官代理不确定性。agent3 的 `max(源值,阈值)` 口径不能沿用。

### 3.3 第三优先：修复后再评估神经残差

如果继续探索神经路线，应先登记以下固定改动，再与原 Copula、PCA 残差和当前 E213 做同口径比较：

- 对解码器施加谱归一化或固定 Lipschitz 上限；
- 在训练折内对残差协方差作最大特征值/迹约束，并把约束写入配置；
- 使用验证前确定的残差强度网格，禁止根据外折剪裁率调小噪声；
- 把“未剪裁分布”和“训练范围内支持裁剪”分开评价；
- 仍保持端点曲率为零、四路随机流、10×3 外折和相同生成种子。

这条路线只有在神经残差的尺度回到与 PCA/原始残差同一数量级后才值得继续。若修复后仍不能改善联合 energy、W1、覆盖和风格尾部，就停止神经路线。

### 3.4 第四优先：ABV 单维外部弱先验

Kaggle 的 ABV 与官方酒精度字段可直接对齐，但它只增加一个外部边缘变量。当前已按酒厂固定分为 prior/holdout：Tripel 39/11、Kriek 13/6、Lambic 60/38，跨组酒厂为0。由于外部数据此前已整体查看，这个 holdout 不能作为完全未见的独立验证。

如继续，应只在官方外折训练集内选择权重 `w`，比较 `w=0`、固定弱权重和训练内选择权重；官方验证折负责评估。ABV 先验不得改变231维化学相关结构，也不得被用于感官标签、Q2排名或迁移安全判定。

## 4. 不推荐的路线

- 直接扩大 CVAE、GAN、扩散模型：样本量和风格内样本仍不足，E213 已显示复杂解码器的尺度控制是风险。
- 把 DeepKriging 当成空间模型：本题没有自然空间坐标，化学距离只是人为表示，需要单独证明局部生成有效。
- 用 Kaggle 评论、IBU 上下界构造强化学习动作转移：没有同一对象的前后状态和奖励反馈。
- 继续调 α、噪声强度或剪裁阈值直到某个指标变好：会把预登记约束变成事后选模。

## 5. 建议的下一轮顺序

先登记地板感知边缘的单独候选，完成一折工程复核后再跑完整 10×3；若地板率和联合指标改善，再登记严格收缩迁移。ABV 只做弱先验敏感性。神经残差改进放在这两条路线之后，只有修复残差尺度后才重新进入数值实验。
