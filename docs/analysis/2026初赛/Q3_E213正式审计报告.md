# Q3 神经残差与曲率插值正式审计

2026-10-26；内部编号E213。**30/30完成，正式决定保留原风格收缩Copula。** 神经正式候选无综合增益；线性残差方案虽过原分布比较条件，但触发预登记的剪裁限制，不改选为主模型。Q1 v5、Q2冻结答案、900份画像与原迁移结果均未替换。

## 1. 实施与防泄漏

沿用250款×231字段、固定10次重复×3外折、三风格、5生成种子。每个外层训练内部再按风格分成两折，以3生成种子选择α与β。只有官方训练化学谱参与网络拟合，无感官Y、Q1预测反馈、Kaggle输入、外折早停或A100。

网络为231→32→8→32→231，共15599参数，Tanh、200固定AdamW步、去噪输入、Huber重构目标。每折两次内层拟合加一次外层训练，共90次小网络拟合、18000步训练史；本机RTX5070Ti Laptop GPU，推断在CPU float64。填补、1%—99%裁剪/IQR尺度与残差协方差均为当前训练内计算。

端点保持曲率为`D((1-t)E(u_i)+tE(u_j))-(1-t)D(E(u_i))-tD(E(u_j))`，真实线性谱上加β曲率和固定γ=0.5的协方差残差噪声。β=0/0.5、α=0.25/0.5/0.75；PCA残差3候选，神经正式候选6候选，预算差异保留。各风格恒定列保持常量，局部分量按该训练风格范围限定，并记录截断前比例。范围限制不是缺陷安全投影。

选择器/Copula/锚点/噪声为四个独立流。旧Copula和独立流普通混合的指标/样本只读，未重跑；完整性按冻结折身份、源哈希与Q1注册表/OOF哈希核验。

对重复均值作2000次重复块描述性bootstrap，PCA的energy差区间为[-0.008442,-0.001640]；重复训练集高度重叠，此区间不是独立确认置信保证，也不抵消截断依赖问题。

这里的cell比例针对每次生成的全部局部提案，不因该提案是否被整行混合选择而缩小分母；每折、每风格、每种子等权。生成样本实际被截断的比例另存`generated_cell_clipping`。

神经候选约79%的局部坐标越出训练风格范围。未截断敏感性下，其稳健energy为0.743418、原始W1/energy=2.301390/7.365036，均比截断后更差；PCA未截断稳健energy为0.576765、coverage为0.608617。以上是固定候选的诊断，不据此事后换成未截断方法。

训练内诊断显示：PCA的平均残差协方差迹在三个风格约431—516，神经约309118—364960；这是同一规范化坐标下的计算。外层网络平均Huber损失从1.4860降到1.2812，但这种重构目标下降没有转化为可用的残差生成。当前固定网络/固定残差强度导致大量越界，不能直接归因成“所有深度模型都无用”或“样本不足是唯一原因”。本轮不增大网络、不手调γ、不改剪裁条件。

## 4. 工程修复与完整性

首折工程回放发现，C/F输入布局可令重复特征值的协方差采样因子改变；协方差相对差≤5.3e-15，采样因子差却可达19.8，导致固定种子的噪声不同。先以失败测试复现，再规范输入为C布局、把实际采样因子连同小型网络权重写入NPZ；恢复时验证其协方差并使用保存因子，不重新选择等价特征子空间。

修复前首折完整保留在`q3_engineering_archive_E213/pre_sampling_state_fix/`，标为非正式工程产物；没有最终manifest，不混入本次30折。修复未更改架构、训练步数、评价、候选集合或采用条件。

正式审计验证136个冻结输入、5400条评价、1620条内层选择、18000行训练史；30折完整谱逐条回放最大绝对误差1.82e-12，energy复算误差2.27e-13。两项原基线全部指标复现，Q1注册表/OOF接口一致，神经网络没有重训Q1或重新拟合NNLS。Spearman相关诊断保留原数组口径，近似同秩对浮点精度敏感，不拿它改写固定W1/energy/覆盖决定。


测试：138项+53个子测试通过，包含端点/仿射曲率、独立流、零修正旧原语、保存状态恢复、特征空间旋转回归、内层选择、完整折/种子覆盖和固定拒绝规则。每个NPZ约2.56MB，是恢复噪声与权重所需状态，不包含大型训练cache/joblib。
