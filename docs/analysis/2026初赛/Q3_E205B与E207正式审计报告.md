# Q3 E205B / E207：感官约束搜索、一次审计与冻结谱敏感性

## 结论与主规则

在固定33个源—目标组合中，预登记的“最小改动”主规则找到29条可进入审计的谱；最终2条满足C1可判定直接约束、至少1%目标靠近、支持域和双模型预测不升。它们均来自源beer=230，分别指向Tripel和Kriek。其余26条直接化学证据不足、4组固定搜索无可行点、1条审计模型重复方向不稳。不能把2条候选解释成2款独立实测源啤酒，更不能报告新啤酒物理安全率。

原E205只审计既有路径，可用候选为0；本轮把NNLS的感官约束前置到有限候选搜索，出现了满足统计筛选的点。这是本题数据上的设计改进，不是新的外层泛化成绩或因果干预证据。

## 固定搜索与锁定顺序

- 11源×3目标，每组来自原2000条Copula池的最近256条几何锚点，加原秩映射锚点；每个锚点固定7个非零λ，共59,367个搜索点。
- 主模型只读取源所在验证折的10个冻结NNLS预测器；单目标等价计算对完整模型的最大差9.30e-16。Q1没有重训、NNLS没有重估权重，Q2文件没有改写。
- NNLS平均Stale hops变化和重复90%分位均须≤−0.01 z，目标相对靠近≥1%，且至少9/10重复处于预测支持域。0.01 z是搜索裕量，不是生理感官阈值。
- 三种规则各1条：最小改动（主规则）、最大目标靠近、最大预测裕量。总计99规则行，锁定87条可用谱；相同谱可能被不同规则重复选择，实际唯一谱81条。
- 候选锁定提交 `5fefb10` 后才运行独立模型族审计；没有根据ElasticNet输出重新搜索或改选候选。99条规则行中4条通过不等于主规则4/33成功。
- 独立模型族仅在本轮搜索中不被访问；它在前一轮已有诊断，且共享原始样本，因此不称完全未见数据的独立外部验证。

## 直接化学值与未知项

主规则两个统计候选均来自唯一四类直接缺陷可逐项核验的源。Tripel候选DMS/双乙酰/trans-2-nonenal保持源值，4VG由0.01940降至0.01372 mg/L；Kriek的DMS由15.1128降至11.5494 μg/L，4VG同样下降，其余两项不升。当前C1下均无已知约束违反。

其他源存在4VG地板/未知LOD或双乙酰缺失，不能用生成或中位数填补消除未知状态。三目标主规则中26条谱虽通过NNLS搜索，仍需补测直接化学证据。

## 冻结谱敏感性

E207只评估原锁定候选，未重新选点。均值/中位阈值与C1/C2/C3分开：C1相对不升不依赖绝对阈值；C2/C3对trans-2-nonenal始终保留未知，不能宣布全部阈下。

|额外要求的双模型预测下降裕量|Tripel主候选|Kriek主候选|
|---|---|---|
|0 z（原最终筛选口径）|满足|满足|
|0.01 z|审计器重复90%分位不满足|审计器重复90%分位不满足|
|0.02 z|两模型均不能保持该裕量|两模型均不能保持该裕量|

这说明两个候选在原“预测不升”定义下通过，但对更强下降要求不稳健。Stale hops的OOF解释度约0.03，模型误差约0.30 z，不能把0.03—0.06 z的预测变化写成已验证的真实感官改善。重复分位不是置信区间；没有LOD区间时也未模拟出虚构的安全概率。

## 完整性与检查

91个冻结输入哈希不变。独立核验逐组重算99个固定规则选择、重构87条锁定谱，最大谱误差1.78e-15；没有未知项被记为可用，没有物理安全认证。Q3测试85项与29个subtests通过。

本轮不用GPU，没有启动CVAE/扩散。复杂生成模型不能补出缺失测量或未知绝对阈值；优先完善真实可核验的数据边界与论文证据链。
