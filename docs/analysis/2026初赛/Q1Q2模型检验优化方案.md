不足：
1. **没有校准/区间覆盖**：只报点预测误差，没有“预测区间是否可信”的证据。
2. **没有重复划分稳定性图**：10 次重复只给均值和 SD，没展示重复间分布、模型排序是否稳定。
3. **残差诊断只在附图**：正文没有残差 vs 拟合、QQ、异方差、目标/风格残差结构。
4. **没有负对照/标签置换**：无法直观证明性能不是泄漏或目标结构带来的。
5. **没有风格外推压力测试**：只有风格内 MAE，没有“留一风格训练→预测该风格”的泛化证据。
6. **逐目标可靠性没有区间**：16 个弱目标只用文字说明，缺逐目标 CI/可靠性分层图。
7. **量表映射敏感性不足**：0–6 只作相对强度，缺不同锚点下的结论稳定性；
8. **外部一致性可选**：Kaggle 风格级外部校验已有 provisional 结果，但尚未进入论文，需谨慎定位为辅助附录。

## 2. 参考论文的验证写法（只学版式，不抄内容）

- **BZD**：2×2 面板、浅网格、直接数值、误差棒；每个面板一个结论，模型名/类别不挤坐标轴。适合 Q2 的模型对比、bootstrap 频率、Jaccard、覆盖度。
- **agent**：稳定性与化学合理性分开呈现；网络模块/阈值/一致性分图；避免把一张巨型网络承载全部结论。适合 Q2 的证据族与负对照。
- **学长版**：逐目标 R²、QWK/±1、校准/残差、bootstrap、网络阈值、Jaccard、OAV 分图组织；单图信息量低但每个结论清楚。适合 Q1 的逐目标可靠性与校准。
- **共同点**：图少而结论明确、字号大、直接标注、留白足、正文只引用图号；不在图内塞整段解释。

## 3. Q1 优化方案

### 3.1 新增检验（Tier 1，无需重训）

1. **重复划分稳定性**
   - 数据：`model_metrics_by_repeat.csv`（10 次重复 × 各模型 × 五项指标）。
   - 指标：重复间分布、变异系数、模型排序稳定性（每个重复内模型名次与总名次的一致性）。
   - 输出：`q1_validation_repeat_metrics.csv`、`q1_validation_model_rank_stability.csv`。

2. **逐目标校准**
   - 数据：`final_oof_predictions.csv.gz`（250×50 OOF）。
   - 方法：每个目标按预测分位分 5–10 箱，计算箱内观测均值 vs 预测均值；汇总 ECE/MCE；按香气/风味/口感/总体分组。
   - 输出：`q1_validation_calibration_bins.csv`、`q1_validation_calibration_summary.csv`。

3. **共形/经验区间覆盖**
   - 数据：OOF 残差；按目标做折外残差分位数（不使用验证折拟合）。
   - 指标：80%/90%/95% 名义覆盖率、平均区间宽度；覆盖率 vs 目标 R²。
   - 输出：`q1_validation_interval_coverage.csv`。
   - 说明：这是“固定 OOF 残差”的经验区间，不声称严格共形保证；若实现 CV+，需在报告中写清折外校准方式。

4. **逐目标可靠性分层**
   - 数据：逐目标 R²/MAE/Spearman + beer bootstrap 或残差 bootstrap CI。
   - 输出：50 个目标的点估计 + 95% CI，按强/中/弱分层；对应论文“三个世界”的表述。
   - 输出：`q1_validation_target_reliability.csv`。

### 3.2 Tier 2（需要小规模重训/新计算，按时间决定）

1. **负对照/标签置换**：训练折内打乱目标，重跑同一流程；预期 R²≈0、MAE≈基线；只做 1–2 次重复，证明无泄漏。
2. **特征组消融**：去掉 hop/yeast/malt/ester 汇总/缺失指示等组，比较五项指标；或复用已有权重结构消融，不重复建模。
3. **留一风格压力测试**：每次留出一个风格训练，预测该风格；报告 R²/MAE 与样本量。小样本风格只作描述。
4. **0–6 映射敏感性**：全局 min–max、训练折经验分位、均值锚点三种映射下，比较模型排序/结论是否稳定；只作附录表。

### 3.3 Tier 3（可选）

- Kaggle 风格级外部一致性：只用 5 个主维度 + ABV，作为辅助外部效度附录；不训练、不选模型、不写成独立验证。已有 provisional 结果可直接转成一张小图/表。

### 3.5 Q1 正文改写

在“模型检验与稳健性”下按四段写：
1. 泄漏与协议：外层折不可见、折内预处理、无全量矩阵入模；
2. 重复稳定性：10 次重复分布、名次一致性；
3. 校准与区间：校准曲线、覆盖率、宽度；弱目标不夸大；
4. 消融/负对照/外推：特征组、标签置换、留一风格、量表敏感性；失败与退化如实写。

明确保留：

## 4. Q2 优化方案

### 4.1 新增检验（Tier 1，全部复用已有结果，无需重训）

1. **负对照可视化**
   - 数据：`q2_null_target_permutation_E117.csv.gz`、`q2_shadow_feature_audit_E117.csv`、`q2_cpss_selection_E117.csv`。
   - 指标：真实入选频率 vs null target/shadow 的入选频率；经验 FDP；零入选比例。
   - 输出：`q2_validation_negative_controls.csv`。

2. **稳定性区间**
   - 数据：E107 bootstrap selections / Jaccard / leave-one-style；E117 CPSS half selections。
   - 指标：入选频率、Jaccard、留一风格生存率的中位数 + 95% bootstrap 区间；按 A/B/C/D 分组。
   - 输出：`q2_validation_stability_ci.csv`。

3. **直接锚点恢复矩阵**
   - 数据：`q2_anchor_recovery_*`、`q2_final_top3_E112.csv`、E117 结果。
   - 形式：4 个直接锚点 × 边际/条件/图/最终四路，标命中/遗漏/排名；CO2 缺失单独标出。
   - 输出：`q2_validation_anchor_matrix.csv`。

4. **Top-3 删除敏感性**
   - 数据：`最终感官模型Top3删除敏感性.csv`（E115）与冻结 OOF。
   - 指标：删除 Top-1/2/3 后 ΔR²/ΔMAE，按目标/证据等级汇总。
   - 输出：`q2_validation_deletion_sensitivity.csv`。
