## 2. 统一指标口径

### 2.1 连续尺度指标

附件 4 是 50 个感官维度的标准化连续值。主评价在该尺度上逐目标计算 R²、MAE、RMSE、Spearman，再对 50 个目标作宏平均。R²和 MAE衡量数值拟合，Spearman衡量排序保持能力；三者不能互相替代。

### 2.2 BZD 可比的七级代理指标

BZD 的 Q1 A/C 方案把每个目标的真实值和 OOF 预测值分别按各自全样本的经验七分位数映射到 0—6，再计算 QWK、准确率和 ACC±1。该方法消除了真实值和预测值的边际分布差异，适合检查排序后的七档一致性，但存在两个限制：

1. 它不是从附件 4 唯一恢复的真实 0—6 原始评分；
2. 分箱边界使用完整 OOF 集合，只能作事后比较，不能用于新样本的部署映射。

为实现同口径比较，本队新增 `compute_q1_extended_metrics.py`，完全复现上述“各自分箱”定义；正式提交仍沿用训练折经验分布的单调映射，不把代理 QWK 写成真实评分准确率。

| 指标层次 | 指标 | 本队解释 | 是否用于替换 v1 的门槛 |
|---|---|---|---|
| 连续主指标 | R²、Spearman | 解释度与排序能力 | 是 |
| 连续误差 | MAE、RMSE | 标准化尺度误差 | 辅助，方向越低越好 |
| 有序代理 | QWK、ACC±1 | 独立七分位分箱后的事后一致性 | 是，但必须标“代理” |
| 部署量表 | 折内经验 CDF 的 0—6 连续等级 | 新样本可复算的相对强度 | 用于最终输出，不与 BZD 代理分数混称 |

### 3.2 值得吸收

1. **累积有序建模。** BZD B 在 Spearman 和 ACC±1 上有优势。可将附件 4 仅在训练折内分成七档，为每一阈值建立 HGB 二分类器，再通过单调累计概率解码；连续尺度预测仍需保留，以防代理等级掩盖幅度误差。
2. **风格中心化消融。** BZD C 虽总体性能不高，却直接回答“模型是否只记住风格”。本队应在固定外层折中，用训练折风格均值中心化 X/Y；未知风格回退全局均值，并与 E003 成对比较。
3. **多输出联合正则。** agent 的感官图拉普拉斯思想可以改造为折内构图的多任务 Ridge/ElasticNet 消融，图只由训练折目标相关矩阵构造，避免完整标签泄漏。
4. **多指标门控。** 不再只按单个 R² 决定模型，连续拟合、有序一致性和重复稳定性同时检查。

### 3.3 不应直接沿用

- agent 从列最小值、最大值和最小相邻差反推原始 0—6 标签，逆问题并不唯一，不能称为标签恢复；其全数据高斯条件插补、完整目标图和随机 KFold 会使验证偏乐观。
- BZD 的“真实七级”实为分位数代理，不能写成原始评分；若候选模型专门拟合该代理，其 QWK/ACC±1 必须与连续 R²共同报告。
- 图拉普拉斯项若由完整 50 目标相关矩阵生成，也会把验证标签结构带入训练；必须逐折重算。
- 现有样本仅 250，普通深 MLP、强化学习和无空间坐标的深度克里金均没有优先性。它们不进入本轮最小实验集。

### 3.4 本队差距与反超点

本队相对 BZD A 的 mean-OOF 提升为 R² +0.0280、MAE -0.0068、Spearman +0.0304、QWK +0.0323；相对 BZD B，Spearman高 0.0080、QWK高 0.0305，但 ACC±1低 0.0138。严格看 10 次重复均值时，本队 R²、MAE、Spearman、QWK仍优于 BZD A 的报道值，但不同重复次数导致的不确定性不可忽略。

本队的主要反超点不是单一均值，而是 10×3 固定外层折、折内清洗/选参、重复方差、逐目标结果和可部署量表被拆开记录。当前差距是尚未在同一拆分上完成累积有序、风格中心化和联合正则的成对实验。

### 4.1 方法与结果

### 4.2 值得吸收

- BZD A 的共表达模块是处理 231 个高度相关化合物的有效结构先验；可与本队训练折图和稳定模块结果互相验证。
- BZD B 的树模型 + SHAP/MDI 可作为归因敏感性，但正式排名必须使用 OOF 或训练折内的条件/分组置换，不能用全数据拟合后解释训练样本。
- BZD C 的稳定选择提供稀疏基线；在高度共线数据中应报告模块层稳定性，避免把“替代变量轮换”误判为完全不稳定。
- agent 的“网络路线与回归路线分开，再比较共识”值得保留，但本队应保证每个目标始终输出三项，并对弱证据目标明确降级。

### 4.3 不应直接沿用

- 把附件 6 自身同时作为选种和验证会形成内部循环；它只能证明算法复现官方相关矩阵，不能算外部验证。
- 直接在完整数据上构图、插补、偏相关或筛特征会泄漏。所有用于预测或排名选择的统计量均需在外层训练折重算。
- MDI 在连续变量、高基数变量及相关特征下有偏；单独作为 Top-3 依据不稳健。
- agent 空缺 Top-3 与题面“每个感官维度”冲突；复杂网络图不能弥补交付缺项。

### 4.4 本队差距与反超点

本队 E105 的连续预测强于 BZD B/C 报道值；稳定性频率低于 BZD B，原因之一是本队使用 218 个严格单化合物、500 次风格内 bootstrap、OOB 排名及多方法融合，筛选条件更严格，定义也不同。我们的优势是防泄漏、样式压力测试、固定 50×3 输出和化学证据分级；不足是 48/150 条仍处于 D 级，说明统计关联不能自动变成化学机理。Q2 后续优化应优先提高证据和模块解释，而不是只追求更高的 Top-3 频率。

## 5. 问题三对照

| 来源/方案 | 方法 | 主要报告结果 | 关键风险 | 可吸收部分 |
|---|---|---|---|---|
| BZD A | 按风格拟合 Gaussian copula，再采样和迁移 | 保真度 0.295；感官距离 0.768；迁移目标概率 0.363；缺陷合格 0.364 | Kriek 距离约 1.374，非线性/小样本拟合不足 | 透明、可采样，可作最低基线 |
| BZD B | 条件 VAE，潜变量 12，训练 1200 epoch | 保真度 0.617；感官距离 0.284；迁移目标概率 0.581；缺陷合格 0.364 | 多样性比约 0.49—0.53，存在收缩；缺陷改善有限 | 条件生成框架、分风格保真与多样性检查 |
| BZD C | WGAN-GP + 分位数校准 | 校准后保真度 0.573、感官距离 0.167；迁移距离 0.117；缺陷合格 0.364 | 未校准保真度仅 0.069，结果高度依赖事后校准 | 将生成质量拆成原始与校准后两层报告 |
| agent | 收缩高斯因子模型 + 高斯最优传输 + 缺陷投影 | 给出风格谱、迁移和缺陷约束图，无统一可比汇总表 | 依赖其 Q1 的不唯一等级重建；雷达图线多且难读 | 小样本下的收缩协方差、显式缺陷投影 |
| 本队 | 尚未正式实施 Q3 | 无结果 | 不得用 Q1/Q2 结果替代生成验证 | 计划从收缩 Gaussian copula/因子基线起步，再比较 CVAE；缺陷作为硬约束或投影，不使用 RL |

问题三现阶段不宜直接采用“校准后的最好数字”。所有模型必须同时报告：化学分布保真、样本多样性、代理感官画像、跨风格目标达成和五类缺陷不恶化率，并保留校准前结果。对 n=10—28 的目标风格，参数共享和收缩通常比直接训练 GAN 更稳妥。

## 7. 新 skill 的使用记录

新 skill 的 01—15 子目录大多采用同一套“输入—输出—假设—评价—复现—论文一致性”骨架。本次不是机械逐条套用，而是按任务选择如下规则：

| 目录 | 实际采用内容 | 采用原因 |
|---|---|---|
| 01 problem-analysis | 任务拆分、假设设计、baseline 设计 | 防止把连续预测、有序诊断和量表输出混为同一任务 |
| 02 data-processing | 缺失处理、特征工程、编码、归一化、重采样 | 明确所有统计量只在训练折估计；保持 250 行不因异常值删除 |

| 05 prediction | 线性/逻辑回归、随机森林等条目 | 将累积二分类视为有序候选，将 ExtraTrees 保留为强 baseline；神经网络仅筛查适用性 |
| 06 evaluation | 仅采用稳定性/敏感性检查清单 | 该目录主体是 AHP、TOPSIS、DEA 等综合评价模型，不适合本题监督预测，故未把其中算法用于 Q1 |

## 8. 后续实验的替换门槛

Q1 v1 的 E003 不因单次均值改善而替换。候选模型必须在相同的 10×3 固定外层折上满足：

1. R²、Spearman、代理 QWK、代理 ACC±1 四项中至少两项的 10 次重复均值优于 E003；
2. 改善在多数重复中方向一致，而不是依靠一个异常重复；
3. MAE 不发生实质性恶化，50 个目标的尾部性能和留一风格压力测试不明显退化；
4. 全部预处理、分箱、图结构和调参均在训练折内完成。

最小候选顺序为：累积有序 HGB、风格中心化 Ridge、折内感官图正则多任务 Ridge；多输出联合模型只有在前三者明确不足时再扩展。未达到门槛的结果进入“未采纳方案”，不改动 v1 数字。
