# Q3 E201 经验基线检查点

E113 首个有效外层检查点 R00F0 通过哈希和 `outer_train_fold` 范围核对后，启动 Q3 E201。Q1 v5 保持冻结，Q1 最终 OOF 只做身份和哈希核验，不重训。

E201 已完成30个固定外层折。每折在训练样本内完成中位数填补和尺度估计，比较三类基线：风格内经验重采样、同风格局部插值、风格均值退化控制；固定五个种子。真实—真实参考使用训练风格内不相交的同规模子集，样本不足时记 NA。结果、逐折 checkpoint、重复汇总和 manifest 位于 `03_结果/Q3_风格生成/q3_*_E201.*`。

当前不选择“最优”基线，也不生成 Q1 感官画像或化学迁移结论。经验重采样的近重复比例为1，说明它只是复制型参照；局部插值近重复比例为0，但仍需结合 W1、energy、覆盖、相关结构和风格间误差判断。Kriek 样本较少，距离指标波动较大，应报告不确定性而非按单项指标挑选路线。均值控制的相关误差在常数维度上不可计算，保留 NA。

E201 是分布基线，不代表真实感官安全，也不触发 Q3 复杂生成模型、迁移优化或 GPU 训练。后续先完成 E113 全部折审计；若 Q2 最终接口和支持域检查可用，再登记 Q3 画像接口与真实—真实对照。
