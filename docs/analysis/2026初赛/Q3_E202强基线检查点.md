# Q3 E202 强基线检查点

E202 已完成一个最小 R00F0 外层训练—验证 pilot，仅验证代码接口和统计输出，不启动正式全折实验、GPU或CVAE。入口条件为 E113 30折完成、E201完成、Q1最终NNLS OOF hash一致；pilot签名记录在 `q3_e202_pilot_decision.json`。

实现了两类强基线：按风格均值收缩的 Ledoit–Wolf 全维高斯，以及按风格经验边缘和秩高斯相关结构的 Copula。两者只用当前外层训练行拟合；Q1画像接口改为只读 `final_model_registry.json` 的感官组收缩NNLS OOF，不读取旧基线。

R00F0 的 pilot 仅用于暴露尺度与尾部风险：style_gaussian 的 W1/energy 在三种风格均明显受少数高方差字段影响，style_copula 的边缘距离较低但仍有大量地板维度和小样本不确定性。结果不能据此选择赢家；正式 E202 需要先决定训练尺度、地板状态和协方差正定策略，并保留真实—真实参考。当前 `formal_run_started=false`，没有生成感官画像、安全率或迁移结论。
