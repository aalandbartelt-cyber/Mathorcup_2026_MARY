## E200实际数据发现

| 项目 | 数量 | 用途 |
|---|---:|---|
| 样本/化学特征/感官目标/风格 | 250/231/50/22 | 与Q1契约一致 |
| log10/原尺度/尚未核验字段 | 37/33/161 | 未核验字段不擅自指数化 |
| 原始缺失 | 73单元 | 不进行全数据插补 |
| 正值对应不一致 | 80单元、32字段 | 保留两表值与来源，不能覆盖附件1 |
| 负参考值 | 3单元、2字段 | 标异常，不裁剪为零；与合法log10负值区分 |
| 异常合计 | 83单元、34字段、27款啤酒 | 进入逐条审计清单 |
| 源直接缺陷观测 | 44记录：33可比、9零/地板歧义、2缺失 | 是观测完整性，不能当模型约束通过率 |

70个字段可以识别存储尺度，并不意味着所有单元格逐元素一致。源啤酒四项都具完整对照观测的仅beer230；其他10款仍可提出统计候选，但未识别的源浓度不得写成真实“不升”认证。Stale hops始终单列感官预测风险。
