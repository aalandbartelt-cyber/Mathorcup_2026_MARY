## 2. Q1：有序回归与低秩补全

### agent2 做法与结果

- 以 28 个维度构造离散有序评分任务，使用共享低秩系数和维度特异系数；损失中同时加入有序交叉熵、连续辅助标签损失、感官图拉普拉斯、核范数和稀疏项。
- 对化合物特征加入稳健缩放、缺失指示、左删失指示和软阈值低秩补全；源码中用 Ridge 初始化低秩因子，再以 PyTorch/Adam 优化。
- 其分问文档选择“自然对数反变换”作为校准浓度处理；这与本队已固化的“1.csv 的 log10 字段保持原尺度、不重复取对数”不同。
- `q1/留一验证指标.csv` 报告：整体 336 个观测位置，Accuracy=0.913690，离散等级 MAE=0.232143，宏平均 F1=0.889411，QWK=0.912414；Aroma/Flavour 的 QWK 分别为 0.900277/0.924451。

### 可借鉴

1. 共享低秩 + 目标特异效应是小样本多目标任务的合理解释性消融，可在本队 50 个连续目标上实现为多输出 Ridge/ElasticNet 的低秩正则版本。
2. 缺失指示与左删失指示的分开编码值得保留；它们可以在本队折内中位数填补之外作为敏感性分析，检验检测限信息是否提供增量。
3. 有序模型可以作为代理量表诊断，不应替代连续回归。候选模型必须与 ExtraTrees 在同一 10×3 外层折上比较 R²、MAE、Spearman、代理 QWK、代理 ACC±1。

### 不借鉴及理由

1. 不采用 agent2 的自然对数反变换作为本题主口径：官方附件的 log10 字段已在当前 E000 数据契约中固定为原尺度，重复还原会改变特征含义。
2. 不把 0.913690 Accuracy、0.232143 离散 MAE 或 0.912414 QWK 写成本队预测精度；它们只覆盖 28 维的 336 个离散观测位置，和本队 50 维标准化连续目标不是同一任务。
3. 不直接复用其最终参数和完整评分矩阵。低秩补全、尺度参数、图结构和正则强度必须在本队外层训练折内估计，并通过既定多指标硬门槛才可晋级。

## 3. Q2：图拉普拉斯与稳定性选择

### agent2 做法与结果

- 以 2.csv 带符号共表达图构造图拉普拉斯；在三折划分上以预测误差与 Top-3 集合稳定性选择阈值，再把直接效应与邻域传播效应合成为重要性。
- 进行 30 次 bootstrap，并同时报告图正则模型与无图正则模型；`感官维度关键化合物Top3.csv` 共 84 行（28×3），`Bootstrap排名稳定性.csv` 共 1205 条记录，入选频率中位数 0.033333、最大值 0.633333。
- `模型验证对照.csv` 的 28 维平均结果为：图正则模型 Accuracy=0.985119、MAE=0.014881、R²=-0.070370；无图正则模型 R²=-0.082746。准确率很高但 R² 为负，表明离散标签极度稀疏/不平衡，Accuracy 不能作为主要预测证据。
- 名称匹配覆盖率为：1.csv/2.csv/6.csv 均 100%，8.xlsx 为 231/261=88.5057%。

### 可借鉴

1. “预测误差 + Top-3 稳定性”联合选图阈值的思路可加入本队 Q2 消融，但阈值、图拉普拉斯和传播权重都必须在每个训练折/重采样内重算。
2. 直接效应、邻域传播、社区归属和交叉相关方向放在同一条证据链中，有助于把单个化合物降级为“模块代表节点”，避免过度因果化。
3. 图正则与无图正则成对比较可作为本队 E111/E112 的结构化消融，但仍须保持 50×3 完整输出。

### 不借鉴及理由

1. 不用 0.985119 Accuracy 证明图模型优于本队；其 R² 为负且标签口径不同，需优先报告连续 OOF 和稳定性指标。
2. 30 次 bootstrap 不足以替代本队 500 次风格内 bootstrap；本队的频率、OOB 排名和四镜头 Jaccard 继续作为主证据。
3. 28×3 输出和 8.xlsx 88.5% 化学属性覆盖不能满足题面 50 个感官维度逐一 Top-3 的交付要求；缺失证据只能降级，不能由网络图补齐。

## 4. Q3：图约束条件 VAE 与迁移安全

### agent2 做法与结果

- 采用 PyTorch 条件 VAE（潜变量 12、隐藏层 128），条件为风格标签；损失包括观测重构、左删失、KL、图平滑、风格判别和综合属性约束。
- 三折交叉验证的观测位置重构 MAE 为 1.222805、1.308407、1.212321，风格判别准确率均为 1.00，左删失违反率为 0.544803、0.507519、0.545788。
- Tripel/Kriek/Lambic 各生成 80 条，目标风格一致率均 1.00，MMD 分别为 0.427827、0.736371、0.782607。
- Pils/Lager→Tripel 迁移的目标风格一致率为 1.00，但缺陷不恶化率仅 0.309091，迁移约束违反 39 条；完整模型消融中移除缺陷安全约束后不恶化率为 0.145455。

### 可借鉴

1. GPU 可用于条件生成、重复采样和迁移优化；但 GPU 只解决计算效率，不改变小样本泛化和口径问题。
2. 左删失约束、图平滑和风格判别可以作为生成模型的候选损失项；生成后还应增加显式可行域投影/拒绝采样。
3. 将风格一致、化合物分布、感官画像和缺陷安全分开报告的结构值得保留。

### 不借鉴及理由

1. 不以风格一致率 1.00 作为晋级标准；左删失违反率约 0.51—0.55，说明生成谱仍大量越过检测边界。
2. 不接受缺陷不恶化率 0.309091 作为题面约束的“满足”；五类缺陷必须逐条检查，硬投影/可行域筛选后仍需报告违反数与覆盖率。
3. 不直接把 agent2 的全量预处理、图阈值和感官映射迁移到本队；所有统计量应按生成训练折估计，并保留小风格样本的收缩/参数共享策略。

## 5. 对本队主线的影响

- **不改变 E004—E008 顺序和硬门槛。** agent2 仅增加一个对照组，不覆盖 E003，也不改变正在进行的 E006。
- Q1 后续若实现低秩/有序消融，必须在固定 10×3 外层折上至少两项主指标稳定改善，且 MAE 不实质恶化；否则只记录为未采纳方案。
- Q2 保持 50×3、折内图构造、500 次风格内 bootstrap 和统计/化学证据分级。
- Q3 先用收缩 copula/因子基线建立可审计的硬约束流程，再决定是否使用 GPU 条件 VAE；GPU 不作为模型选择理由。
