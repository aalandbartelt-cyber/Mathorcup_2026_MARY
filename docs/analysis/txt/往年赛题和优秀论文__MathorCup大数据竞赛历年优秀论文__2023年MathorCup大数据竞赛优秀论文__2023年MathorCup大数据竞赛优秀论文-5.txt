基于特征融合与集成学习的电商供应链分层预测方法
摘要
需求预测往往是电商平台智能供应链的决策基础，它可以让管理者提前预知各地的
需求，从而将库存提前放在靠近需求的仓库中，显著地降低库存成本，同时保证商品的
按时履约。本文对各商品的历史出货量数据进行挖掘与分析，构建了基于数理特征与专
家经验的多模型集成预测框架，旨在协助电商平台优化库存管理，更好地规划和定制促
销活动，提高库存周转率。
针对问题一，需要对商品序列进行分类并预测未来需求量。本文首先根据附件数据
构建全体需求量序列集。考虑部分字段信息覆盖了功能场景、仓库区域等组成的先验分
类知识，先基于8 个字段特征进行第一层级分类。然后，采用K-means 算法对第一层级
类别进行细化聚类，建立9 个不同尺度的分类标准。针对预测问题，本文提出了一种基
于自顶向下和分层聚类的集成预测方案。首先，基于9 个分类标准获得各类别下总的需
求量序列。然后，基于特征工程构建各类别汇总序列的特征集，分别采用指数平滑、Auto
ARIMA、XGBoost、LightGBM、LSTM 等5 个算法对各分类标准各类别下的总需求量
序列构建预测模型，并设计合适的指标评估各算法的优劣。最终，采用9 个分类标准下
的模型预测值的集成量作为最后的预测输出，结果表明融合后的模型获得更高的
1-WMAPE 指标且预测更为稳定。
针对问题二，需要预测新出现序列组合的未来需求量。首先，将附件1 与附件5 的
数据整合（2206 条），对所有组合截取等维长度的序列并提取数理特征，并将构建的数
理特征与独热编码后的8 个解释变量特征汇整，采用K-means 算法对所有实例进行聚类
（2206 条序列聚为14 类）。然后，设置滑动窗口对聚类后的各类别序列进行特征提取和
样本集构建，采用SVM、XGBoost、LightGBM、LSTM、KNN 算法分别训练预测模型，
基于5 折交叉验证法调整模型参数并评估算法性能。在预测阶段，首先对待预测实例进
行分类，采用类别下的5 个模型预测值的集成量作为最后的预测输出，结果表明集成后
预测模型可以挖掘出更为显著的相似序列特征，实现对新组合的精准预测。
针对问题三，需要预测规律性大型促销活动期间各商品的未来需求量。首先，提取
附件1 中各商品每月1 日-11 日的出货量数据（共5 个月）组成日常序列，并将各商品
以月为基准取均值得到日常均值序列。提取附件6 中各商品1 日-11 日的出货量数据组
成促销序列。然后，根据日常均值数据与促销数据计算各商品的促销力度值，基于问题
一提出的集成预测框架对各商品在6 月1 日-6 月20 日的日常值进行预测。最后，将预
测结果与对应的促销力度值求积，得到最终的促销预测值，结果表明构建的事件影响模
型可以分析出促销活动期间商品序列的波动规律，使预测值更符合促销期间的实际情况。
关键词：特征融合；集成学习；分层时序预测；LightGBM；K-means；LSTM

1 问题重述
1.1 问题背景
电商平台存在着上千个商家，他们会将商品货物放在电商配套的仓库，电商平台会
对这些货物进行统一管理。通过科学的管理手段和智能决策，大数据智能驱动的供应链
可以显著降低库存成本，同时保证商品的按时履约。需求预测往往是智能供应链的决策
基础，它可以让管理者提前预知各地的需求，从而将库存提前放在靠近需求的仓库中，
此时的预测任务为：根据历史一段时间的需求量，预测各仓库中各商品未来需求，“预
测维度”即为不同商家在各仓库中存放的各种商品每天的数量。一般来说，企业会首先
根据数据的历史情况，分析出需求量序列的数理特征，对相似的需求量序列进行归类，
并根据分类结果做到更加精准的预测。
然而，在实际的电商供应链预测任务中，常常会出现多种不同的问题。例如，部分
商品的销售时间过短、仓库存在新增或切换等情况，导致该预测维度下历史数据过少；
另外，部分大型促销期间货量的陡增并由此带来的不规律性，也给需求量的精准预测带
来了不小的难度。此时便需要通过算法得到历史一般规律，找出相似的历史情况（如相
似的仓或商品），从而实现精准预测。

6 问题二模型建立与求解
问题二主要涉及预测任务。相对于问题一，主要是出现了新的商家+仓库+商品维度，
这些实例主要有以下特征：1）出货量序列信息不一致，部分实例由于是新上市或改变
了原先存放的仓库，导致不同序列长度不一致；2）出现了新的第一层级类别，使得难

# 函数：计算1-WMAPE
def compute_wmape(y_true, y_pred):
assert len(y_true) == len(y_pred), "y_true and y_pred must have the same length"
return 1 - np.sum(np.abs(y_true - y_pred)) / np.sum(y_true) if np.sum(y_true) != 0 else 1 -
np.count_nonzero(y_pred)/len(y_true)
def compute_rmsse(y_true, y_pred, y_train):
# Find the index of the first non-zero demand
start_index = np.argmax(y_train > 0)
# If no non-zero demands are found, start from the beginning
if start_index == 0 and y_train[start_index] == 0:
start_index = 0
# Adjust y_train to consider only periods after the first non-zero demand
adjusted_y_train = y_train[start_index:]
numerator = np.sum((y_true - y_pred) ** 2)
denominator = np.sum((adjusted_y_train[1:] - adjusted_y_train[:-1]) ** 2) / (len(adjusted_y_train) - 1)
if denominator == 0:
return np.inf
return np.sqrt(numerator / denominator)
# 函数：计算MAPE
def compute_mape(y_true, y_pred):
y_true_adjusted = np.where(y_true == 0, 0.1, y_true)
# 使用np.where 将y_true 中的0 替换为0.1
return np.mean(np.abs((y_true - y_pred) / y_true_adjusted)) * 100
# 函数：计算RMSE
def compute_rmse(y_true, y_pred):
return np.sqrt(mean_squared_error(y_true, y_pred))
