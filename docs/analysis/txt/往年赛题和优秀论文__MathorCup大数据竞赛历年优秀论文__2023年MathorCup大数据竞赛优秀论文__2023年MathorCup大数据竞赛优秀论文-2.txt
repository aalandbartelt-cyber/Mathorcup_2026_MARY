基于预训练的DenseNet-121 模型的坑洼道路检测识别 
摘 要 
本文主要建立了一个预训练的计算机视觉模型，对坑洼道路进行有效的检测。首先
对题目给出的数据集进行数据清洗和分析图像特征，再从CNN 中选取四个较为典型的
预训练模型进行分别训练，检测，并选出最优、最适合本题的DenseNet-121 模型进行训
练和多维度评估，并最终对题目给出的数据集进行检测。 
针对问题一，对训练数据集进行数据清洗，重新分类错误图片，像素统一处理为
224×224 大小，之后进行7:3 的训练集和验证集的划分，并提取图像的特征信息。由于
题目给出的数据集过少，传统网络模型易出现过拟合现象，会消耗大量计算资源和时间，
故本文选用经典的VGG16、DenseNet-121、GoogLeNet 和ResNet-50 模型分别训练，对
四种模型从多角度分析评估，得到DenseNet-121 模型的准确率达到99.34%，平均迭代
时间为16.02s，综合评价为四种模型中最佳，故选用DenseNet-121 模型进行后续的训
练与预测。在建立DenseNet-121 模型时，首先引入随机种子，加载训练好的参数，对图
像进行数据增强处理，以提高模型的泛化能力；冻结模型的权重，以防止预训练的权重
被破坏，并添加一个具有128 个神经元和ReLU 激活函数的全连接层进行二分任务，完
成DenseNet-121 模型的建立。 
针对问题二，对问题一建立的DenseNet-121 模型进行训练和评估。本文从准确率、
损失函数、训练速度和鲁棒性等维度进行训练评估。首先测试模型的准确性，将训练好
的模型对训练集进行预测，得到了99.34%的准确率，绘制并观察ROC 曲线，得到AUC
面积为0.98，模型性能良好；之后为测试模型的泛化能力，我们下载了新的681 张图片
进行预测，发现对于新的数据集模型仍可达到96.34%的准确率；记录模型的训练耗时
信息，得到平均迭代时间16.02s；最后，对图像数据加入扰动，对比其扰动前和扰动后
模型的损失率和准确率，发现在50 次的迭代次数下仍可快速的趋于稳定，模型鲁棒性
较高，具有识别率高、速度快、分类准确的特点。 
针对问题三，将新的数据集同样统一处理为224×224 的像素大小，在处理中，发现
名为guy7iodk.jpg 的图像无法识别，将其剔除。之后进行特征提取并利用问题二中训练
好的模型进行检测，检测过程中生成随机16 张图像与检测结果作为可视化示例，将结
果存储到test-result.csv 文件中，通过统计发现共有1256 张图像检测为正常道路，其余
3685 张图像为坑洼道路。

一、问题重述 
1.1 问题背景 
坑洼道路检测和识别是一种计算机视觉任务，旨在通过深度学习技术来识别道路上
的坑洼，对于地质勘探、航天科学和自然灾害等领域的研究和应用具有重要意义。传统
方法在处理复杂和多变的坑洼图像特征时效果有限，近年来深度学习技术的发展，为坑
洼道路检测提供了新的解决方案。深度学习能够提取坑洼的重要特征，并将其转化为更
易分类的表示形式。研究者可以使用深度学习方法分类道路图像，也可利用迁移学习来
提高性能。要求我们进行分析、特征提取和建模已标记的道路图像，以实现对新道路图
像坑洼状态的自动识别。 
1.2 问题重述 
基于上述问题背景我们需要建立模型解决如下具体问题： 
针对问题一，题目要求从提供的图像文件中，使用图像特征提取技术构建一个高准
确率、高速度的模型，用于识别道路图像是正常还是有坑洼。 
针对问题二，题目要求对构建的模型进行训练，从不同维度进行综合的模型评估。 
针对问题三，题目要求利用已经训练好的模型，对测试集中的坑洼图像进行识别，
并将识别结果保存在"test_result.csv"文件中。

保模型具有高学习效率，且避免过拟合，本文选择预训练模型对测试集进行训练，选取

各个模型的不同指标，最终选择最优的模型进行建立并用于图像识别任务。

5.1.4 数据集划分 
为准确评估模型的性能并防止过拟合，我们采用数据集划分的方法，将数据按7:3
比例分为两个部分：训练集和验证集，即70%的数据训练模型，余下的30%用于验证模
型的性能。 
我们使用Python 的Scikit-Learn 库中的train_test_split 函数来执行数据集划分，将
数据集分成训练集和验证集，并严格按照7:3 的比例划分，并设置stratify 参数，以确保
在划分过程中各个类别的样本保持相对均衡。 
5.1.5 数据增强 
数据增强是通过对原始图像进行随机变换来增加数据样本多样性的一种技术，用于
提高深度学习模型的性能和泛化能力。 
我们使用Python 中TensorFlow 中的ImageDataGenerator 类来实现数据增强。以下
是数据增强具体参数设置： 
•旋转范围：最大旋转角度为20 度，模拟不同拍摄角度的道路图像。 
•宽度位移范围：最大位移范围为图像宽度的20%，增加位置多样性。 
•高度位移范围：最大位移范围为图像高度的20%，增加位置多样性。 
•剪切范围：最大剪切范围为20 度，增加图像的形状多样性。 
•缩放范围：最大缩放范围为20%，模拟不同距离和尺度的道路图像。 
•水平翻转：以50%的概率对图像进行水平翻转，增加图像对称性的多样性。 
参数设置在数据增强过程中引入了随机性，并增加训练数据的多样性，确保后续模
型能够更好地适应不同场景下的道路图像，从而提高模型对坑洼道路检测和识别的能力。 
5.2 CNN 模型的建立 
卷积神经网络（Convolutional Neural Network，CNN）是一种深度学习模型，广泛应

用于计算机视觉领域的图像分类、目标检测、图像分割和生成等任务[1]。CNN 由卷积层、
汇聚层和全连接层等组件构成，能够学习和提取图像的特征。CNN 通过层层堆叠，从低

5.2.1 不同神经网络的对比与选择 
数据集的规模通常是影响机器学习和深度学习任务的模型性能和泛化能力的重要
因素之一。由于题目给出的301 张测试集相对较少，易导致模型在训练过程中出现过拟
合，泛化能力下降、学习能力不足等问题。因此，我们采用预训练好的模型进行训练，
在卷积神经网络中有多种预训练好的网络模型，例如牛津大学提出的VGG 模型、微软
研究院提出的ResNet 模型、康奈尔大学的DenseNet 模型和Google 团队提出的
GoogLeNet 模型。 
首先，为保证实验的可复现性和结果的一致性，在每个模型训练前先加入随机种子
42，之后对图像数据集进行统一处理，将像素大小调整为224×224。批处理样本数被设
置为32，模型的架构为一个128 个神经元和ReLU 激活函数的全连接层，以及一个具有
1 个神经元和Sigmoid 激活函数的输出层，用于二分类任务。最后，我们选取数据集的
70%作为训练集，30%作为测试集进行训练，并进行50 次的迭代训练。 
下面将对这四种重要的模型进行多维度的比较，以确定最适合题目提供的数据集类
型的网络模型。 
（1） VGG16 (Visual Geometry Group 16) 
VGG16 模型使用了较小的3x3 卷积核进行特征提取。通过堆叠多个小卷积核，
VGG16 能够捕捉不同尺度的特征，并提高模型的表达能力。然而，相对于更大的卷积
核，VGG16 的参数数量较多。由于该模型的简单结构和良好的性能，它在图像分类和特
征提取任务中被广泛使用。VGG16 在多个图像识别挑战中取得了很好的结果，并成为
了深度学习领域的经典模型之一[3]。

八、模型的评价、改进与推广 
8.1 模型的优点 
（1）本文基于多个角度进行模型对比，得到DenseNet-121 模型具有出色的性能，
能够实现更高的准确率，识别速度和分类准确性，尤其在有限的数据集上 
（2）DenseNet-121 模型采用密集连接，每一层都与前面的所有层相连接，有助于
梯度传播和特征重用，减少了梯度消失问题。 
（3）由于密集连接的特性，DenseNet-121 模型对于小型数据集更具鲁棒性，更不
容易过拟合。 
8.2 模型的缺点 
（1）DenseNet-121 模型的计算和内存需求相对较高，资源有限的环境下运行困难。 
（2）由于其深度和连接密集性，且训练数据集较小等因素，DenseNet-121 模型的
训练时间可能较长，需要更多的计算资源。 
8.3 模型的改进 
DenseNet-121 模型在训练过程中可以引入更多图像数据，提升训练效果和准确率，
并可以通过分布式训练进一步加速训练过程，以减少训练时间。 
8.4 模型的推广 
本文主要建立的预训练的DenseNet-121 模型不仅适用道路坑洼识别等图像分类任
务，还可推广到目标检测、图像分割、视频分析等多个计算机视觉领域[6]。且DenseNet
的思想也可应用于自然语言处理和语音识别等其他领域，以及自动驾驶、医学影像分析
等领域，以改进模型性能和泛化能力，对提高机器学习模型的效率和性能具有重要意义。

import pandas as pd 
from sklearn.metrics import roc_curve, roc_auc_score 
import matplotlib.pyplot as plt 
 
# 读取CSV 文件，将预测结果和真实标签加载到DataFrame 中 
df = pd.read_csv('E:\Acode\\ans.csv') 
y_true = df['True Labels']  # 将'真实标签'替换为实际的真实标签列名

y_scores = df['Predicted Labels']  # 将'预测概率'替换为实际的预测概率列名 
 
# 计算ROC 曲线的假阳性率和真阳性率 
fpr, tpr, thresholds = roc_curve(y_true, y_scores) 
 
# 计算AUC 面积 
auc = roc_auc_score(y_true, y_scores)

plt.xlabel('False Positive Rate') 
plt.ylabel('True Positive Rate') 
plt.title('Receiver Operating Characteristic (ROC) Curve') 
plt.legend(loc='lower right')
