基于计算机视觉的坑洼道路检测和识别 
摘 要 
坑洼道路检测和识别是地质勘探、航天科学和自然灾害等领域一项重要研究，快速
精准识别道路坑洼状态对分析和模拟道路形态具有重要意义。本文针对坑洼道路检测和
识别问题，基于改进超分辨率生成对抗网络和改进YOLOv8 检测网络建立识别模型，
依据训练收敛性和检测精度等维度对识别模型进行评估。 
针对问题一，首先选取超分辨率生成对抗网络获得虚拟特征以解决训练样本数量少
的问题，加入空间和通道注意力机制引导生成器特征生成接近真实特征的道路坑洼特征
图，使用图像分块对待训练的图像进行分块和重组，在提升图像占比的同时保留中心目
标点。然后选取YOLOv8 检测网络作为目标检测的基础框架，利用深度卷积神经网络改
进检测网络中的卷积核，引入双路径注意机制以提升检测网络对目标的关注度，采用共
线方程和高斯滤波提取坑洼道路边缘特征，利用特征增强模块连接多通道特征值以生成
待检测的特征图，进而增强网络的特征提取能力，再将得到的特征图输入值道路检测网
络实现特征提取与目标检测，针对检测过程中目标丢失的问题，在已有IoU 损失函数的
基础上采用CIoU 调整检测过程中存在的损失函数，进一步提升坑洼道路的检测精度。
通过级联改进超分辨率生成对抗网络和改进YOLOv8 网络最终建立坑洼道路检测和识
别模型，级联后的算法将达到快速、高精度目标检测与识别。 
针对问题二，基于问题一所建立的模型进行参数训练，分别选取SGD 和Adam 优
化器对模型参数进行分组优化，得到损失小和精度高的最佳权重，基于最佳权重值以实
现模型评估和验证。本文从模型收敛性和检测精度两个维度对模型进行评估，选取训练
损失、准确率、精确率、召回率、F1 分数和mAp 等指标评估模型性能，对设计的检测
模型进行消融实验和横向对比实验。实验结果表明，经SGD 优化的检测模型相较于
Adam 优化后的模型可以达到更快的收敛，且精度较高。加入注意力机制和深度卷积核
可明显提升模型性能，在消融实验中改进后的YOLOv8 模型与基准YOLOv8 相比，精
度提升了10.9%，mAp.5 提升了14.2%，mAp.5:.95 提升了12.2%，在横向对比实验中改进
后的YOLOv8 准确率高于其他检测模型，相较于基准YOLOv8 精度提升了12.23%，验
证了所建立模型的有效性，且通过模型剪枝的方式降低了器参数量，实现了模型轻量化，
因此基于改进超分辨率生成对抗网络和改进YOLOv8 的坑洼道路检测模型可以达到较
高精度的目标识别。 
针对问题三，在问题一模型和问题二权重的基础上，利用测试数据进行模型验证，
将测试图像输入至检测模型中得到识别结果，识别结果表明，4942 张测试图片中坑洼道
路有4045 张，正常道路有897 张，在坑洼道路图片中，对坑洼位置识别置信度在80%
以上的图像有2597 张，仅有68 张图片识别置信度小于50%，但具有坑洼特征的测试图
像均已识别，说明识别结果的有效性。检测结果表明，利用问题一建立的模型不仅可以
精确识别单个坑洼目标，还可以识别多个坑洼目标，且具有对遮挡、重叠、远距离、模
糊小目标的检测能力，表明本文坑洼道路模型的有效性与泛化性。 
 
 
关键词：YOLOv8；超分辨率生成对抗网络；注意力机制；特征增强；特征生成

一、问题重述 
1.1 问题背景 
坑洼道路检测和识别作为一种计算机视觉任务，可以通过数字图像（通常是地表坑
洼图像）识别出存在坑洼的道路。这对于地质勘探、航天科学和自然灾害等领域的研究
与应用具有重要意义，可以帮助在地球轨道上识别坑洼，以及分析和模拟地球表面的形
态。但在坑洼道路检测任务中，图像特征是复杂多变的，传统的分类算法往往不能取得
较好的效果，而深度学习技术的发展为坑洼道路检测提供了新的解决方案。 
深度学习因其具有很强的特征提取和表示能力，可以从图像中自动提取出重要特征，
利用深度学习可以在坑洼图像分类任务中提取到坑洼的轮廓、纹理和形态等特征，并将
其转换为更为容易分类的表示形式，同时可通过迁移学习和知识蒸馏等技术进一步提升
分类性能。 
1.2 任务目标 
基于计算机是绝对阿坑洼道路检测和识别需要通过对已标记的道路图像进行分析、
特征提取与建模，进而自动识别新道路图像的坑洼状态。 
问题一：结合附件图像文件，提取图像特征，建立识别率高、速度快、分类准确的用于
识别图像中道路状态的模型。 
问题二：对问题一中构建的模型进行训练，并从不同维度进行模型评估。 
问题三：利用已训练的模型识别测试集中的坑洼图像，并保存识别结果。 
二、问题分析 
针对问题一，需要结合附件中的图像文件，提取图像特征并建立识别率高、快速、
分类准确的模型，通过对附件数据进行量化分析，拟选取改进超分辨率生成对抗网络进
行特征生成以扩充特征图，在超分辨率生成对抗网络的基础上引入通道和空间注意力机
制以实现对目标特征的精准提取，利用生成对抗网络结构生成接近真实数据的坑洞特征。
拟选取改进的YOLOv8 检测网络实现道路检测识别，引入双路径注意机制和特征增强
模块提升特征分解精度，将共线方程与高斯滤波结合实现对真实图片的坑洼边缘特征提
取，然后利用检测网络对特征图进行识别以完成目标检测，引入CIoU 提升最终的检测
精度，进而建立了基于计算机视觉的坑洼道路检测和识别模型。 
针对问题二，需基于问题一所建立的模型进行训练，并从不同维度进行模型评价，
拟分别选取SGD 和Adam 优化器对模型参数进行分组优化，进而获得最佳权重值以实
现模型评估和验证。拟选取训练损失、准确率、精确率、召回率、F1 分数和mAp 等指
标评估模型性能，从模型收敛性和检测精度两个维度进行评估，并对设计的检测模型进
行消融实验和横向对比实验。因此基于改进超分辨率生成对抗网络和改进YOLOv8 的
坑洼道路检测模型可以达到较高精度的目标识别。 
针对问题三，在问题一模型和问题二权重的基础上，利用测试数据进行模型验证，
将测试图像输入至检测模型中得到识别结果，进而验证本文坑洼道路模型的有效性。

六、问题一模型建立与求解 
6.1 问题一分析 
基于深度学习的图像分类算法以卷积神经网络作为图像特征提取网络，基于预先设
定的卷积核和图像特征矩阵进行卷积计算，进而对图像目标进行特征提取，最终可以得
到不同维度的纹理、色彩和几何等图像特征。 
基于视觉对道路坑洼进行分类，在各种照明场景下，物体在形状、比例和阴影方面
往往会存在较大的差异，通常带有高度复杂的背景（如存在遮挡、目标不清晰等）会对
图像分类造成干扰，因此需要具有鉴别细节、模糊、隐藏特征能力的模型对各种场景下
的坑洼道路进行识别。 
针对道路坑洼图像特征复杂且环境多变的难点，本文建立了基于改进YOLOv8 和
超分辨率生成对抗网络级联的坑洼道路识别模型。模型首先通过，并结合共线方程和高
斯滤波边缘检测细化坑洼目标的边缘粒度，进而在YOLOv8 的基础架构上得到改进的
YOLOv8 检测算法。其次针对坑洼目标特征不足的问题，引入改进的超分辨率生成对抗
网络对目标进行特征生成，并引入CBAM 机制提升生成网络对坑洼目标的关注度，使
用重叠分块对图像进行分块与重组，将特征生成网络与检测网络进行级联以达到高识别
率、快速、分类准确的目的。针对问题一有待解决的问题，本文绘制了如图5 所示的问
题分析框架图。

6.2 基于改进超分辨率生成对抗网络的特征生成模型 
针对数据集较少的问题，本文通过引入虚拟特征来增强目标特征数据集，基于增强
型超分辨率生成对抗网络架构，加入空间注意力对图像进行超分辨率处理，以达到补充
图像特征集的目的，同时提高模糊图像在训练过程中的分辨率。 
生成对抗网络由生成网络和判别网络组成，通过互相学习和博弈的方法实时调整判
别网络参数，最终使得判别网络无法判断生成网络的输出结果的真实性，本模型则通过
引入超分辨率生成对抗网络（Super-Resolution Generative Adversarial Networks, SRGAN）
生成目标特征[1]，在原有特征数据集的基础上提取更多符合实际坑洼道路的特征。

对抗网络的基本单元，每个连接层会以历史输入层的结果作为额外输入结果以达到稠密
连接。

九、模型评价 
9.1 模型优点 
9.1.1 问题一优点 
1）采用改进的超分辨率对抗生成网络以特征生成的方式在原有数据集的基础上扩
充目标特征图，基于生成网络和对抗网络可以得到接近于原始图像的特征图，采用注意
力机制增强道路坑洼目标与环境的耦合性，进而提升了生成特征值的置信度。 
2）采用改进的YOLOv8 检测网络以实现快速识别、高精度检测分类的效果，通过
改进深度卷积网络，加入增强特征模块和Canny 边缘检测达到对道路坑洼位置的高精度
检测。 
3）采用模型图像分块和模型剪枝的方法降低整个检测网络的参数量，在原有基础
上实现轻量化。 
9.1.2 问题二优点 
1）针对问题一提出的检测模型，通过多个评价指标从收敛性和精度等维度进行评
估，且具有达到较好的评价效果。 
2）通过消融实验验证了模型改进对检测精度的提升，并通过与多种检测算法的对
比，验证了改进YOLOv8 模型的高精度。 
9.1.3 问题三优点 
基于问题一检测模型与问题二的预训练权重得到测试集下的检测结果，保持了整体
建模的连贯性，模型可以准确识别坑洼道路，且多数目标可以达到80%以上的置信度。 
9.2 模型缺点 
 
虽然本文建立的模型具有较高的检测精度，但不免存在一些问题，可以从以下方面
进行考虑。 
 
1）本文提出的检测模型由于训练样本数量少，基于特征生成的方式扩充目标特征仅
仅适用于小样本权重，后续可考虑增加训练样本数，进一步提升模型精度。 
2）由于自然场景中的图像较为复杂，获取的图像可能存在低分辨率、重复遮挡等情
况，对多个目标的检测精度还有待提升，可以考虑优化模型结构，提高多目标检测的置
信度。

def convert_annotation(year, image_id, list_file): 
    in_file = open(os.path.join(VOCdevkit_path, 'VOC%s/Annotations/%s.xml'%(year, image_id)), encoding='utf-8') 
    tree=ET.parse(in_file) 
    root = tree.getroot() 
 
    for obj in root.iter('object'): 
        difficult = 0  
        if obj.find('difficult')!=None: 
            difficult = obj.find('difficult').text 
        cls = obj.find('name').text 
        if cls not in classes or int(difficult)==1: 
            continue 
        cls_id = classes.index(cls) 
        xmlbox = obj.find('bndbox') 
        b = (int(float(xmlbox.find('xmin').text)), int(float(xmlbox.find('ymin').text)), int(float(xmlbox.find('xmax').text)), 
int(float(xmlbox.find('ymax').text))) 
        list_file.write(" " + ",".join([str(a) for a in b]) + ',' + str(cls_id)) 
         
        nums[classes.index(cls)] = nums[classes.index(cls)] + 1
