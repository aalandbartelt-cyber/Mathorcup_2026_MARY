基于数据挖掘的电商品类货量预测与分仓规划研究
摘
要
在现代商业环境中，仓库的运营往往被看作是日常运作中不可或缺的一部分。本文
对品仓分类问题进行了深入研究，从问题深度来说，将问题分解为：精准预测货量；根
据货量预测结果进行“一品一仓分仓方案”的规划；对于新增维度下的“一品多仓分仓
方案”的规划。
针对问题1：对于如何精准预测货量。首先进行数据清洗，利用Pandas 中isnull 方
法查询缺失值，利用四分位距检测异常值，并采用多项插值法替换出现的异常值。然后
基于附件1 和附件2 的相关数据，以80%的数据为训练集，以20%的数据为测试集依次
构建随机森林模型、XGBoost 模型、灰色预测模型、BP 神经网络和LSTM 神经网络，
得到五个模型的训练集真实值、测试集真实值、各模型预测值、各模型MAPE 值以及各
模型评估参数对比。最后选择LSTM神经网络预测月库存量，其中精确度达0.836，MAPE
值为0.011；BP 神经网络预测日销量，其中精确度达0.814，MAPE 值为0.013，预测结
果见附件1 中的result 表格。
针对问题2：根据货量预测结果进行“一品一仓分仓方案”的规划。首先需要对附
件3 中的数据进行预处理，将问题1 所得每天销售量的数据集按每月进行归类。可将问
题2 进行简化，即将“一品一仓”问题抽象成0-1 规划问题。然后根据题目的要求综合
考虑多个业务目标并确定约束条件，从而建立“一品一仓”方案模型。最后基于附件3
的相关数据，采用分枝定界法利用Lingo 软件以及SCIP 求解器进行求解，直至容差界
限小于0.001，此时用时86 秒，迭代次数3941 次，说明了该算法在求解过程中的高效
性和稳定性，预测结果见附件1 中的result 表格。
针对问题3：对于新增维度下的“一品多仓分仓方案”的规划。首先基于问题一中
所得“月库存预测结果”和“日销量预测结果”两个工作表的数据，读取题中所给的附
件3、附件4、附件5 相关数据，构建品类关联度矩阵，并对各指标设置权重系数。接
着建立目标函数，最大化仓库中品类的关联度，通过添加松弛变量并在目标函数中给予
惩罚权重，确定约束条件。然后分别建立多目标模拟退火算法和多目标粒子群优化算法，
通过对比两个算法的收敛图效果，最后选取多目标粒子群优化算法，预测结果见附件1
中的result 表格中。
关键词：电商品类；分仓规划；LSTM 神经网络；BP 神经网络；分枝界定法；多目标
粒子群优化算法

1 问题重述
1.1 问题背景
进入21 世纪，随着互联网技术的快速发展和普及，中国的电子商务平台如雨后春笋
般崭露头角。历经二十余载的迅猛发展，电子商务产业已成功构建起一个规模宏大、结构
健全的产业体系。如今，电子商务平台不仅颠覆了传统的商业运作模式，更在潜移默化中
重塑着人们的消费观念与生活方式。与此同时，随着民众生活质量的稳步提升，消费观念
亦在悄然演进。消费者对于商品的需求，已从往昔单纯注重经济实用性，转向追求更为个
性化与多元化的体验。他们不再仅仅满足于商品的基本功能，而是更加注重商品所蕴含的
文化底蕴与所展现的品牌形象价值。这一消费观念的转变，促使电商企业必须更加敏锐地
捕捉市场动态，提供丰富多样、高度个性化的商品与服务，以满足消费者的多元化需求。
然而，随着电商业务的蓬勃发展，库存管理问题逐渐浮出水面。品类分仓规划决定各
商品存放在哪些仓库问题，合理的品类分仓规划对提升每个仓的管理效率、降低总体仓储
成本至关重要，这给电商公司的库存管理带来了极大的挑战。库存管理的优化不仅关乎到
公司的成本控制，更直接影响到公司的市场竞争力和长期发展。库存作为电商业务的核心
环节之一，其管理策略直接关系到企业的运营效率和经济效益。然而，在现实中，由于商
品种类繁多，且每种商品的数量可能也很大，因此需要将这些商品合理地分配到不同的仓
库中进行存储，如图1 所示。首先，合理的品类分仓规划可以提升每个仓库的管理效率。
其次，合理的品类分仓规划还可以降低总体仓储成本。许多电商企业往往面临库存计划不
精准的问题，导致短缺与积压并存。消费者需要的商品缺货，而不需要的商品却积压过多。
这种高缺货率和高呆滞库存比例不仅直接导致了业务收入的损失，更使得库存商品的价值
逐渐贬值。为了缓解库存压力，企业不得不采取削价清仓的方式，这无疑进一步加剧了成
本负担，给企业带来了沉重的经济压力。

1.2 问题提出
为了研究商品分仓问题,我们团队对附件中所提供的数据和相关材料进行了全面处理
和深入分析,我们的研究重点围绕以下三个问题展开：

问题1：建立“货量预测”模型
根据附件1 和附2 各品类的历史库存量、销量来预测未来3 个月每个品类的月库存量
和每日销量。库存量和销量的准确预测可以支持后续的分仓决策，提前安排仓储资源，减
少冗余和缺货风险。并将月库存预测结果和日销量预测结果填入在result 表格。

问题2：设计“一品一仓”分仓方案
假设每个品类只能放一个仓库中，基于问题1 的预测结果，设计一个最优的分仓方案。
根据附件3 提供不同仓库相关信息，需要在仓库容量、仓库产量、仓租成本之间找到平衡，
以实现最低仓租成本和资源的高效利用。并将完整“一品一仓”分仓结果填入在result 表
格。

问题3：设计“一品多仓”分仓方案
依据附件4 和附5 五各品类之间的关联度以及相关信息，允许一个品类最多可以分布
在3 个仓库中，并尽量将同件型、同高级品类放在同一个仓库中。通过优化品类关联度，
减少订单分拆，降低履约成本。此问题是多目标优化问题，需在品类关联度、仓容和产能
利用率及仓租成本之间取得平衡。并将完整“一品多仓”分仓结果填入在result 表格。
1.3 研究综述

地理解仓库运行机制，控制风险因素，相关数学模型变得更加的科学新颖，对智能出货的
结果也变得更加的精确。因此，本次建模会借鉴已有的相关研究成果，参考已有研究成果
的建模思路、技术路线和结论，在文献综述的基础上进一步探究出“货量预测”模型的建
立问题、“一品一仓”分仓方案以及“一品多仓”分仓方案问题。

3 模型假设
假设一：假设在电商供应链系统中，所有品类的需求是独立于其他品类的，即每个品
类的需求和其他品类的需求之间不存在直接的因果关系，这使得我们可以对每个品类独立
进行需求预测，同时在预测过程中考虑品类之间的相关性来提高预测准确性。
假设二：假设每个仓库的容量上限和产能上限在规划周期内是固定的，且这些限制在
规划期间内不会发生变化。这保证了仓库的基础设施和作业能力在短期内是稳定的，不会
因为季节变化或其他因素而发生显著变化，这为分仓规划提供了稳定的约束条件。
假设三：假设品类之间的关联度是基于历史销售数据或其他可靠方法计算得出的，能
够反映品类之间的销售相关性。且在未来的规划期内保持相对稳定，这种假设使得我们可
以利用历史数据中的关联关系来指导未来的分仓决策，从而提高订单履约效率。
假设四：训练集数据能够充分代表整个时间序列的特征和趋势，测试集数据能够反映
时间序列的最新趋势和变化。
假设五：数据预处理步骤（如缺失值处理、异常值检测和处理、数据标准化等）是有
效的，并且不会对模型性能产生负面影响。

5.1 数据预处理
在进行仓储网络库存量与销量的预测时，数据预处理是一个至关重要的步骤。数据的
质量，直接决定了模型的预测和泛化能力的好坏。它涉及很多因素，包括：准确性、完整
性、一致性、时效性、可信性和解释性。而在真实数据中，我们拿到的数据可能包含了大
量的缺失值，可能包含大量的噪音，也可能因为人工录入错误导致有异常点存在，非常不
利于算法模型的训练。数据清洗的结果是对各种脏数据进行对应方式的处理，得到标准的、
干净的、连续的数据，提供给数据统计、数据挖掘等使用。具体来说，历史数据中可能存
在缺失值，如某些仓库在某些日期的库存量或销量未记录。这些缺失值会影响预测模型的
准确性和稳定性，因此需要通过插值、填充平均值或利用其他统计方法进行处理。同时，

===== PAGE 12 =====

数据中可能包含异常值（如销量大于库存量时就不符合逻辑），这些异常值可能是由于记
录错误或特殊事件导致的。它们会扭曲数据的真实分布，影响预测模型的性能，因此需要
识别并适当处理这些异常值。当缺失数据和异常数据的占比非常小时，可以将忽略缺失数

异常值可能是离群点，即与整体数据情况偏离很大的数据点（常见的四分位距），也
可能是超过某个不合理范围的数据点，在分析中应该首先排除掉异常值，异常值检测逻辑

异常值进行置空或者是填补为其它有效值。本研究使用四分位距检测异常值，四分位距是
指第一四分位数（�1，即25%分位数）与第三四分位数（�3，即75%分位数）之间的差值。

异常值）的敏感度较低，因此能够更稳健地反映数据的中心分布情况。通过将数据集按大
小排序后分为四等分，计算第一四分位数（�1）和第三四分位数（�3）之间的差值，我们

6.2.2 问题2 模型的求解
将“一品一仓”问题看作线性规划问题，因此可以采用分枝定界法进行求解，该方法
不但能求解纯整数规划问题，还能处理混合整数规划问题。分枝定界法是由杰出学者理查
德·卡普首创，他曾成功解决含有65 个城市的旅行商问题，并创下了当时的记录。该方
法的核心思想在于将问题的可行解按照树状分支展开，然后在各个分支中寻找最佳解。每
次分支后，对于那些已知不会超越已知可行解值的子集，将不再继续展开分支，因此许多
子集（即搜索树上的许多节点）可以被排除在外，从而有效地缩小了搜索范围。这个过程
一直持续，直到找到一个可行解，其值不超过任何子集的上界。因此，这种算法通常能够
找到问题的最优解，具体算法流程如图25 所示。

7.2.2 问题3 模型的求解
模拟退火算法是一种基于概率的算法，模拟固体降温过程的最优化算法。其模拟的过
程是首先将固体加温至某一温度，固体内部的粒子随温度上升慢慢变为无序的状态，内能
增大，然后让其慢慢冷却，温度下降时，内部的粒子慢慢趋于有序，达到一种平衡态，最
后达到常温时成为基态，此时内能减为最小，算法模拟这样一个过程期望能达到最优化的
目的，如图28 所示。多目标优化问题，是指在优化过程中存在多个目标函数需要同时最
小化或最大化，这些目标函数之间往往存在冲突和矛盾，因此需要通过一定的方法来平衡
这些目标之间的关系，从而得到一个满足所有目标的最优解集。

8 模型的评价和推广
8.1 模型的评价
8.1.1 模型的优点
（1）LSTM 神经网络模型的优点
LSTM 模型凭借其独特的门控机制（包括遗忘门、输入门和输出门）以及细胞状态，
在多个方面展现出显著优势。它能够有效地捕捉序列数据中的长期依赖关系，这在处理时
间序列数据、自然语言处理等领域尤为重要。LSTM 通过精细控制信息流动，在一定程度
上缓解了梯度消失/爆炸问题，从而能够处理更长的序列数据。作为复杂的非线性单元，
LSTM 可以集成到更大型的深度神经网络中，提升模型的表达能力和泛化能力。
（2）“一品一仓”方案的优点
在搜索过程中，分枝定界法通过剪枝策略，即放弃那些界限超出已知可行解的子集，
从而避免了不必要的搜索，提高了算法的效率。分枝定界法特别擅长处理包含离散变量的
优化问题，这是许多其他算法难以做到的。通过分枝定界法精确计算每个商品在特定仓库
的存储和运输成本，可以优化总成本。
（3）“一品多仓”方案的优点
相比“一品一仓”，“一品多仓”方案允许一个品类在多个仓库中存储，这增加了
库存的灵活性。然而，实施该方案时也需要考虑多个约束条件，如品类相似性和关联性、

===== PAGE 40 =====
35
库存和出库量比例的一致性等，以确保方案的可行性和有效性。同时，需要设计合理的评
估机制来比较不同方案下各个业务指标的表现，并找到多个目标之间的最佳平衡点。在求
解过程中采用多目标粒子群优化算法，该算法全局搜索能力强，能跳出局部最优解探索不
同区域。该算法概念简单，易于实现，且本质并行，适合多处理器系统。此收敛性能好，
能快速向最优解靠近。
8.1.2 模型的不足
（1）LSTM 神经网络模型的不足
LSTM 处理序列数据时只能顺序计算，限制了大规模数据的并行处理效率。其内部结
构复杂，训练过程耗时且需更多计算资源。并且其复杂性导致难以解释其决策过程。
（2）“一品一仓”方案的不足
在解决“一品一仓”方案时，需要用分枝定界法，而其方法搜索过程中内存消耗大，
需存储大量信息。大规模搜索空间下，分枝定界法计算复杂度高，运行时间长。并且其效
率依赖界估计准确性，不准确可能导致效率低下。
（3）“一品多仓”方案的不足
在解决“一品多仓”方案时，需要用多目标粒子群优化算法，该算法在处理多目标优
化时，计算复杂度高，尤其在目标函数多或问题规模大时负担显著增加。同时，该算法可
能过于追求个别目标最优，难以找到均衡解。
8.2 模型的推广
8.2.1 科学性
LSTM 模型、分枝定界法和多目标粒子群优化算法在科学研究中均展现出高度的科学
性和有效性。LSTM 模型在时间序列数据处理领域（如自然语言处理、语音识别、机器翻
译等）得到了广泛应用和验证。分枝定界法基于数学优化理论，通过系统搜索解空间来找
到最优解，其有效性得到了广泛认可。多目标粒子群优化算法则基于粒子群优化思想，擅
长处理多目标优化问题，能够找到多个目标之间的最佳平衡解（Pareto 前沿），同样具有
坚实的理论基础和广泛的实验验证。
8.2.2 拓展性
LSTM 模型能与其他深度学习模型结合，提升性能和适用范围。分枝定界法和多目标
粒子群优化算法则可与其他优化算法融合，形成更高效的混合算法，加速求解并提高质量。

# 灰色预测（GM(1,1)）模型预测与MAPE 计算
def grey_model_forecast(series, forecast_steps=3):
n = len(series)
X1 = np.cumsum(series)
Z1 = (X1[:-1] + X1[1:]) / 2.0
B = np.vstack([-Z1, np.ones(n - 1)]).T
Y = series[1:]
result = np.linalg.lstsq(B, Y, rcond=None)[0]
a, b = result
def grey_forecast(k):
return (series[0] - b / a) * np.exp(-a * k) + b / a
forecast = [grey_forecast(i) for i in range(n, n + forecast_steps)]
return np.array(forecast)
