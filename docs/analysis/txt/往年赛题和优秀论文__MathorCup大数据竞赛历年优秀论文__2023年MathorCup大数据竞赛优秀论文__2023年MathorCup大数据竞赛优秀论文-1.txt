基于深度学习的坑洼道路检测和识别研究 
摘 要 
道路的状况对于交通安全至关重要。坑洼道路是指路面出现了凹凸不平、有大大小
小的裂缝和洞坑等问题，不仅会给车辆和行人带来不便，还可能导致交通事故的发生。
随着近年来科技的进步，深度学习技术迅速发展，为坑洼道路检测任务提供了新的解决
方案。本文结合所给的图像文件，提取了图像特征，建立了识别图像道路坑洼与否的模
型，并从不同维度进行模型评估，并利用该模型对测试集中的图像进行分类识别。 
针对问题一，需要建立一个识别道路坑洼的模型，由于数据集中normal 和potholes
类的样本数量不平衡，所以对potholes 类数据进行翻转和四等分裁剪操作以达到平衡数
据集的效果。在图像特征提取方面，本文使用VGG16 获取图片特征向量并使用PCA 降
维，同时分析图像颜色分布直方图和使用Canny 算法检测轮廓特征。为了提高模型准
确率，本文引入两个深度学习模型Yolov5 和Yolov8，同时加入一个基于集成学习的机
器学习模型。并采用加权投票的方法将机器学习、Yolov5 和Yolov8 的结果进行集成，
权重分别为0.2、0.4、0.4。这样可以有效解决两个深度学习模型分类结果歧义问题。 
针对问题二，对模型进行了完整的训练和评估，从指标评价、鲁棒性和生成对抗样
本三个方面进行了分析。分别考察了损失函数变化、精确度和召回率、高斯噪声鲁棒性、
生成对抗样本及识别等，得出了模型具有一定的鲁棒性和抗对抗样本能力的结论。 
对于Yolov5 模型，其各项损失函数随着迭代的增加而逐渐降低、精确度和召回率
整体呈上升趋势，具体见图22；在噪声数据上，有4 个样本前后识别结果不一致，分类
准确率为97.010%，鲁棒性较强；不考虑对抗攻击强度因素，在对抗样本上，仅有1 个
对抗样本前后识别结果不同，抗对抗样本能力较强。 
对于Yolov8 模型，其损失函数同样随着迭代周期增加而降低，具体见图24，F1 在
置信度为0.453 时达到最大值0.59，精确度随置信度增加呈上升趋势，在0.914 置信度
达到1.0；在噪声数据上，9 个样本前后识别不一致，分类准确率下降了2.325%，为
96.678%，具有一定鲁棒性；不考虑对抗攻击强度因素，在对抗样本上，仅有2 个对抗
样本前后识别结果不同，抗对抗样本能力较强。 
综合上述评估指标，本文所构建的模型识别率较高、分类准确、鲁棒性较好，且具
有一定的抗对抗样本的能力。 
针对问题三，将训练好的模型用于识别所给训练集中，对于正常道路需要标记为1，
对于坑洼道路需要标记为0，并将结果存入到“test_resulu.csv”文件中。

一、 问题重述 
1.1 问题背景 
基于计算机视觉的坑洼道路检测和识别是一个具有实际应用意义的问题。及时检测
和识别坑洼道路可以帮助城市和交通管理部门快速定位和修复道路问题，从而提升道路
的安全性和可行性。通过减少坑洼道路的存在，可以减少车辆事故和损坏，并提高驾驶
者和乘客的舒适度。对于自动驾驶车辆而言，准确检测和识别坑洼道路至关重要。自动
驾驶车辆需要实时感知道路状况并作出相应的决策，以确保安全行驶。通过坑洼道路的
检测和识别，自动驾驶车辆可以调整车速、避免碰撞或选择更平整的道路。除了日常生
活，坑洼道路检测和识别在地质勘探、航天科学和自然灾害等领域的研究和应用具有重
要意义。 
随着近年来科技的进步，深度学习技术迅速发展，为坑洼道路检测任务提供了新的
解决方案。在识别坑洼的过程中，深度学习可以提取坑洼的轮廓、纹理和形态等特征，
并将其转化为更易于分类的表示形式。例如，一些研究者采用基于深度学习的方法对道
路图像进行分类，将其分为正常和坑洼两类。他们利用深度学习模型从大量带有标签的
训练图像中学习坑洼图像的特征，并通过训练模型进行分类预测。此外，一些研究者利
用迁移学习的思想，利用在大规模图像数据上预训练的通用模型（如ImageNet 上的预
训练模型），学习坑洼图像的特征表示。他们通过微调或仅训练分类层，将预训练模型的
知识迁移到坑洼图像分类任务中，以提高分类性能。 
总而言之，深度学习技术在坑洼道路检测任务中具有重要作用。它能够自动提取关
键特征，并利用迁移学习等方法提升分类准确性。这些方法为解决坑洼道路检测问题提
供了更可靠和有效的解决方案。

本次赛题提供了道路图像数据，对此进行分析、特征提取和建模，根据建立的模型
自动识别一张新的道路图像的坑洼状态。基于如上要求，完成下列任务：

还是坑洼的模型，要求识别率高、速度快并且分类准确。 
问题二：训练问题一中所构建的用于识别道路坑洼与否的模型，并从不同维度评估

4.1.1 数据预处理 
(1) 平衡数据集 
当目标检测模型面临类别不平衡的数据集时，存在过度拟合样本更多类别、忽视小
样本类别的问题。这种情况下，模型往往倾向于偏向于预测数量较多的类别，而对于数
量较少的类别则表现出相对较低的关注度和准确性。数据扩增成为了该领域中一种常用
的解决方案。在本次赛题中，我们发现其提供的道路图像数据集存在normal 类266 张、
potholes 类35 张的不平衡情况，为此，我们对potholes 类数据集进行了扩增。具体而言，
我们通过将35 张potholes 类道路图像进行翻转，并进行四等分裁剪的方式，得到了更
多的数据集。这一方法能够有效地缓解模型对数量较多类别的偏向，提高对数量较少类
别的关注度和准确性。

（一）深度学习模型提取图像特征 
VGG16 模型在2014 年的ImageNet 图像分类与定位挑战赛中确实取得了显著的成
绩，展现了其出色的性能。其主要优点之一是其结构的简洁性和深度。这种深度使得模
型能够捕捉到图像中更复杂和更高级的特征。 
VGG16 特意使用小的
卷积核，这与许多其他模型使用的较大卷积核不同。小
的卷积核有几个优点。首先，它们减少了参数数量，这有助于防止过拟合，同时保持了
模型的计算效率。其次，使用多个小卷积核的连续卷积层可以模拟较大卷积核的效果，
但是带有更少的参数和更高的非线性，这使得模型可以学习更复杂的特征。 
此外，VGG16 的设计也确保了每一个卷积层的输出与前一个卷积层具有相同的空
间维度（宽和高），这意味着仅当达到池化层时，特征图的尺寸才会减半。使用
大
小、步幅为2 的max 池化方式可以确保每一层的输出尺寸是前一层的一半。 
VGG16 由若干卷积层和池化层按顺序堆叠而成，通过这种方式，VGG16 能够形成
一个深度网络结构，这对于捕捉图像中的细微和高级特征至关重要。

4.1.3 模型建立

⚫ 
自适应锚框计算 
大部分传统的图像检测模型往往只能对固定尺寸图像进行单目标检测。而在数据集
中，训练集样本的每一目标框的尺寸、数量、位置不一，难以具体确定锚框大小，目标
框的尺寸没有规律，加上图片尺寸较大，不能通过简单的数值约定约束锚框大小。因此，
自适应锚框计算的核心思想是根据数据集中的目标尺寸和分布情况来自动计算和调整
锚框的大小和长宽比。 
YOLOv5s 网络在每次训练迭代中，按照事先定义的输入长宽尺寸设置锚框，然后
根据新数据集的标签信息，自动学习适应锚框的尺寸。如果召回率达到了0.98 以上，就
不再进行优化，而是直接返回结果；但如果召回率低于0.98，那么模型将采用K 均值聚
类方法，结合自定义数据集的分析，以获得适合数据集目标边界框的预设锚定边框。具
体来说，在可能的位置根据预设锚定框来选取目标区域，然后在这些预设锚定框的基础
上进行微调。其次，利用真实标签位置相对于预设锚定框的偏移来构建预定义的锚框，
模型在这些锚框的基础上输出目标检测的预测框。接下来，将这些预测框与真实标签进

行比对，计算它们之间的差异，并通过反向传播来更新模型参数，迭代使损失值最小化，

这一过程实现了自适应计算不同训练数据集中的最佳锚框值。在目标检测任务中，

metrics/precision(B)和metrics/recall(B)：在训练过程中，精确度 (precision) 和召回
率 (recall) 呈现了波动的上升趋势。这表示模型在正确识别目标的能力逐渐增强。 
metrics/mAP50(B)：这个指标代表在IoU 阈值为0.5 时的平均精确度 (mean average 
precision)。它也显示了一个上升的趋势，说明模型的整体性能在提高。 
metrics/mAP50-95(B)：这是在多个IoU 阈值（从0.5 到0.95）上的平均精确度。这
个指标也在逐渐上升，表示模型在多个阈值上的性能都在提高。 
Yolov8 模型在训练过程中逐渐获得了更好的性能。损失值在下降，而性能指标在上
升。但是，还需要注意验证损失和性能指标的波动，这可能表示模型对于训练数据可能
存在一定的过拟合。 
4.2.3 模型的鲁棒性 
鲁棒性是指系统或模型在面对各种不确定性、异常情况或攻击时的稳定性和健壮性。
在深度学习和人工智能领域，鲁棒性是指模型对于输入数据的变化、扰动、噪声以及对
抗性攻击等的处理能力。验证模型的鲁棒性是一个重要的任务，本文通过添加高斯噪声
和生成对抗样本两种方法来验证模型的鲁棒性。

五、 模型评价与推广 
5.1 模型优点 
1. 本文主要实现了基于YOLO 目标检测深度学习模型的道路坑洼检测项目，并结
合机器学习进行集成学习，所成的融合模型识别率高、分类准确，能够快速准确地识别
图像中的指定物体。 
2. 在前期数据预处理中，由于所给训练数据集中正常和坑洼道路类别不平衡。我
们通过翻转、裁剪操作对potholes 类数据集进行扩增，显著提高模型预测的准确性。 
3. 我们通过对图片增加噪声和生成对抗样本来评估模型的鲁棒性。通过数据对比
可得其在处理复杂背景、部分遮挡和小目标等情况下表现出较强的鲁棒性和抗干扰能力，
能够适应不同的场景。 
5.2 模型缺点 
1. YOLOv5 的性能高度依赖于大规模、多样化的训练数据。如果训练数据不足，
模型的性能可能会下降。 
2. YOLOv5 深度学习模型在处理大规模数据时需要较强的计算资源（GPU）支持，
这限制了模型训练的最终性能，使得模型特征提取能力和识别准确度受到进一步限制。 
3. 由最终得取的测试结果说明模型的泛化预测能力还需进一步提升。 
5.3 模型推广 
深度学习在大数据中具有较强的特征提取能力，极大地提高了对于复杂数据集的处
理能力，以较快的速度和准确率平衡而广受推崇。由于YOLO 模型泛化能力、特征提取
能力较强，其对于大多数目标检测准确率都较高，这使其应用广泛，其可应用于各种物
体检测项目，比如道路人流检测，人脸识别技术等领域。

def split_image(image_path): 
    # 打开原始图片 
    image = Image.open(image_path) 
 
    # 获取图片尺寸 
    width, height = image.size 
 
    # 计算每个子图的尺寸 
    sub_width = width // 2 
    sub_height = height // 2 
 
    # 分割图片 
    upper_left = image.crop((0, 0, sub_width, sub_height)) 
    upper_right = image.crop((sub_width, 0, width, sub_height)) 
    lower_left = image.crop((0, sub_height, sub_width, height)) 
    lower_right = image.crop((sub_width, sub_height, width, height)) 
 
    # 返回分割后的四个子图 
    return upper_left, upper_right, lower_left, lower_right

# 交叉和变异 
def crossover_and_mutate(parent1, parent2, mutation_rate): 
    child = parent1.copy() 
    rows, cols, ch = parent1.shape 
    # 随机选择交叉点 
    crossover_point = np.random.randint(1, cols - 1) 
    child[:, crossover_point:] = parent2[:, crossover_point:] 
    # 变异 
    mutation = np.random.randint(0, mutation_rate, child.shape, dtype=np.uint8) 
    child = (child + mutation) % 256 
    return child

def convert(size, box): 
    dw = 1. / (size[0]) 
    dh = 1. / (size[1]) 
    x = (box[0] + box[1]) / 2.0 - 1 
    y = (box[2] + box[3]) / 2.0 - 1

    h = h * dh
