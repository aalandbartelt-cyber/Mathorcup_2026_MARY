## 4. 官方六大答卷问题自查表（讲座 p.32 原文）

| # | 官方问题 | 自查项（每项打勾） | 怎么验证 |
|---|---|---|---|
| 1 | 数据预处理没有章法，不按需求处理 | 有清洗步骤表（每步行数变化+理由）；按题目需求而非模板处理 | 论文“数据预处理”节能列出 5–8 步，且每步有前后数字 |
| 2 | 问题理解不明确（细节自己定方案） | 每问写明边界、输出格式、自定假设 | “问题分析”里每问有一段“本题要求回答……” |
| 3 | 模型条件约简不符合实际 | 假设可辩护；简化说明代价 | 每条假设后写“若放宽会怎样” |
| 4 | 只注重展示方法，不注重问题解决 | 方法与问题一一对应；不堆模型 | 每个模型能回答“为什么用它、解决了哪条难点” |
| 5 | 结论不验证实际、不讨论 | 有误差分析/失败案例/业务解释 | 每问结果后有一段“结果合理性/局限” |
| 6 | 程序跑不通 | 干净环境可复现；输出与论文一致 | D-1 演练 + 提交前再跑一次 |

## 5. 题型 → 路线 → 交付 速查

| 题型 | 主线方法 | 关键指标 | 交付物 |
|---|---|---|---|
| 图像分类 | 迁移学习（ResNet/DenseNet/EfficientNet/MobileNet） | Acc/P/R/F1、AUC、混淆矩阵 | 预测 CSV（image_id,prediction,probability） |
| 目标检测/分割 | YOLO 系列（+注意力/多尺度）、Mask R-CNN、U-Net | mAP@0.5、mAP@0.5:0.95、IoU/Dice | `image_id,class_id,x_center,y_center,width,height`（归一化） |
| 表格回归 | XGB/LGB/CatBoost + 交叉验证 + 特征工程 | R²/RMSE/MAE/MAPE | 预测 CSV（id + 目标列） |
| 表格分类 | XGB/LGB/RF/Stacking，处理不平衡 | Acc/F1/AUC、业务约束满足率 | 预测 CSV（id + label + prob） |
| 时序预测 | ARIMA/SARIMA、指数平滑、Prophet、LSTM、集成 | MAPE/1-WMAPE/RMSE | 预测 CSV（时间 + 值） |
| 运筹优化 | 0-1/混合整数规划、贪心、模拟退火、PSO/NSGA | 目标值、约束满足、Gap | 结果 TXT（决策变量） + 方案图 |
| 综合评价 | 熵权/TOPSIS/AHP/灰色关联 + 敏感性分析 | 权重、排序稳定性 | 评价表 + 排名 |

## 6. 结果文件模板与校验

模板位置：`docs/templates/`

| 模板 | 用途 | 字段 |
|---|---|---|
| `result_classification.csv` | 分类/图像分类 | `image_id,prediction,probability` |
| `result_detection.csv` | 检测（YOLO 归一化） | `image_id,class_id,x_center,y_center,width,height` |
| `result_assignment.txt` | 分配/方案型（参照 2022 A 讲解） | `id,serviceStartTime,auntId` |
| `result_assignment_batch.txt` | 分批决策（2022 A 的 result22） | `currentTime,id,serviceStartTime,auntId,retainable` |

提交前校验：

```bash
python scripts/check_result.py --file outputs/result_detection.csv --images-dir data/<数据集>/images/test
python scripts/check_result.py --file outputs/result_classification.csv --images-dir data/<数据集>/images/test
python scripts/check_result.py --file outputs/result_assignment.txt
```

校验内容：表头匹配、数值范围（检测坐标 0–1）、类别 id、重复行、图片覆盖、缺失预测警告。
**注意**：以赛题最终给的字段/顺序为准；模板只是通用起点。
