# Q3 E209 Lambic固定候选扩展与更强裕量复核

延续已授权Q3迭代，单独新增结果，保留E205B/E207全部数字和选点。只处理尚无稳定主候选的Lambic，目标是检验候选空间不足是否解释旧方案失败，不承诺一定出现可用谱。

## 预登记设置

- 11个Pils/Lager源，目标Lambic；主情景C1。原Copula池2000条保持，加2000条经验Beta线性和2000条经验Beta阶梯候选。新增两池是迁移搜索的探索性提案，不自动获得E208主生成器地位；E208的生成质量结论必须另列。
- 每源按几何距离取最近512条提案，再从其余提案按固定种子无放回取512条，加入原经验秩端点，共1025个锚点。固定9个λ=0.025/0.05/0.10/0.20/0.35/0.50/0.65/0.80/1，合计每源9225个点；不按审计模型分数扩展池。
- 已知4类直接缺陷按C1下投影；源缺失掩码保留、地板/未知LOD仍未知。
- 源排除的10个NNLS用于搜索，平均与重复90%分位变化均≤−0.03z；至少1%目标靠近，谱改动RMS≤1.0，支持域至少9/10重复满足。
- 固定三规则各一条：最小改动（主规则）、最大目标靠近、最大预测裕量。没有可行点明确拒绝。33规则行不是33个独立源，主分母是11。
- 候选、谱与输入哈希先提交锁定，再由冻结ElasticNet一次复核，不根据该结果重新搜索。最终比E205B多要求两模型平均与90%分位均≤−0.01z；原“预测不升”口径并列作敏感性，不能偷换成主结论。
- 已经使用过的ElasticNet不能叫全新未见的验证集；这里只是搜索未访问的模型族复核。源浓度未知永不变成通过，物理安全认证始终false。
- 若E208未通过生成主模型替换条件，保持原Copula为生成主方法；E209即使出现候选，也不能反推Beta在条件分布上最优。

`run_e209_lambic_search.py`只复用现有锁定框架、单目标NNLS等价预测、几何距离、支持域及C1投影，读Q1/Q2不写。`audit_e209_lambic.py`重新核对谱的来源锚点/λ、输入哈希、完整11源分母、一次模型族复核，以及更强裕量；分开给出严格/边界敏感/直接未知/搜索拒绝。
