# Q3 基础代码设计：E200契约、缺陷审计与独立评价

> 2026-10-25；承接Q3独立方案v1。用户授权自主做其他工作，E009由ZCode监控；本轮只准备Q3代码与数据审计，不训练、不调参、不检查E009进度。工作树q3-foundation，基于927403d。

## 1. 范围与取舍

三个可独立测试的模块：字段/样本与量纲契约、四个直接缺陷的C1/C2/C3审计、无训练的分布评价。采用纯函数与显式输入，避免直接依赖全量相关阵、Q1模型或参考组生成结果。

不在本轮实现生成器、迁移优化器、训练型风格分类/C2ST、图稿或Word。数据核验可读取全附件，但只导出描述性契约；地板概率、尺度参数、模型参数和评价阈值的训练仍必须折内进行。

## 2. 数据契约

- 主键beer完整唯一，附件1/4/8键集合一致，连接后风格一致；忽略beer_id的连接身份。
- 附件1保持231字段、附件4保持50目标；均为数值，无Inf；目标无缺失。冻结CV索引应恰好10×250条，repeat/fold/row_position/beer互相匹配。
- 附件8字段元数据按field_name_R唯一连接，不能按位置偷换字段。5个派生量kcalperc/esters_sum/aroma_hops_sum/acids_sum/sulfur_sum只标识，不捏造计算公式。
- 70个可校验字段用正值成对比较raw/log10；至少3对，最佳匹配率≥0.95且严格超过另一路才识别尺度。0.95只用于识别字段变换，不认证单元格。每个单元格另标observed/reference_conflict/reference_zero_ambiguous/missing_stored/missing_reference。
- 保留未知161字段；对未知量纲不指数化。实测少数原尺度字段并非逐元素完全一致，导出所有冲突，不覆盖附件1。
- 实测附件8还含3条负参考值，标reference_negative并保留原值，不裁剪、不作物理浓度认证；这与合法log10负值不同。
- 四直接缺陷分别核对单位：DMS ug/L，其余mg/L；均值/中位阈值并列。trans-2-nonenal缺阈值，stale_hops是感官代理、没有单一化学字段。
- 源Pils/Lager的缺失/零/冲突不能经中位数或参考零变成已知真实浓度；低于未知LOD不填造区间端点。

E200输出：231行字段合同、校准冲突表、5行缺陷注册表、11×4源缺陷表、22风格计数、样本/列变化步骤表和含输入/配置/源码哈希的manifest。没有任何预测器fit。

## 3. 缺陷审计接口

`audit_concentrations(source, candidate, source_known, scenario, threshold=None)`返回逐项状态、上限、违反幅度和nullable布尔通过标记。输入为已核验的非负同单位浓度；候选NaN/Inf/负值明确无效，未知源不参与确定性通过率。

- C1：上限source；C2：上限max(source,threshold)；C3：上限min(source,threshold)。C2/C3阈值缺失返回unknown_threshold，不能默认C1。
- 比较容差固定为atol=1e-9、rtol=1e-7，随源浓度量级；不是业务放宽。
- `project_upper_bounds(candidate, upper)`只对已知上限向下截断，不把低于上限的值上调；未知上限保持原值且后续审计仍未知。
- `summarize_migration(audit, target_gain, proxy_nonworsening)`分别计直接通过/失败/未知；没有目标靠近判no_target_gain，代理失败拒绝、代理未知待核验。返回eligible_statistical_candidate不能叫真实酿造安全认证。

## 4. 独立评价接口

`distribution_diagnostics(real, generated, training, scale, knn_k=1)`不fit任何模型；scale由调用者的训练折提供且必须正/有限。real/generated样本数须相同且均≥2；字段顺序由上游契约固定。

输出边缘归一化W1、联合energy V-statistic、可计算Spearman相关对数及均方差、训练近邻重复率、基于真实邻域的覆盖。RMS距离统一除以sqrt(p)。不输出伪造p值、置信区间、C2ST或综合最优分数。

常数列导致相关不可识别时单列数量/NaN；不能把无可比相关对记零误差。knn_k必须小于真实样本数，不自动照搬图像文献的k=5。

## 5. 必须通过的边界

1. beer顺序打乱仍正确连接；重复/缺失主键或风格冲突拒绝。
2. 大多数尺度匹配但个别浓度冲突时保留尺度识别，冲突单元不获认证；未知字段不变换。
3. 附件8零对应附件1缺失/地板仍为未知；单位错配拒绝；缺阈值不补造。
4. C1/C2/C3在源低于阈值和源高于阈值时表现不同；候选无效不能被未知源掩盖。
5. 投影不改变更低值，未知边界不变；零迁移不能因缺陷通过而算成功。
6. 相同分布W1/energy为零；平移分布非零；常数相关标未知；复制训练样本能被重复指标识别。
7. E200可复算既有250×231/50、37/33/161、73缺失、4VG地板、两款源双乙酰缺失及原尺度冲突；仅生成契约。
