## 1. 目标与不变项

正式答案继续采用四路稳健统计 Top-3；感官组收缩 NNLS 的分层条件归因只作为独立预测依赖证据。补充三证据融合保留为未采用消融，后续化学正式化分级不生成。本次不得重跑数值实验，不得修改 Q1/Q3，也不得改变 Q2 排名或结果数字。

## 2. 原生公式设计

七个公式全部使用可编辑 OMML。每个数学 run 显式设置 Cambria Math，普通变量使用数学斜体；函数名、数字和运算符保持正体。分式、上下标、上下标组合、求和和定界符分别使用 `m:f`、`m:sSub`/`m:sSup`/`m:sSubSup`、`m:nary` 和 `m:d`。第六式重建为

`π_kj = (1/B) Σ_{b=1}^{B} I(k ∈ T_b^(j))`。

XML 验收不仅检查公式数量和结构节点，还检查任一 `m:oMath` 内不存在空 `m:r`、每个数学 run 含非空 `m:t`、七式所需结构及关键符号齐全。PDF 中逐式目检分数线、求和上下限、上下标和编号。

## 3. 四张主图设计

四图均由净化后的论文级 CSV 输入 R/ggplot2，使用 `theme_mcup()`、9×6 英寸（3:2）、300 dpi、白底和黑细框，不在图片内写整图标题。

1. 图1只回答“所选相关阈值如何平衡边保留和网络碎裂”。左侧显示正负边随阈值的数量变化，右侧显示孤立节点/连通结构；以竖线、实心标记和简短注释突出选定阈值。
2. 图2只回答“候选预测器的折外性能如何，最终排序与四路证据是否一致”。使用上下两个清晰面板：上部以 R²/MAE 两个分面比较方法，下部单独显示四路 Jaccard 与完全一致目标数，避免三个狭窄面板并排。
3. 图3只回答“150 条候选的重采样和跨风格稳定性如何分层”。主面板显示入选频率—留一风格保留率和稳健等级，侧面用紧凑计数条显示证据等级，不使用网络或大热图。
4. 图4只回答“8 条 A 级关系在四路名次和 OAV 上是否相互支持”。排名用清晰点线/热格表达；OAV 使用同单位区间点图，不可比项在对应行明确标为 `N/A`，不伪造数值位置。

每张图都生成源数据、图清单、彩色版、70% 缩放检查版和灰度检查版；只有彩色主图进入正文。

## 4. 论文论证设计

摘要式开篇、问题分析、方法、结果和讨论同步更新。新增“公开方法对照与消融”表，列为“方法家族—回答的问题—本文对应结果—差异及采用判断”。文献只用公开作者和年份：Zhang 与 Horvath（2005）的加权相关网络、Friedman 等（2008）的 graphical lasso、Strobl 等（2008）的条件置换、Lundberg 与 Lee（2017）的 SHAP、Meinshausen 与 Bühlmann（2010）及 Shah 与 Samworth（2013）的稳定选择。跨数据、跨目标、跨尺度的文献结果统一标注不可直接横比，不录入外部数值。

正文使用“边际关联基线、稀疏回归、图正则消融、树模型条件归因、最终感官模型归因、稳健统计排序”等学术名称。任何内部实验编号、内部参考代号和管理术语均不得进入正文、图源、文件名和 ZIP。
