# Q3 E216 双侧物理界迁移设计

状态：2026-10-26，运行前登记。E215 的单侧 C1 投影使 10/33 条 Tripel 端点出现负双乙酰；其结果保持只读，不追改。本设计独立新增 E216 候选，不改 Copula、Q1/Q2、900 份画像及 E204/E205B/E209 数字。

## 数学修改

仍用 E215 固定的经验贝叶斯风格均值 `κ_μ=15`、协方差 `κ_Σ=30`、同一 11 源×3目标和七个 λ。对直接化学字段在原存储尺度上建区间：所有 `raw` 浓度下界为 0；已知源测量的 C1 上界为该源浓度；`log10` 字段因反变换始终为正，不另造未知检出限下界。未知源值没有 C1 上界，且在结论中仍是未知。

求解 `min_z (z−a)^T Σ_t^{-1}(z−a)/2`，约束 `l_D≤z_D≤u_D`。由于直接字段最多四项，枚举“未激活/下界激活/上界激活”的 `3^4` 种 KKT 状态，核对乘子符号和全部区间约束。数值容差固定 `1e-9`，禁止事后逐列裁剪再宣称联合结构保留。λ=0 必须与原源谱逐值相同；七个非零路径不得因投影改变源身份。

## 两阶段检查

第一阶段仍为全数据后选择几何审计，不读感官代理：33端点、231非零路径，逐项报告 C1 已知通过/未知、非负性、目标靠近、谱改动、目标风格支持域外比例，并与 E215 单侧投影成对对照。若存在任一已知直接缺陷数值违反或负的原始直接浓度，停止 E216；不得补救性调 κ 或 λ。

第二阶段只有在第一阶段数值有效后才另行执行既定冻结代理筛选：每源—目标在七个 λ 中按 E205B 的最小改动主规则锁定候选，条件仍是目标靠近≥1%、NNLS Stale hops 平均与重复90%分位均≤−0.01z、训练支持域重复比例≥0.9。锁定后再调用独立 ElasticNet 家族作一次审计，保留全 33 组分母与未知状态。双乙酰非负不等于真实酿造可行；Stale hops 仍是弱预测代理。
