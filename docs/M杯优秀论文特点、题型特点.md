## 1. 题型地图

### 1.1 五年赛题谱系（按年份）

| 年份 | 赛题/赛道 | 任务本质 | 典型方法（优秀论文实际使用） |
|---|---|---|---|
| 2021 | 二手车估价 + 推荐序列收益 | 表格回归、排序优化 | KNN 填补、特征工程、XGB/LGB/CatBoost、**Stacking**、贝叶斯优化 |
| 2022 | 移动用户满意度 + 家政派单 | 表格分类回归、运筹优化 | 熵权/灰色关联/卡方效应量、多种回归对比、**混合整数规划+贪心** |
| 2023 | 坑洼道路检测 + 电商需求预测 | 图像分类/检测、时序预测 | VGG/DenseNet/ResNet/ViT/YOLO、ARIMA/LSTM/Prophet/指数平滑 |
| 2024 | 台风 + 电商货量分仓 | 聚类+时序+物理解析、预测+多目标优化 | KMeans/DBSCAN/层次聚类、LSTM/DTW、指数衰减、**NSGA-III/模拟退火/PSO/0-1 规划** |
| 2025 | 集装箱破损检测（A）+ 物流理赔（B） | **分类+检测+分割+评估**；无监督标注+回归+不平衡分类 | CABNet/ResNet+注意力、**YOLOv11/v8 改进**、HI 健康指数；分位边界、Stacking、SHAP、SMOTE |
| 2026 练习 | TMDb 观影分析（练习1）+ COVID CT（练习2） | 引导式 EDA+ML 回归；CT 图像二分类 | pandas 清洗+5W1H 可视化；迁移学习 CNN |

**结论**：M 杯大数据赛道的题型高度稳定，五年只围绕五类任务出题（§1.2）。2025 赛道 A 与 2026 练习 2 都是 CV，说明视觉类题目是重点；2026 练习 1 用「填空式教程」明确展示了官方期待的 EDA 分析框架（5W1H）——这是出题方对「数据分析部分该怎么做」的明示。

### 1.2 五类任务与出题套路

**A. 图像分类/检测/分割（CV）** — 代表：2023 坑洼、2025 集装箱、2026 练习2
- 出题结构几乎固定三问：**Q1 建立模型（分类或检测）→ Q2 评估模型（多维度）→ Q3 对测试集预测并输出 CSV**。
- 2025 赛道 A 把三问定义为：Q1 有无残损二分类、Q2 定位+识别类别（检测与分割）、Q3 多维度模型评估；复赛升级为 **7 类残损**并要求按 ImageSets 划分 [S25Af]。
- 2023 坑洼题的 Q2 是「完整训练与评估（指标/鲁棒性/对抗样本）」、Q3 是「测试集预测写 test_result.csv」[P23-1]——与集装箱题同构。
- 2026 练习 2（COVID CT）：在 `CT_COVID`/`CT_NonCOVID` 上训练测试，再对 `predict` 目录 577 张图给出预测 [S26P2]。**本质是二分类+批量推理**。

**B. 表格数据预测（回归/分类）** — 代表：2021 二手车、2022 满意度、2025 理赔
- 出题结构：**数据清洗→特征工程→建模→预测提交**；常要求「分析影响因素 + 建立预测模型」两个层次。
- 2025 赛道 B 是典型：Q1 基于业务约束给运单打风险标签（无监督/规则）、Q2 预测实际赔付金额（回归）、Q3 在类别极度不平衡下优化分类 [S25B]。
- 优秀论文的共同动作：**多模型对比 + 调参 + 融合 + 特征重要性解释**，几乎 100% 出现。

**C. 时间序列预测** — 代表：2023 电商需求、2024 台风/货量
- 标准套路：数据预处理（缺失/异常/节假日）→ 序列分类/聚类 → 分群/分层预测 → 集成或加权 → 促销/事件因子修正。
- 2024 货量题进一步要求**预测结果驱动优化**（分仓规划），形成「预测→优化」两阶段题 [P24-5][P24-6][P24-7][P24-8]。

**D. 运筹优化** — 代表：2022 家政派单、2024 分仓
- 标准套路：定义决策变量与约束 → 建立 **0-1 整数规划/混合整数规划/多目标模型** → 求解（PuLP+CBC、LINGO+SCIP、贪心、模拟退火、PSO、NSGA-III）→ 与基线对比。
- 2024 分仓题的三问层层递进：单品单仓 → 单品多仓 → 多目标综合收益 [P24-5][P24-7]。

**E. 无监督/不平衡数据** — 代表：2025 理赔
- 2025 赛道 B 的 Q1 是「无历史标签的风险标注」：优秀论文用**分位数分层+阈值拟合**（线性/幂函数/单调分位边界 MQBL）或**孤立森林+One-Class SVM** 构造标签 [P25-5][P25-7][P25-8]。
- 2025 Q3 考「严重超额」样本极少（≈3%）：SMOTE、代价敏感、类权重、加权融合是标准解法 [P25-6][P25-7]。

### 1.3 「第三问」的三种延伸模式（预测题高分关键）

统计 40 篇可见，第三问通常不是重复建模，而是以下三种之一：
1. **评估与推广**：从准确性/鲁棒性/效率/泛化多维度评估模型（2025-3 的「三维评估体系」[P25-3 p.9]、2025-4 的「性能/效率/鲁棒性/泛化」四维 [P25-4]）。
2. **开放建议/策略**：基于模型输出给业务建议（2021-1 问题三从利润率/客户/业务广度/附加值四方面给策略 [P21-1]）。
3. **系统化延伸**：把模型包装成系统/指标（2025-1 的集装箱健康指数 HI=1−S_d，给出 Excellent/Good/Poor/Critical 分级 [P25-1 p.22-23]）。

**可复用经验**：第三问若为「评估」，不要只报数字——要**分维度 + 对照实验 + 消融实验 + 失败原因分析**（见 §6）。


### 1.4 2026 练习题数据核验（解包实测）

| 练习 | 数据实际结构 | 与题面的一致性 |
|---|---|---|
| 练习1 观影 | `data/tmdb_5000_movies.csv`（5.7MB）、`tmdb_5000_credits.csv`（40MB）、`tmdb_1000_predict.csv`（1.1MB） | 与 PDF 描述的 2+4 变量、1000 部待预测一致 |

## 2. 优秀论文的通用骨架（带出现率）

### 2.1 一级结构（40 篇统计）

| 章节 | 出现率 | 说明 |
|---|---|---|
| 摘要 + 关键词 | 40/40 (100%) | 第 1 页；关键词 3–8 个，用分号或顿号分隔 |
| 目录 | 40/40 (100%) | 第 2 页（官方规范要求） |
| 问题重述/问题背景 | 38/40 (95%) | 含「1.1 背景 1.2 目标任务」 |
| 问题分析 | 39/40 (98%) | **每问单独一节**：2.1/3.2 针对问题一/二/三 |
| 模型假设 | 34/40 (85%) | 通常 3–6 条，围绕数据质量与场景假设 |
| 符号说明 | 35/40 (88%) | 表格式，符号+含义，10–20 行 |
| 数据预处理/EDA | 38/40 (95%) | 独立成章是常态 |
| 模型建立与求解 | 28/40 (70%) | 每问「建立→求解→结果」三连 |
| 结果分析 | 22/40 (55%) | 图表逐张解读 |
| 模型检验/灵敏度 | 15/40 (38%) | 加分项：学习率/阈值/参数扰动 |
| 模型评价（优缺点） | 34/40 (85%) | 优点 3–4 条、缺点 2–3 条、推广 2–3 条 |
| 参考文献 | 40/40 (100%) | 15–30 篇，IEEE 风格带 DOI 很常见 |
| 附录（全代码） | 38/40 (95%) | **官方硬性要求**；篇幅 20–130 页 |

数据来自全语料统计（§10 附录 A 可复现）。

### 2.2 典型章节标题序列（2025-1 实际目录 [P25-1 p.2]）

```

四、问题三求解  4.1 多分类模型（数据处理/求解/结果）  4.2 健康状态分析系统（设计/结果）

```

### 2.3 两种结构变体

**变体 A：按问题分章**（2025-1、2024-1、2023-1 等，最常见）
```
问题重述 → 问题分析 → 假设与符号 → 问题一模型 → 问题二模型 → 问题三模型 → 评价
```

**变体 B：按建模流程分章**（2025-3）
```
问题重述 → 假设与符号 → 问题分析 → 数据预处理 → 问题求解（5.1/5.2/5.3 每问：思路→建立→求解）
→ 模型分析检验（灵敏度+测试集检测）→ 模型评价与推广 → 参考文献 → 附录
```
[P25-3 p.3-4 目录]

**选择建议**：数据预处理量大（清洗/扩充/增强）用变体 B 更顺；每问模型差异大用变体 A 更清晰。

### 2.4 篇幅与图表密度

- 正文 18–30 页（官方上限 30 页 [F25]），附录 20–130 页代码；总页数 18–160 页。
- 图数 11–109 个、表数 0–45 个；**正文每 1.5–2 页至少 1 个图或表**。
- 参考文献 15–29 篇（2025-1 共 29 篇，含 2010–2024 年文献，综述写满 3 页 [P25-1 p.3-6]）。

## 3. 摘要怎么写（模板 + 真实拆解）

### 3.1 四段式骨架（40 篇共性）

```
第 1 段：背景 1–2 句 + 本文总体方案 1 句（"为此，本文提出/构建了一种……"）
第 2 段：针对问题一，……（方法 + 关键设置 + 指标数字）
第 3 段：针对问题二，……（同上）
第 4 段：针对问题三，……（同上；或评估体系）
结尾：关键词：A；B；C；D
```

语料统计：`针对问题一` 出现 64 次、`针对问题二` 58 次、`针对问题三` 47 次；`提升` 518 次、`显著` 273 次、`结果表明` 31 次、`验证了` 31 次（40 篇合计）。**每问一段、数字收尾**是绝对主流。

### 3.2 真实摘要拆解（2025-1 赛道 A，全文见 [P25-1 p.1]）

> 港口自动化与智慧物流的快速发展对集装箱外观损伤的检测精度和处理效率提出了更高要求。……为此，本文基于深度学习与计算机视觉技术，提出了一种从图像级残损判定、目标检测到结构健康评估的集装箱智能检测体系……
> **针对问题一**，构建了基于残差神经网络的图像级二分类模型 CABNet……模型在 test 数据集上取得**准确率 98.0%**……
> **针对问题二**，提出了改进型 YOLOv11……最终模型取得 **Precision=0.817、Recall=0.750、mAP@0.5=0.809、mAP@0.5:0.95=0.628**……平均 **IoU=0.863**，检测成功率 79.6%，**F1=0.728**……
> **针对问题三**，……建立**损伤得分函数 S_d=Σω_ti·s_ai·ω_li·p_i**，并定义**健康指数 HI=1−S_d**……平均健康指数 0.749……
> 关键词：深度学习；计算机视觉；CABNet；YOLOv11；集装箱健康评估系统

可复用动作：
1. **方法名自造**：CABNet（既有论文的模型名，用时注明引用 [P25-1 p.7 图4 标注 [28]]）。
2. **每问给 2–4 个具体指标数字**，不写"效果良好"。
3. **第三问给公式**（损伤得分、健康指数），让阅卷人 10 秒看到建模深度。
4. 关键词覆盖：技术领域（深度学习/计算机视觉）+ 具体模型（CABNet/YOLOv11）+ 应用对象（集装箱健康评估）。

### 3.3 其他年份摘要范式

- **表格题**（2021-3 [P21-3]）：「本文建立基于 Stacking 技术和贝叶斯优化的模型……针对问题一，主要需要确定影响成交价格的因素并建立合适的预测模型。本文建立了基于 Stacking 的 XGBoost、LightGBM 和 CatBoost 融合模型，并运用贝叶斯优化调参……验证集评测值 0.5324，**优于单一模型**」。
- **时序题**（2023-5 [P23-5]）：「提出**自顶向下+分层聚类**的集成预测方案……指数平滑、Auto ARIMA、XGBoost、LightGBM、LSTM 五个算法……融合后获得更高的 **1-WMAPE**」。
- **优化题**（2024-5 [P24-5]）：「SARIMA + 随机森林回归……构建线性规划模型，强调'一品一仓'原则……**PULP_CBC_CMD 求解器，分支割平面法**，总成本 **6977267.16 元**」。
- **不平衡题**（2025-7 [P25-7]）：「构建**单调分位边界学习（MQBL）**模型……在'合理诉求占比≥85%''严重超额占比≤3%'**业务约束**下完成标注」。

### 3.4 摘要雷区
- 只在第一问写细节、后两问一句带过（评委按问题给分）。
- 通篇方法堆砌无数字；或数字与正文不一致（自查：摘要每个数字必须能在正文图表找到）。
- 摘要出现图表编号（"见图 3"）——摘要应自包含。

### 4.2 各任务类型的「必配图清单」

**CV 题（集装箱/坑洼/CT）**
1. 数据样例图（原图+标注框）——用于说明挑战（"图9 赛题原始数据" [P25-1 p.14]）
2. 全流程技术路线图
3. 模型结构图（标出改进模块；引用来源时在标题后标注文献号）
4. 训练曲线（loss+accuracy 或 loss+mAP）
5. 混淆矩阵（原始 + 归一化两版，2025-1 用「图15 原始和标准化混淆矩阵对比」[P25-1 p.23]）
6. PR 曲线（分类任务）/各类别 P-R 曲线（检测）
7. 检测结果可视化（预测框/掩码叠加图）
8. 消融对比表/图（模块逐个加）
9. 鲁棒性测试图（噪声/亮度扰动前后对比）

## 5. 问题分析的写法（高分核心）

### 5.1 「难点→对策」映射模板

优秀论文的分析段几乎都是三段式：**任务本质 → 数据/场景挑战（编号列举）→ 建模选择（逐条应对）**。

**范例 1（2025-1 问题二分析 [P25-1 p.14]）**：
> 该任务实质上属于……目标检测与实例分割问题。**从赛题数据来看**，数据集共 3713 张……三类破损……**然而，问题二存在多重挑战**：首先，图像背景复杂（港口机械、地面、天空）；其次，光照、反光与污渍造成噪声；第三，缺陷尺寸差异大（微小裂纹 vs 大面积锈蚀），需多尺度特征提取；最后，类别分布不均衡……**综上**，问题二的核心任务是构建一个在复杂背景下具备多尺度检测能力、能有效区分不同类型破损的视觉检测模型。

**范例 2（2025-3 问题二分析 [P25-3 p.8-9]）**：明确列「其一/其二/其三」三个难点（多尺度适应性、外观相似+样本不均、分割精度），然后「针对上述……问题，选用 YOLOv8 作为基础架构……Focal Loss……纹理增强分支……Dice Loss」逐条对应。

**写法要点**：
- 难点要**从数据里来**（引用 EDA 数字：类别占比 39%/11.7%、图像数 3713、尺度范围），不写空话。
- 每个难点必须有**对应的技术动作**，形成"问题清单→对策清单"。
- 段末用一句"综上，本问核心任务是……"收敛。

### 5.2 数据层面的两个高频「杀手锏」

1. **负样本缺失 → 构造法**。2025-1 发现原始数据全部带标注、无「无残损」图，于是**用白色矩形覆盖标注框生成"无残损"图**，构建 1:1 平衡数据集 [P25-1 p.6-8]。
2. **类别不平衡 → 裁剪扩充法**。2025-3 从有缺陷图中裁剪无缺陷区域（排除标注框及边缘 50 像素，尺寸≥224×224，滑窗步长 112）补充负样本 [P25-3 p.10-11]；并配合加权交叉熵/Focal Loss。
> 这两个动作在集装箱题上直接可用，2026 若仍是缺陷检测类题，优先复用。

### 5.3 数据预处理章节的标准内容（95% 论文有）
1. 数据概览（样本量、类别分布、尺寸、标注格式）
2. 缺失值处理（KNN/均值/中位数/众数，说明理由）
3. 异常值处理（IQR/分位数/可视化）
4. 类别编码（Label/One-Hot/Count）
5. 特征工程（构造比率、频率、统计特征）
6. 数据增强（翻转/旋转/色彩抖动/高斯模糊/随机擦除/Mosaic/MixUp）
7. 划分策略（7:3、8:2、9:1、5/10 折交叉验证、分层抽样）
8. 标准化（ImageNet 均值方差 / Min-Max / RankGaussian）

## 6. 技术栈库（按任务类型）

### 6.1 图像分类（CV 第一问）
- **骨干**：ResNet18/50、VGG16、DenseNet-121、GoogLeNet、MobileNetV3、EfficientNet、ViT [P23-2][P23-4][P25-2][P25-4]
- **改进**：注意力（CBAM/CA/GAB）、FPN 融合、轻量化（深度可分离卷积）[P25-1][P25-3][P25-4]
- **损失**：加权交叉熵、Focal Loss（α=0.7）[P25-4]
- **训练**：ImageNet 预训练 + 冻结骨干 + 替换分类头、Adam/AdamW、ReduceLROnPlateau/余弦退火、早停
- **评估**：Acc/Prec/Rec/F1、混淆矩阵（原始+归一化）、分类报告
- 真实结果参照：2023-2 DenseNet-121 准确率 99.34%、AUC 0.98 [P23-2]；2025-3 ResNet50+FPN+CA 96.84%/F1 97.77% [P25-3 p.14]

### 6.2 目标检测与分割（CV 第二问）
- **框架**：YOLOv5/v8/v11（主流）、Faster R-CNN、Faster R-CNN+U-Net 多任务 [P23-1][P25-1][P25-2][P25-3]
- **改进三件套**：多尺度融合（FPN+PAN/FPN+CA）、注意力（CBAM/增强 CA）、分割头+Dice Loss [P25-1][P25-3][P25-4]
- **损失**：CIoU/CIoU+Dice 联合、分类 BCE、λ1=1.0 λ2=0.5 [P25-1 p.17]
- **训练**：COCO 预训练迁移、AdamW+余弦退火、batch 32–96、300 epochs、Mosaic/MixUp/仿雨污渍增强 [P25-1 p.18]
- **评估**：mAP@0.5、mAP@0.5:0.95、各类 AP、P-R 曲线、混淆矩阵；**额外加 IoU 匹配脚本**（2025-1 平均 IoU 0.863）
- 真实结果参照：2025-1 mAP@0.5=0.809；2025-3 mAP@0.5=90.1%（分割头+Dice）

### 6.3 表格回归/分类
- **预处理**：KNN 填补、标签/独热编码、对数变换、分箱、特征构造
- **模型**：线性/Ridge/Lasso、决策树、随机森林、GBDT、XGBoost、LightGBM、CatBoost、KNN、SVM [P21-1][P21-6][P22-3][P22-4]
- **融合**：Stacking（常见两三层：基学习器→元学习器）、加权融合 [P21-6][P25-7]
- **调参**：网格搜索 + 5/10 折交叉验证、贝叶斯优化（HEBO）、Optuna [P21-3][P22-8]
- **解释**：特征重要性、SHAP [P25-7]
- **不平衡**：SMOTE、SMOTEABAG、类权重、欠采样、代价敏感 [P22-8][P25-6][P25-7]
- **指标**：R²、RMSE、MAE、MAPE、1-WMAPE、Accuracy/F1/CKS

### 6.4 时间序列
- **分解/统计**：ADF 检验、ACF/PACF、季节分解
- **模型**：ARIMA/SARIMA、指数平滑（Holt-Winters）、Prophet、XGBoost/LightGBM、LSTM/GRU、BP 神经网络 [P23-5][P23-6][P24-7]
- **组合**：按 1-WMAPE 赋权相加、分层/分群预测后集成、促销因子修正 [P23-5][P23-6]
- **序列分类**：KMeans/DBSCAN/层次聚类 + 手肘法/轮廓系数 [P23-7][P24-2]

### 6.5 运筹优化
- **建模**：0-1 整数规划、混合整数规划、多目标优化（成本/利用率/关联度）
- **求解**：PuLP+CBC、LINGO+SCIP、贪心、模拟退火、粒子群、NSGA-III（可改进：反向学习+动态交叉变异）[P22-2][P24-5][P24-6][P24-7][P24-8]
- **呈现**：方案图、收敛曲线、成本对比表

### 6.6 无监督/风险标注（2025 B 赛道特有）
- **分层+阈值拟合**：分位数分层（低/中/高金额层）→ 线性/指数/幂函数拟合阈值（R² 选最优）[P25-5]
- **单调分位边界学习 MQBL**：等频分箱→局部分位数→保序回归修匀→线性插值 [P25-7]
- **异常检测**：孤立森林 + One-Class SVM 构造决策边界 [P25-8]
- **业务约束**：合理诉求≥85%、严重超额≤3% [P25-7][P25-8]

## 7. 评估的维度与指标（问题 3 直接套用）

### 7.1 六个评估维度（来自 2025-3/2025-4/2025-1 的评估体系）
1. **准确性**：分类（Acc/P/R/F1、混淆矩阵）、检测（mAP@0.5/0.95、各类 AP、PR）、分割（Dice、IoU、像素准确率）、回归（R²、RMSE、MAE、MAPE）
2. **鲁棒性**：高斯噪声、亮度±30%、阴影/遮挡、雨污渍扰动；指标保持率（2025-3：F1 保持率>98%）[P25-3 p.9]
3. **效率**：单图推理时间（0.035–0.045 s）、FPS、参数量、FLOPs [P25-3][P25-4]
4. **泛化性**：跨数据划分/新样本验证（2023-2 用 681 张新图测到 96.34% [P23-2]）
5. **可解释性**：热力图/Grad-CAM、特征重要性、SHAP、雷达图 [P25-7][P25-1 p.25]
6. **模块有效性**：消融实验（逐模块加）、对照实验（基线 vs 改进）

### 7.2 消融实验的写法（必做）
- 表格形式：基线 / +模块 A / +模块 A+B，行=模型，列=指标（Acc/Prec/Rec/F1 或 mAP/参数量）[P25-3 p.14]
- 文字必须给**增量**："FPN 与 CA 分别提升 F1 1.64% 与 1.68%"。

### 7.3 对比实验的写法
- 同任务 3–4 个模型横向对比（2023-2 四种 CNN；2022-4 九种回归+Stacking 的十折对比，最终 SVR 胜出；2023-4 传统网络 vs ViT 融合）[P23-2][P22-4][P23-4]

### 7.4 误差分析与失败案例（加分项）

### 11.1 2021（二手车估价 A / 推荐序列 B）

**2021-1｜基于多模型 Stacking 融合的二手车定价销售策略研究（A）**
- 方法链：分组众数/KNN 填补 → 121 特征（分箱、保值率、淡旺季）→ SFS+双模型取交并集选 34 → XGB/LGB/CAT 贝叶斯调参 → Stacking。
- 独特技巧：按车型/品牌 id 众数修复国标码；长宽高与「距上次过户时长」拆分；成交周期拆为「调价周期+最佳成交周期」；以预测价为指导价上浮 3%–7% 定价（P13/P27）。
- 评估：0.2·(1−MAPE)+0.8·Acc5、调整 R²；11 模型横评+融合前后对比（P20-21）。
- 图表：评测公式（P13）、特征重要性条形图（P15）、Stacking 拟合曲线（P23）。
- 句式：「新车价是二手车交易价格最重要的特征影响因素」（P15）；「成交周期=调价周期+最佳成交周期」（P27）。
- 数字：Stacking 0.55410；XGB R²0.95005/MAPE 8.96%。

**2021-2｜信息流智能推荐算法中的序列评估问题（B）**
- 方法链：位置偏好权重+类别一致性 → e^(−λx) 大众偏好项 → GRU(点击)/RF(时长) → SOA 逐步剪枝(β)。
- 独特技巧：用历史位置权重替代 DCG 折损；一致性惩罚抑制同质堆叠；剪枝保留 [Minp, Minp+β(Maxp−Minp)]；提出近似率/优越性/时间性三指标（P24-25）。
- 评估：RMSE/MAE/MSE 四模型对比；β 灵敏度（重复 100 次）；对比贪心/模拟退火/遗传/随机（P27）。
- 图表：收益公式（P9）、四模型误差图（P13）、β 三指标趋势（P24-25）。
- 句式：「相似内容高度集中的推荐序列往往会带来较差的结果」（P7）。
- 数字：β=0.9 时近似率 97.3%，优越性与时间性均>95%。

**2021-3｜基于 Stacking 模型的二手车价格预测（A）**
- 方法链：异常剔除 → Johnson SU 正态化 → 众数填补 → label+目标统计编码 → Pearson+XGB 重要性 → HEBO 调参 → Stacking（LR 元模型）。
- 独特技巧：价格分布 Johnson SU 转换（偏度 −0.001）；构造城市/品牌价格统计量；自创评估方法折旧公式与「54321」里程法；按重要性从低到高逐次删除验证（P7/P19）。
- 评估：官方 0.2·(1−MAPE)+0.8·Acc5；三基模型 vs Stacking。
- 图表：正态转换对比（P7）、模型效果比较表（P13）、特征重要性排序（P19）。
- 句式：「Stacking 融合模型的预测效果均高于单一模型」（P13）。
- 数字：Stacking 0.5324（XGB 0.5286/LGB 0.5256/CAT 0.5261）。

**2021-4｜基于能量损失的 Transformer 和相似用户模型的推荐序列评估算法（B）**
- 方法链：用户画像+K-means（最大最小距离选心）→ Transformer 编码用户+时间 → 能量损耗损失 → 相似用户估计 → 0.5:0.5 加权 → 集束搜索+RL。
- 独特技巧：用「精力 Energy」解释正负浏览时长；损失含能量归零约束项；冷启动按类别分布相似度找最相似用户；z-score 归一收益作 reward（P4/P15）。
- 评估：无官方指标，双模型互补加权；对比集束宽与贪心。
- 图表：损失函数三项（P15）、混合模型公式（P18）。
- 句式：「假设用户在能量剩余小于等于 0 时不再继续浏览」（P4）。
- 数字：训练 3129.9 万条/测试 10 万；用户 102.7 万→7.16 万，重合 95.55%。

**2021-5｜信息流智能算法中序列收益评估模型的构建与研究（B）**
- 方法链：二级分类 290 → 290×290 优先网格 → 初始收益 E0 → 排序修正 → 时段/星期系数 → LFM 补全未浏览 → 轮盘赌剪枝。
- 独特技巧：以「交换次数/(F−1)²」量化排序收益；正态拟合字段长度曲线面积定 K；按收益反比设轮盘赌区间；优先网格随序列实时更新（P6-8）。
- 评估：500 序列误差≤1 占 93%；500 序列命中最优 90%；最坏复杂度 O(n²)。
- 图表：优先网格示意（P6-7）、时间收益分布（P8）、剪枝命中图（P18）。
- 句式：「推荐内容的排列组合关系，也会影响用户的浏览体验」（P3）。
- 数字：预测精度约 93%、最优序列约 90%。

**2021-6｜基于多模型融合与灰色关联分析的二手车交易问题研究（A）**
- 方法链：异常剔除+log1p → 众数/均值填补 → 17 类 one-hot（536 维）→ RF/GBRT/XGB/LGB 调参 → 双层 Stacking。
- 独特技巧：用训练-测试得分差诊断过拟合、逐参数压深度；一层 4 模型、二层 3 模型、末层 LR；XGB 重要性×灰色关联度融合排序（P12-23）。

**2021-7｜基于机器学习的二手车价格预测与销售策略研究（A）**
