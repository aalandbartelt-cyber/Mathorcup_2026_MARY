## 1. 与 2025 的关键变化

**本队文件名**：`A2601605.pdf` / `A2601605承诺书.pdf` / `A2601605附件.rar|zip`（赛道 A 为例）。

## 2. 论文格式（官方 7 条）

1. 赛道 A/B 任选；报名系统选的赛道必须与内容一致，不符**取消评奖资格**。
2. 第 1 页：题目、摘要、关键词；第 2 页：目录；正文从目录后开始；页脚居中阿拉伯数字从 1 连续编号。
3. 不能有页眉；不能出现答题人身份、学校等个人信息。
4. 中文写作；**正文 ≤30 页**，附录页数不限；排版（字号字体行距颜色）不强制，但要美观。
5. 参考文献：正文方括号编号；按引用顺序列；书籍标页码；期刊标卷期页码；网页标访问日期。
6. 附录：软件名称、命令、全部源程序；源程序保存至获奖名单公布。
7. 未规定项不做统一要求，保持页面美观。

## 3. 提交规范（官方 5 条）

1. 报名系统提交：电子版论文、承诺书、支撑材料、计算结果。
2. 论文 PDF 命名 `#*******.pdf`（题号 + 7 位队号），如 `A2600001.pdf`。
3. 承诺书每人手写/电子签名，扫描或拍照生成 PDF/JPG，命名 `#*******承诺书`。
4. 支撑材料（程序、数据（原始数据除外）、结果）可打包，命名 `#*******附件.rar` 或 `.zip`；非强制。
5. 计算结果按题目要求上传；题目未要求则不强制。

**提交操作**：赛氪 `https://www.saikr.com/vse/bigdata2026` → 报名管理 → 电子档 → 上传论文并选题 → 点“提交电子档”（修改点“更新电子档”）→ 状态显示“电子档已提交”。
