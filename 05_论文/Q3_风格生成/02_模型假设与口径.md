# 问题三模型假设与口径（研究版）

为简化问题，本文拟作出以下假设；每条均需在正式实验中检验，不能以假设替代结果。

E200核验补充：70个可识别尺度字段不等于每个单元格完全一致；80个正值对应不一致与3个负参考值已单列。假设1的绝对约束只用于逐条核验的观测，详见`03_E200数据核验与口径补充.md`。

**假设1：经字段级核验后，同一化学测量在样本之间具有可比尺度。** 依据是附件1与附件8可按beer逐项对照；已识别37个log10字段与33个原尺度字段。若映射或单位不一致，停止该字段的绝对阈值计算，其余未核验字段只用已知存储尺度，不擅自反变换。

**假设2：不同风格可以共享部分低维化学共变结构。** 数据仅250款、231个字段，而目标风格只有10—28款，支持把共享结构作为可检验的简化。若留出分布或关键缺陷的信息损失明显，则改用全维收缩或局部经验模型，不能仅凭解释方差较高保留低维模型。

**假设3：风格参数可以部分向共享残差结构收缩。** 小风格难以独立估计稳定协方差，故以训练折内选择的收缩强度控制方差。若收缩抹去目标风格特征，则降低收缩或切换备选；不能用外层留出集选择该强度。

**假设4：Q1预测器在训练支持域附近可提供带误差的感官画像。** 依据来自本队逐目标OOF，而非对合成样本的实测。低可靠维度仅作弱证据；候选远离训练域或不同画像器分歧过大时，降低可信度或拒绝，不宣称有真实感官安全保证。

**假设5：满足统计与可核验化学约束的谱可作为设计候选。** 题目没有配方、发酵状态转移或干预对，故模型只在化学谱空间中讨论生成和迁移。若要转为酿造建议，必须补充工艺映射与新实测，不能把Q2相关关系直接解释为可单独调控的因果效应。

## 清洗与缺陷定义

| 项目 | 固定处理 | 必须保留的限制 |
|---|---|---|
| 主键/输入 | beer对齐；不使用beer_id；Q1模型输入保持完整字段契约 | Q2的218单体白名单不等于Q3全部输入 |
| 缺失 | 折内插补并保留标识；不删异常样本 | 源缺陷缺失不能用一次插补认证浓度不升 |
| 地板 | 地板状态与非地板连续值分开评估 | 未知LOD下不能把校准零认作真实零 |
| 派生值 | 仅按核验公式重算，否则软一致性审计 | 不对对数值求和，不发明恒等式 |
| 量表 | 标准化连续感官值为主，0—6只展示映射 | 不宣称恢复原始评分 |
| C1主情景 | 已知直接缺陷浓度不高于源值 | 未知/删失列单列，不并入100%分母 |
| C2敏感性 | 超阈值相对负担不升 | 阈内允许上升，不等价C1 |
| C3敏感性 | 上限min(源值,阈值) | 这是额外要求；源原本超阈时零迁移也可能不可行 |
| Stale hops | 报告预测相对变化、模型误差与支持域 | 非单一化合物，不能给未经验证的真实不恶化率 |

本页是可并入总论文的研究稿；最终仅保留实际采用模型需要的假设，并把检验结果、失败与放宽条件补齐。未来Word公式必须为原生OMML，沿用指定Q3模板样式。
