# 问题三补充检验数据

本目录保留固定生成谱的诊断、逐字段独立置换、真实结构消融、迁移分母及锁定候选的裕量敏感性。主生成模型、画像数字与主规则候选没有重新拟合或选择。

## 统计汇总

外层十次重复，每次三折；每折每目标风格五个生成种子。450组固定谱各作五次逐字段独立行置换，形成2250组诊断。每组各字段的经验边缘完全不变，仅破坏化合物之间的样本配对。评价使用对应训练折中位数、1%–99%分位边界及稳健尺度。

`独立置换逐重复差.csv`先平均置换、生成种子和折，单位为风格×外层重复；差为置换−原谱。`独立置换汇总.csv`的标准差描述十次重复扰动，不是独立置信区间。三个目标风格等权，五个随机种子不增加真实啤酒数。风格标签置换和未见风格生成泛化未检验。

## 数据表

- `生成缓存完整性.csv`：逐组样本数、字段数、有限性及训练验证分离。
- `固定生成谱诊断.csv`、`独立置换诊断.csv`：逐组原谱与置换诊断。
- `主模型逐风格逐重复.csv`、`主模型逐风格检验.csv`、`主模型逐重复检验.csv`：原尺度与稳健尺度并列。
- `结构消融逐重复.csv`、`结构消融汇总.csv`：共享低秩、风格残差收缩、风格残差与地板状态，均为实际已有结构比较。
- `迁移阶段分母核验.csv`：早期策略记录与当前源—目标任务的分母；Pareto标记为并行属性。
- `固定候选裕量敏感性.csv`：两条原锁定主候选的0/0.01/0.02z裕量，不重新选谱。
- `表6_补充检验.csv`、`表7_结构消融.csv`与`补充检验摘要.json`：论文引用所需摘要。Word中表6为精简三列，完整机读表保留更详细口径。

两条待实测统计候选均来自同一源；加0.01z裕量后均不再满足。近训练复制率0只对应当前数值容差。小风格相关结构证据有限，未知直接浓度和绝对阈值继续保留未决；生成谱不等于已实现的酿造处方。
