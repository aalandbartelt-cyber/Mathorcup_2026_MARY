# 第二问结果与讨论

> 当前状态：既有统计排名与化学分级已完成，作为后续证据优化的基线；不构成化学因果结论。

正式结果至少包含：逐目标 OOF 性能、150 条严格化合物 Top-3、全部测量因素敏感性结果、bootstrap 入选频率与秩区间、方法间一致性、模块稳定性、风格敏感性、正负对照、化学证据等级和失败目标说明。所有正文数字必须由 `03_结果/Q2_关键化合物/` 的机器可读表自动生成。

讨论顺序固定为：先判断目标是否可预测，再解释 Top-3；先报告字段级稳定性，再说明模块内替代；先区分总关联与风格校正关联，再讨论化学机制；最后给出观测数据不能支持的因果与外推边界。

## Spearman边际模型—有符号图ElasticNet模型 阶段结果

Spearman Top-3、PLS/VIP、ElasticNet 和有符号图 ElasticNet 的宏平均 MAE 分别为 0.3843、0.3556、0.3529 和 0.3530，宏平均 $R^2$ 分别为 0.1064、0.2089、0.2086 和 0.2084。ElasticNet模型 平均有 49.0/50 个目标取得正 $R^2$。这些结果支持“条件稀疏选择优于单变量相关”，但不支持“图惩罚提高预测精度”。

有符号图ElasticNet模型 相对 ElasticNet模型 的宏 MAE 在 10 次重复中平均增加 0.00011，只有 3/10 次重复的 MAE 更低；宏 Spearman 平均增加 0.00017，量级很小。图参数敏感性分析 将 L1 下界扩至 0.003、L2 上界扩至 10、β 上界扩至 12；ElasticNet模型 的选参、OOF 指标和 50 个 Top-3 集合均完全不变，说明 L2=1 是当前数据下的实际最优点。有符号图ElasticNet模型 虽有 20/30 折选择 β>6，宏 MAE 却进一步增加 0.000071，宽/窄网格 Top-3 平均 Jaccard 为 0.91。因此图惩罚降为解释性消融，不再作为预测主线。

## 非线性归因验证器 非线性条件重要性

本问的非线性归因验证器是独立拟合的ExtraTrees，用于条件置换检验，不以第一问最终堆叠模型的预测作为输入。它沿用相同划分下的基线参数；与ExtraTrees基线的OOF预测最大差为$1.18\times10^{-7}$。模型的宏平均 $R^2$、MAE 和 Spearman 分别为 0.2359、0.3422 和 0.4144，相对 ElasticNet模型 分别改善 0.02726、0.01070 和 0.02263；10 次重复的 MAE 均更低，因此将其保留为归因验证方法。

为降低共线化合物之间的重要性错分，字段置换限制在“最强折内 Spearman 邻居”的训练折四分位组内；同时对折内 $|\rho|\ge0.70$ 连通模块做联合置换。150 条字段级 Top-3 的中位误差增量均为正，但入选频率中位数仅为 0.40；与 ElasticNet模型 Top-3 的平均 Jaccard 为 0.124。直接锚点中，4VG、乙醇—Alcohol、乙醇—Body 和 CO2 的聚合排名分别为 3、2、1 和 3；DMS、Diacetyl 和 trans-2-nonenal 排名较后。这一分歧要求最终结果同时报告字段与模块证据，并经 三方法秩共识–风格校正与留一风格分析 共识、bootstrap 和风格校正后才能写入结论。

## 三方法秩共识 三方法统计共识

三方法秩共识 对边际 Spearman、ElasticNet 条件稀疏系数和 ExtraTrees 非线性条件置换三类排名等权融合。先比较各候选在三种方法中的 Top-10 和 Top-3 支持数，再以 $k=60$ 的倒数秩融合分数排序。不使用事后性能权重，避免把预测优势直接等同于化学证据。

50 个目标的 150 条候选中，41 条在三种方法中均进入 Top-10 且至少两法进入 Top-3，标记为 S1 强统计共识；90 条为 S2 中等共识；19 条为 S3 探索性候选。方向共识为正、负和不确定的候选分别有 119、30 和 1 条。加入 PLS/VIP 的四方法敏感性中，Top-3 平均 Jaccard 为 0.652，仅 17/50 个目标完全一致。因此 S1–S3 是统计支持层级，不是最终化学证据等级；仍需 分层自助稳定性分析 bootstrap 和 风格校正与留一风格分析 风格敏感性决定最终 Top-3。

## 分层自助稳定性分析 分层 bootstrap 稳定性

分层自助稳定性分析 在 22 种啤酒风格内分别有放回抽样，保持每种风格的样本数不变，共执行 500 次 bootstrap。每次重算边际 Spearman、固定惩罚参数的 ElasticNet 与 ExtraTrees 条件置换重要性，再按 三方法秩共识 的等权规则融合；树模型的重要性只在该次未入袋的 73–104 个样本上计算。该设计把样本扰动、共线字段替代和非线性模型波动同时纳入稳定性评估，且没有使用全数据图或全数据预处理量。

150 条 bootstrap 聚合 Top-3 的入选频率范围为 0.182–0.992，中位数为 0.428；达到 0.60、0.70 和 0.80 阈值的候选分别有 43、31 和 23 条。不同 bootstrap 的逐目标 Top-3 两两 Jaccard 均值为 0.245，校正随机重合后的 Kuncheva 指标均值为 0.340。这表明多数感官维度存在明显的共线替代与样本敏感性，不能把每个排序前三的字段等同为唯一关键化合物。按共聚类频率 0.70 构造后得到 170 个稳定模块，其中 155 个为单字段模块，最大模块含 15 个字段；正文应同时报告字段入选频率和所属稳定模块。

正对照中，4VG 对 4-vinyl guaiacol 的 bootstrap 排名为 1、入选频率 0.992；乙醇对 Alcohol 和 Body 的排名均为 1，入选频率分别为 0.920 和 0.812。CO2 对 Carbonation 的排名为 4、入选频率 0.318；DMS、Diacetyl 和 trans-2-nonenal 对同名缺陷感官的排名分别为 29、92 和 61。后一结果说明低信噪比目标、共线代理及标准化感官评分会削弱直接锚点恢复，因此缺陷化合物不能只依据统计 Top-3 排除或确认，需在 风格校正与留一风格分析 后结合附件 8 阈值、老化/异味注释和外部化学文献分级。

## 风格校正与留一风格分析 风格校正与留一风格检验

风格校正与留一风格分析 在每个外层训练折内分别估计 22 种风格的化学均值和感官均值，再将该训练折均值应用到训练与验证样本。验证折本身不参与均值估计，未见风格回退到训练折全局均值；缺失值仍交由后续折内预处理。由此得到的排名描述同一风格内部的化学—感官关系，而 三方法秩共识 描述风格间与风格内共同作用下的总关联。

为排除固定参数和聚合方法本身造成的变化，另在完全相同的 10×3 划分与固定参数下计算未校正对照。该对照与 三方法秩共识 的 Top-3 平均 Jaccard 为 0.672、19/50 个目标完全一致；同一固定参数下，未校正与风格校正结果的平均 Jaccard 仅为 0.264，中位数为 0.2，只有 2/50 个目标完全一致。三方法秩共识 与风格校正结果的平均 Jaccard 同样为 0.260。故排名变化主要来自风格效应的剔除，而不是参数固定或聚合口径差异。

进一步逐一删除 22 种风格，并在剩余样本上用冻结的 3 折重新估计三类排名。相对于同口径 3 折参照，1,100 个“风格—目标”组合的 Top-3 平均 Jaccard 为 0.523，中位数为 0.5；三方法秩共识 的 150 条候选在 22 次删除中的平均保留率为 0.641，中位数为 0.682。删除 Low/No alcohol、Strong ale、Blond 和 Kriek 后的目标平均 Jaccard 较低，分别为 0.466、0.466、0.470 和 0.476，但不同风格之间差异不大，不将其解释为单一决定因素。

直接锚点经风格校正后，4VG 对同名感官仍排第 1，乙醇对 Alcohol 排第 2、对 Body 排第 5，CO2 对 Carbonation 排第 3；DMS、Diacetyl 和 trans-2-nonenal 分别降至 127、158 和 144。该结果支持 4VG、乙醇和 CO2 的跨风格关系，同时提示三个低强度缺陷维度的样本级信号不足。最终排名必须并列呈现总关联与风格内关联，并把只在总关联中靠前的候选标记为风格敏感。

## 四路稳健秩融合 四路稳健统计排名

四路稳健秩融合 将 三方法秩共识 总关联共识、分层自助稳定性分析 bootstrap 稳定排名、风格校正与留一风格分析 风格内排名和留一风格保留排名视为四个等权证据源。每个证据源只提供 1–218 的秩，融合时优先比较四路 Top-10 和 Top-3 支持数，再计算 $k=60$ 的倒数秩分数；不同模型的重要性数值不直接相加。

最终 150 条统计 Top-3 中，38 条满足 R1 强稳健、52 条为 R2 中等稳健、60 条为 R3 探索性。融合 Top-3 与总关联、bootstrap、风格校正和留一风格排名的平均 Jaccard 分别为 0.546、0.670、0.386 和 0.586；相应完全一致目标数为 10、20、4 和 14。结果更接近重采样稳定排序，同时保留了风格内证据，但风格内一致性仍最低。

按 非线性归因验证器 的逐目标 OOF $R^2$，50 个目标中 22 个为 P1（$R^2\ge0.20$）、12 个为 P2（$0.10\le R^2<0.20$）、16 个为 P3（$R^2<0.10$）。题面要求每个维度均输出前三，因此 P3 目标仍保留三条候选，但一律在表中标为弱预测背景。严格候选范围内，4VG—4VG、乙醇—Alcohol、乙醇—Body 和 CO2—Carbonation 四个直接锚点进入最终 Top-3；DMS、Diacetyl 与 trans-2-nonenal 未进入，分别排 53、102 和 71。统计排名只完成“稳定候选”判断，不能替代 化学证据分级 的化学证据分级。

## 化学证据分级 化学合理性与证据等级

化学核验在 四路稳健秩融合 排名冻结后进行，不参与模型选择。对附件 8 中同时具有原始校准浓度和同字段、同单位感知阈值的候选计算 OAV；150 条结果中 73 条满足计算条件，其中 23 条的全样本中位 OAV 不低于 1。其余字段不以 `1.csv` 的 log10 数值直接除以阈值。OAV 只判断单体浓度是否达到阈值量级，不处理混合物协同、掩蔽、基质与个体差异。

综合字段身份、直接锚点或描述词、附件来源/老化/异味注释、同行评议文献、统计稳健性和目标可预测性，150 条候选的 A/B/C/D 级分别为 8、16、78 和 48 条。A 级关系包括乙酸乙酯—酯香指甲油（Aroma 与 Flavour）、4VG—4-vinyl guaiacol、乳酸—Acidity、乙醇—Alcohol、乙醇—Body、CO2—Carbonation 和乳酸—Lactic acid。乙酸乙酯的中位 OAV 为 1.203，乙醇为 4.140；4VG 和乳酸的全样本中位 OAV 分别为 0 和 0.346，但前者具有高度稳定的同名锚点，后者受多酸协同和风格分布影响，因此保留 A 级并明确阈值限制。

B 级主要包括乙酸异戊酯—香蕉酯香、麦芽吡嗪—焦香、酒花来源萜类，以及芳樟醇/柠檬烯类—芫荽或橙香。C 级表示统计支持或宽泛化学关系存在但证据不完整；D 级同时缺少特异化学支持或处于弱预测背景。尤其是 Clove 的前三为 limonene、eucalyptol 和 linalool，虽部分浓度高于各自阈值，却不属于丁香味特异锚点，故不因 OAV 较高而升级。DMS、Diacetyl 和 trans-2-nonenal 的同名字段也未进入前三，因此相应输出只能视为数据驱动的探索性替代物。
