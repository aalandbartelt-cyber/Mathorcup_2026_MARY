# 第二问方法与实验矩阵（设计稿）

## 首选模型

对训练折内的 Spearman 相关系数定义软权有符号图

\[
a_{jk}=|\rho_{jk}|^\beta,\qquad s_{jk}=\operatorname{sign}(\rho_{jk}),
\]

并用归一化有符号图惩罚

\[
\Omega_G(b)=\sum_{j<k}a_{jk}
\left(\frac{b_j}{\sqrt{d_j}}-s_{jk}\frac{b_k}{\sqrt{d_k}}\right)^2,
\qquad d_j=\sum_k a_{jk}.
\]

第 $t$ 个感官目标的主选择器为

\[
\hat b_t=\arg\min_b\frac{1}{2n}\|y_t-Xb\|_2^2
+\lambda_1\|b\|_1+\lambda_2\|b\|_2^2+\lambda_G\Omega_G(b).
\]

L1 项产生稀疏选择，L2 项缓和共线，图项使正相关邻居倾向同向、负相关邻居倾向反向。实现时可由图拉普拉斯平方根构造增广数据并调用 sklearn ElasticNet，无需增加求解器依赖。

主选择器之外，独立拟合ExtraTrees基线作为本问非线性归因验证器：先在折外联合置换相关模块，再在高贡献模块内做残差条件置换。PLS/VIP 作为化学计量学对照。三种方法输出完整排名，以中位秩或 Robust Rank Aggregation 形成共识；SHAP 只作候选局部解释，不作为唯一排名来源。

## 稳定性设计

先做 100 次试运行确认计算成本和入选频率收敛，再做 500 次按风格分层 bootstrap。每次从填补、构图、调参到排名全部重跑。对候选 $j$ 和目标 $t$ 的 Top-3 入选频率为

\[
\hat\pi_{jt}=B^{-1}\sum_{b=1}^{B}I\{j\in\operatorname{Top3}^{(b)}_t\}.
\]

同时保存中位秩、四分位距、方向一致率、具体字段频率、模块频率、方法间 Jaccard、重采样 Jaccard、Top-10 秩相关和 Kuncheva 指数。最终阈值在 0.60、0.70、0.80 上做敏感性，不能把某一阈值写成自然常数。

## 实验矩阵

| 实验 | 方法 | 核心问题 | 定位 |
|---|---|---|---|
| 字段与候选核验 | 数据、候选与图合同 | 字段身份、资格、Spearman 和图统计能否复现 | 必做 |
| Spearman边际模型 | 绝对 Spearman Top-3 | 最低边际相关基线 | 对照 |
| PLS/VIP模型 | PLS/VIP | 高维共线下的化学计量学排序 | 对照 |
| ElasticNet模型 | ElasticNet | 去掉图先验后的稀疏选择 | 消融 |
| 有符号图ElasticNet模型 | 有符号图约束 ElasticNet | 图结构能否改善预测与稳定性 | 主线 |
| 非线性归因验证器 | ExtraTrees + 折外模块/条件置换 | 非线性贡献是否支持主线 | 主线 |
| 三方法秩共识 | 三方法稳健秩共识 | 形成逐目标候选榜 | 主线 |
| 分层自助稳定性分析 | 500 次分层 bootstrap | 字段级、模块级稳定性 | 主线 |
| 风格校正与留一风格分析 | 风格校正 + 留一风格 | 排除风格驱动 | 主线 |
| 图参数敏感性分析 | 图参数、候选资格、聚合量消融 | 参数与口径敏感性 | 主文或附录 |
| 图神经网络候选 | 小型 GNN | 深度图模型是否产生稳定增益 | 条件触发 |
| 四路稳健秩融合 | 四路稳健秩融合 | 汇总总关联、bootstrap、风格内与逐风格删除排名 | 最终统计排名 |
| 化学证据分级 | OAV、描述词与文献证据分级 | 区分统计稳定与化学合理性 | 最终证据层 |

## 模型比较与证据检验

主模型进入最终答案需同时满足：折外预测不明显退化、Top-3 稳定性提高、直接感官锚点恢复率不下降、风格删除结果可解释、负对照不过度入选。若 有符号图ElasticNet模型 不优于 ElasticNet模型，取消图惩罚但保留图用于模块置换和解释；若 非线性归因验证器 的条件重要性与 有符号图ElasticNet模型/PLS 长期分歧，则以折外删除和置换证据为主并降低证据等级。图神经网络候选 仅在主线完成后运行，只有折外性能、Top-3 稳定性和化学正对照同时改善才进入正文。

实际执行中，有符号图ElasticNet模型 未改善 OOF 误差，且 分层自助稳定性分析 已显示样本扰动是主要不确定性来源，因此 图神经网络候选 未触发。最终统计排名由 四路稳健秩融合 对 三方法秩共识 总关联、分层自助稳定性分析 bootstrap、风格校正与留一风格分析 风格校正和留一风格删除四路完整排名等权融合；先比较四路 Top-10 与 Top-3 支持数，再使用 $k=60$ 的倒数秩分数。化学证据分级 在统计排名冻结后独立追加化学证据，避免用已知机理反向挑选模型。
