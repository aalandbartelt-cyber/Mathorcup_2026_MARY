基于收缩集成与条件Copula 的啤酒感官预测及风格生成 
摘 要 
啤酒风味同时受到化合物共变、风格差异和感官量表的影响。本文基于250 款啤酒
的231 项测量与50 维标准化感官数据，研究缺失条件下的感官评分、关键化合物识别
及风格条件生成与迁移。 
针对问题一，在化学测量存在缺失、感官目标为标准化连续值的条件下，建立感官
组收缩非负最小二乘（NNLS）堆叠模型，利用极端随机树、直方图梯度提升、岭回归
和偏最小二乘提取互补预测，将感官家族权重向共享权重收缩，以控制逐目标独立拟合
的不稳定性。缺失填补和特征变换均在训练折内完成，通过训练经验分布单调映射形成
相对强度，再就近展示为0-6 七档相对评分。采用主动集NNLS 求解，并以10 次重复
3 折外层验证评价，重复宏平均决定系数为0.2564、平均绝对误差为0.3361。误差按标
准化尺度计算，七档输出不等同于原始品评分恢复。 
针对问题二，在化合物相关数据与实测特征均已给定、关键因素限定为严格单体的
条件下，先以化合物共表达网络描述候选之间的共变，再建立四路稳健秩融合模型，综
合总关联、分层自助、风格校正与留一风格名次，按支持数及倒数秩确定前三项。以化
学身份、浓度与阈值的可比性及气味活性值核验合理性，感官模型条件归因仅作独立解
释。经重采样与逐风格删除检验，在218 个严格单体中给出50 维各3 项、共150 条关
系；bootstrap 入选频率中位数为0.395，其中40 条不低于0.60，乙醇-酒精感、乳酸-酸
度等8 条关系具有A 级化学证据。 
针对问题三，在风格标签已知、目标风格样本较少且迁移须满足缺陷不恶化约束的
条件下，建立风格条件收缩Copula 模型，以经验边缘保留字段分布，用收缩相关矩阵
描述化合物依赖，并调用感官预测器形成画像。对跨风格迁移建立最小改动约束路径模
型，在源谱与目标端点之间搜索，将已知缺陷物质浓度不升纳入约束，陈旧酒花味用感
官代理检验，未知项不判为通过。经分位反变换抽样与有限候选枚举，为Tripel、Kriek、
Lambic 各生成300 条谱及画像，训练折稳健尺度的边缘一阶Wasserstein 距离为0.4762。
33 组迁移任务形成2 条同源待实测统计候选，向Tripel 和Kriek 的目标距离分别下降
38.36%和37.36%，但对代理裕量敏感。 
折外验证、重采样、置换及裕量检验分别考察预测误差、关联稳定性与生成迁移边
界。模型给出可核对的相对评分、关键关联和统计画像，迁移候选仍需独立测量与品评
验证。 
关键词：啤酒感官预测；非负堆叠；稳健秩融合；条件Copula；约束迁移

一、 问题重述 
1.1 问题研究背景 
啤酒的感官特征由多种化合物及其相互作用共同形成。同一化合物可能对应多
个描述维度，风格差异又会改变化学组成与感官响应的分布。仅依据单变量相关筛选
成分，容易混淆共线替代与风格效应；仅依据预测均值设计新谱，也无法保证生成样
本保留真实化学依赖。因而，感官预测、关键成分识别和风格生成需要共用可核对的
数据与预测接口，同时采用各自适当的验证证据。 
1.2 问题回顾 
问题一要求依据附件1，给出附件3 所定义Aroma、Flavour 等维度的0-6 分级
评分。问题二要求利用附件2 构建共表达图，结合附件1，为每个维度给出Top-3 化
合物及稳定性和化学论证。问题三要求以tasting_category_fine 为条件，生成Tripel、
Kriek、Lambic 等风格的化合物谱与感官画像，并在跨风格迁移时检查DMS、双乙
酰、4VG、反-2-壬烯醛及陈旧酒花味等缺陷。下文依次给出评分接口、50 维完整前
三项结果及有约束的统计候选。 
二、 问题分析 
2.1 问题一分析 
本问属于小样本、多输出连续回归。输入维数接近样本量，化学字段共线且各感
官家族可预测性不同，单一高自由度模型易产生不稳定预测。本文以非线性树模型为
基线，联合梯度提升、线性收缩和低秩多输出模型，通过感官组非负最小二乘（NNLS）
堆叠与共享权重收缩控制方差。训练、变换和模型选择嵌入外层验证，并将连续误差、
排序诊断及逐目标可靠性分开评价。附件感官值已标准化，原始评分不可唯一反演，
故0-6 只表示训练经验分布下的相对强度。 
2.2 问题二分析 
关键成分识别同时受共线替代、风格混杂和方法偏好影响。本文先界定严格单体
候选，再以边际关联、稀疏回归和条件置换构造统计证据，将总关联、分层自助、风
格校正及留一风格结果融合为稳健名次。第一问预测器的模块与字段归因用于检视
模型依赖，化学身份和气味活性值用于核验合理性，二者均不回写最终排序。负对照、
直接锚点和折内字段遮蔽分别检查噪声入选、已知关系恢复及预测敏感性，避免把统
计前三项解释为因果或充分性结论。 
2.3 问题三分析 
风格生成需要同时保持字段边缘、联合依赖和样本离散程度，而目标风格样本稀
少，不适合无约束估计高维协方差。本文以经验边缘与收缩正态Copula 建立条件分
布，以留出分布距离、几何覆盖及结构消融检验生成质量；随后调用第一问接口形成
画像，并在可核验直接浓度与感官代理约束下搜索最小改动候选。未知浓度、检测地
板和模型外推分别保留状态，通过固定候选裕量检验明确统计迁移的边界。 
三问技术路线如图1 所示。本文在统一数据口径下衔接感官预测、关键成分识
别及风格生成迁移。第二问的正式Top-3 由四路排序确定，NNLS 归因仅作独立解
释；该排序不作为第三问优化输入。第三问调用同一预测器形成画像并检验代理约
束，0-6 七档仅表示相对强度。

三、 模型假设 
假设1：按beer 对齐后，每行代表一款可比较的啤酒，字段具有一致测量含义。
附件主键唯一性与字段核对支持这一处理；若新增批次或重复样品，应改用批次分组
验证并重新校准尺度。 
假设2：在当前已观测字段条件下，折内中位数填补与缺失指示可用于预测缺失
项。该假设只服务于统计建模；若获得检测限或非随机缺失证据，应采用删失模型或
分层处理，缺失浓度仍不得作为缺陷安全上限。 
假设3：附件标准化感官值可作为连续监督信号，训练折经验分布可用于相对等
级展示。缺少原始评委中心与尺度时，不假设能恢复0-6 原始均分；取得原始评分后，
应重新进行量表校准。 
假设4：样本内化学-感官关系可在训练支持域附近用于预测与关联筛选。重复
验证和风格扰动用于检验局部稳定性；若候选离开支持域或跨模型方向不一致，则降
低解释强度，不推及未见风格或因果干预。 
假设5：风格经验边缘与收缩依赖足以构成生成的统计近似。若留出联合距离、
相关诊断或离散程度恶化，应保留相应消融结果并限制画像用途；生成数量和随机种
子不增加真实样本量。 
假设6：已知直接浓度约束与固定代理约束下的路径搜索可用于形成待实测候
选。该假设不涵盖配方、发酵过程与物理安全；若要提出生产建议，需补充独立浓度
测量、工艺可行性和感官品评。

from __future__ import annotations 
 
from dataclasses import dataclass 
 
import numpy as np 
from scipy.optimize import nnls 
 
 
@dataclass(frozen=True) 
class NNLSStackingFit: 
    weights: np.ndarray 
    intercept: np.ndarray 
    global_weights: np.ndarray 
    scope: str 
    shrinkage: float 
 
    def predict(self, stack) -> np.ndarray: 
        values = np.asarray(stack, dtype=float) 
        if values.ndim != 3 or values.shape[1:] != self.weights.shape: 
            raise ValueError("prediction tensor must have the fitted 
targets/models shape") 
        if not np.isfinite(values).all(): 
            raise ValueError("prediction tensor must be finite") 
        return np.einsum("ntm,tm->nt", values, self.weights) + self.intercept 
 
 
def _solve(centered_stack, centered_y, scales) -> np.ndarray: 
    design = (centered_stack / scales[None, :, None]).reshape(-1, 
centered_stack.shape[2]) 
    response = (centered_y / scales[None, :]).reshape(-1) 
    if not np.any(design): 
        return np.zeros(design.shape[1], dtype=float) 
    weights, _ = nnls(design, response, maxiter=max(100, design.shape[1] * 30)) 
    return weights

def fit_nnls_stacking(stack, y, *, groups=None, scope="shared", shrinkage=.5) 
-> NNLSStackingFit: 
    """Fit on outer-training inner-OOF predictions and their training labels 
only. 
 
    Weights are nonnegative but need not sum to one. Target centering removes 
    intercepts before NNLS, so an intercept is free to be negative afterward. 
    Standardizing each training target gives shared/group fits equal target 
units. 
    """ 
    predictions, truth = np.asarray(stack, dtype=float), np.asarray(y, 
dtype=float) 
    if (predictions.ndim != 3 or min(predictions.shape) < 1 
            or predictions.shape[0] < 3 or truth.shape != predictions.shape[:2] 
            or not np.isfinite(predictions).all() or not 
np.isfinite(truth).all()): 
        raise ValueError("finite samples-by-targets-by-models predictions must 
align with y") 
    if scope not in {"shared", "group", "target"}: 
        raise ValueError("scope must be shared, group or target") 
    if not np.isfinite(shrinkage) or not 0 <= shrinkage <= 1: 
        raise ValueError("shrinkage must be in [0, 1]") 
    if scope == "group" and (groups is None or len(groups) != truth.shape[1]): 
        raise ValueError("group labels must cover all registered targets") 
    means = predictions.mean(axis=0) 
    target_means = truth.mean(axis=0) 
    centered, y_centered = predictions - means, truth - target_means 
    scales = np.std(truth, axis=0) 
    scales = np.where(scales > 1e-12, scales, 1.) 
    global_weights = _solve(centered, y_centered, scales) 
    weights = np.tile(global_weights, (truth.shape[1], 1)) 
    if scope != "shared": 
        labels = np.arange(truth.shape[1]) if scope == "target" else 
np.asarray(groups, dtype=str) 
        for label in dict.fromkeys(labels.tolist()): 
            positions = np.flatnonzero(labels == label) 
            local = _solve(centered[:, positions], y_centered[:, positions], 
scales[positions]) 
            weights[positions] = (1. - shrinkage) * local + shrinkage * 
global_weights 
    intercept = target_means - np.einsum("tm,tm->t", means, weights) 
    return NNLSStackingFit(weights.copy(), intercept.copy(), 
global_weights.copy(), 
                           str(scope), 1. if scope == "shared" else 
float(shrinkage))

def _psd_factor(matrix): 
    """Return a symmetric PSD matrix and a cached sampling factor.""" 
    symmetric=(np.asarray(matrix,float)+np.asarray(matrix,float).T)/2. 
    eigenvalues,eigenvectors=np.linalg.eigh(symmetric)

    return psd,eigenvectors*np.sqrt(eigenvalues)
