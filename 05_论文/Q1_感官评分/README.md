## DOCX 交付口径

最终文件为 `第一问_论文正文_v1.docx`，版式直接继承国赛 C 题第一问模板的 `Heading 1/2/3`、`Body Text`、表格和公式 1×3 编号样式。正文层级为“问题一模型建立与求解—问题一分析—问题一模型—问题一求解—模型检验与结果讨论”。V1 已嵌入用户确认的 4 张主图和附图 S1，图表均在正文中引用。

公式必须使用 Word 可编辑的原生专业 OMML 结构。分式、上下标、带限求和分别使用 `m:f`、`m:sSub/m:sSup/m:sSubSup`、`m:nary`；禁止公式图片、Unicode 伪上下标和单一 `m:t` 线性字符串。公式置于 1×3 无边框表的中间单元格，编号在第三列；生成后必须同时通过 OOXML 结构检查和 PDF 渲染检查。
