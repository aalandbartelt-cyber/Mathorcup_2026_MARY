# 第一问方法与实验矩阵（论文稿）

## 主线

1. 训练折中位数填补并添加缺失指示；线性与低秩模型在折内缩放，树模型保留原尺度。
2. E0 全局均值、E1 收缩风格均值、E2 Ridge/Elastic Net、E3 PLS2 构成最低基线组。
3. E4 岭降秩回归学习 50 个目标的共享结构；E5 ExtraTrees 与 E6 轻量 Gradient Boosting/XGBoost 捕捉非线性阈值。
4. E7 在内层 OOF 中按目标选择低秩与树模型的凸组合权重。
5. E8 TabPFN 是第一深度候选；E9 TabM、E10 核岭/ARD-GP、E11 折内化合物图 GCN 只有在前置诊断和复现条件满足时运行。

## 验证与指标

- 主验证：10×3 重复风格分层外层交叉验证；内层 3 折调参。
- 压力测试：22 次留一风格验证。
- 逐目标指标：R²、MAE、RMSE、Spearman ρ、校准截距/斜率与 90% 共形区间覆盖率。
- 汇总：宏平均与中位数、五个目标组、达到 R² 阈值的目标数、最易/最难目标、风格 MAE 和啤酒配对 bootstrap 置信区间。

## 增强模型晋级规则

增强模型进入最终方案需同时满足：宏平均 OOF MAE 改善至少 1% 且配对 bootstrap 95% 区间支持改善；至少 30/50 个目标不退化；10 次重复中至少 7 次改善；留一风格 MAE 不恶化超过 2%；最差目标和小风格无灾难性退化；支撑材料可复现。

## 消融

- A1：去掉缺失指示；
- A2：去掉 5 个汇总化学字段；
- A3：加入风格 one-hot；
- A4：留一风格；
- A5：经验分位数与稳健仿射 0—6 映射。
