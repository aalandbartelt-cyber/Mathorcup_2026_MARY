# 第一问当前论文图件

当前版本位于`final_v4/`，四张主图加一张附图，均提供300dpi PNG和SVG。旧版已移入交付目录之外的历史归档。

| 图 | 文件 | 论证目的 |
|---|---|---|
| 图1 | 图1_模型对比.png | 相同划分下比较解释度、绝对误差和重复波动，保留其他方法更好的情况 |
| 图2 | 图2_逐目标预测性能.png | 完整呈现50个目标的R²和Spearman差异 |
| 图3 | 图3_OOF观测预测.png | 固定酸度、4VG、陈旧酒花味，检查幅度收缩和预测偏差 |
| 图4 | 图4_风格与难目标稳健性.png | 联合报告22种风格和10个预登记难目标，明确显示局部退化 |
| 附图S1 | 附图S1_残差诊断与量表映射.png | 检查残差并说明0—6相对等级的训练折映射 |

图片不嵌整图图题。图例在图外下方；图4空心点为ExtraTrees基线，最终模型为按MAE着色的实心点，颜色由蓝低到红高。风格名括号表示样本量，总体MAE写在横轴标题，不遮挡数据。

原数据表由`03_结果/Q1_感官评分/publication_final/`提供；图清单见`final_v4/Q1_图清单.csv`。独立程序和图表源数据随论文交付包提供。
