# 04 图表

最终论文图统一由 R/ggplot2 生成，调用 `source("scripts/plot_style.R")` 与 `theme_mcup()`。图名采用 `fig_q<问号>_<主题>_<序号>.png`，300 dpi；每张图有来源 CSV、图注和正文引用位置。

## 强制排版规则

1. **图片内不写整图标题或“图 N”**。图号和图题只在论文排版时放在图下方，避免与 DOCX 图注重复。
2. 多面板图可使用加粗 `(a)(b)` 标识或简短分面标签，但禁止灰色底框和装饰性标题条。
3. 每问正文默认 3—4 张主图，无充分理由不超过 5 张；诊断图和补充分析移入附图。
4. 主图优先 3:2 或接近 16:9 的横版。高纵比图必须与另一张纵图组合，不得单独占用大幅页面。
5. 图例不得遮挡数据；主方法、主要差异或结论用颜色、粗线、点大小或加粗数值之一突出，避免全图无视觉重点。
6. 改图时将旧版移入当问目录下的 `archive_vN/`，不覆盖丢失历史图稿。
