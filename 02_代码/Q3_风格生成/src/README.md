- `audit_e205b_sensory_search.py`：候选锁必须先入Git，再执行一次不同模型族审计；完成后只校验产物，不再次评价后改选。
- `verify_e205b.py`：不重训模型，重新核对99个固定选择规则与87条谱的重构、全部哈希和拒绝状态。
