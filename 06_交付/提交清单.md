# 2026 提交清单（MCB2601605）

> 规范：2026 年 MathorCup 大数据竞赛论文格式及提交规范（2026-10 修订）
> 文件名：`A2601605.pdf` / `A2601605承诺书` / `A2601605附件.rar|zip`（题号按实际赛道）

## A. 论文结构

- [ ] 第 1 页：题目 + 摘要 + 关键词
- [ ] 第 2 页：目录
- [ ] 正文从目录后开始，页码从 1 连续、页脚居中
- [ ] 正文 ≤30 页；附录页数不限
- [ ] 无页眉；无学校/姓名/队号/指导教师等身份信息（含 PDF 元数据）
- [ ] 中文写作；字体可读、页面美观（字体字号不强制）

## B. 内容

- [ ] 摘要四段（背景+总述 / 问题一 / 问题二 / 问题三），每段含具体数字
- [ ] 摘要数字 = 正文表/图 = 结果文件
- [ ] 每问：任务本质 → 难点 → 模型 → 求解 → 结果与分析
- [ ] 模型评估：准确性 + 至少一项（鲁棒性/效率/泛化/消融）
- [ ] 图表编号连续、正文引用；图题在下、表题在上
- [ ] 参考文献 15–30 篇；正文方括号编号与列表双向对应；书籍标页码
- [ ] 附录含软件名称、命令、全部源程序

## C. 交付文件

- [ ] `01_论文/A2601605.pdf`（或 B2601605.pdf）
- [ ] `02_结果文件/`：按赛题要求的 CSV/TXT，字段/顺序/坐标正确
- [ ] `03_承诺书/A2601605承诺书.pdf|jpg`：每位队员签名，赛道与队号填写正确
- [ ] `04_支撑材料/A2601605附件.rar|zip`（可选）：代码+结果，不含原始数据与身份信息
- [ ] 支撑材料清单与压缩包内容一致


- [ ] 校验无错误；仅有可解释的警告

- [ ] 文件名、赛道、队号三者一致
