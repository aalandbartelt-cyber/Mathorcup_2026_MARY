# AI 工具使用详情说明（目录说明）

> 规定要求：使用 AI 的参赛作品必须在支撑材料中提供 **`AI工具使用详情说明.pdf`**（中文名，原样）。

## 怎么做

1. 复制 `AI工具使用详情说明_模板.md`（或直接编辑 `AI工具使用详情说明_模板.docx`）。
2. 填四部分：工具清单、应用环节、关键交互记录、采纳与人工修改。
3. 导出 PDF，命名为 **`AI工具使用详情说明.pdf`**，放在本目录。
4. 打包支撑材料时，把它放进压缩包根目录或 `AI说明/` 子目录（与论文声明一致）。
5. 论文参考文献后加“AI 工具使用声明”，参考文献列出 AI 工具条目。

## 注意

- 工具名称/版本/机构/日期要真实；日期用实际使用日。
- 关键交互记录只放“重要提示词与回复摘要”，不必全文粘贴。
- 采纳内容要写清“哪些用了、怎么验证、人工改了什么”。
- 不要写“AI 独立完成核心建模”——规定要求核心建模由队员独立完成。
