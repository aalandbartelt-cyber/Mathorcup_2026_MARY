## 流程

1. 论文从 `00_官方模板与规范/论文模板.docx` 起稿；正文 ≤30 页，第 1 页摘要、第 2 页目录。
2. 结果文件放入 `02_结果文件/`，先跑 `scripts/check_result.py`。
3. 承诺书每人签名后放 `03_承诺书/`。
4. 支撑材料打包放 `04_支撑材料/`（压缩包内不含数据原始集与身份信息）。
5. 用 `scripts/prepare_submission.py` 统一改名/归档：

```bash
python scripts/prepare_submission.py --root . --team MCB2601605 --track A \
  --paper path/to/论文.pdf --result path/to/test_result.csv \
  --promise path/to/承诺书.pdf --support path/to/附件.zip
```

6. 跑 `scripts/audit_mcup_submission.py`，再按 `提交清单.md` 逐项检查。
7. 登录赛氪 `https://www.saikr.com/vse/bigdata2026` → 报名管理 → 电子档 → 提交/更新；状态显示“电子档已提交”才算成功。
