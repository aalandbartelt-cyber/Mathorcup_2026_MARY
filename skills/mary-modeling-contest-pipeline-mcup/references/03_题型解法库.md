# 03 题型解法库

> 按题型给“基线 → 改进 → 评估 → 论文写法”。所有做法来自 40 篇优秀论文与 2025/2026 真题，可直接套。

## 3.1 图像分类（问题 1 常见）

**基线**：ResNet18/50 或 EfficientNet-B0 迁移学习；冻结骨干 5 epoch → 解冻微调。
**改进**（按性价比排序）：
1. 数据增强：水平翻转、±10–15° 旋转、颜色抖动 0.2、随机擦除（医学图像不做垂直翻转）。
2. 处理不平衡：加权交叉熵 / Focal Loss / 重采样。
3. 注意力：CBAM / Coordinate Attention（放在骨干末端或 Bottleneck）。
4. 多尺度：FPN 融合（小目标、细裂纹）。
5. 轻量化：MobileNetV3 / 深度可分离卷积（部署叙事）。

**必做对比**：3–4 个骨干同协议比较；增强前后；有无注意力。
**指标**：Acc、Precision、Recall、F1、AUC、混淆矩阵（计数+归一化）。
**论文写法**：任务本质（二分类）→ 数据难点（不平衡/背景/小目标）→ 模型结构图 → 训练配置 → 混淆矩阵与分类报告 → 选型理由。
**真实参照**：2023-2 DenseNet-121 99.34%/AUC 0.98；2025-3 ResNet50+FPN+CA 96.84%/F1 97.77%；2025-1 CABNet 98.0%。

**无负样本的解法**（2025 A 关键）：
- 用标注框白色遮挡生成“无残损”图（2025-1），1:1 平衡；
- 从有缺陷图裁无缺陷区域（2025-3：排除 bbox 与边缘 50px，尺寸≥224×224，步长 112）。

## 3.2 目标检测与分割（问题 2 常见）

**基线**：YOLOv8n/s 或 YOLOv11n/s，COCO 预训练迁移。
**改进**：
1. 多尺度：FPN+PAN；小目标加 P2 层或提高输入分辨率（640→1024）。
2. 注意力：CBAM / 增强 CA。
3. 损失：CIoU；分割加 Dice / Dice-CIoU。
4. 分割头：YOLO-seg 或检测+U-Net 双任务（共享骨干）。
5. 类别不平衡：Focal Loss、类别权重、过采样少样本类。

**训练**：AdamW + 余弦；batch 16–32（12GB）；300 epoch 或早停；Mosaic/MixUp/HSV/旋转。
**指标**：mAP@0.5、mAP@0.5:0.95、各类 AP、P-R 曲线、混淆矩阵；分割加 Dice/IoU。
**额外可信度**：独立 IoU 匹配脚本（2025-1 平均 IoU 0.863）。
**论文写法**：检测任务定义 → 多尺度/小目标/类别混淆三条难点 → 结构改进图 → 消融表（基线/+模块A/+模块B）→ 各类 AP 与失败案例分析。
**真实参照**：2025-1 mAP@0.5=0.809；2025-3 摘要 90.1%（但其表 5 为 46.3%，**引文需核对**）；2025-4 mAP@0.5=86.3%。

## 3.3 表格回归

**基线**：Ridge / 随机森林；主模型 XGBoost / LightGBM / CatBoost。
**特征工程**：缺失（KNN/中位数/众数/模型）、编码（One-Hot 低基数、Target 折内、Label）、对数变换（长尾目标）、交叉/比值/频数特征、日期特征。
**调参**：网格/随机搜索 + 5 折 CV；贝叶斯优化（Optuna/HEBO）。
**融合**：Stacking（基模型 → 元模型），按验证集加权。
**解释**：特征重要性 + SHAP；与业务逻辑对照。
**指标**：R²、RMSE、MAE、MAPE；长尾目标在 log 空间评估后再还原。
**论文写法**：数据与目标分布 → 清洗与特征工程（每步有数字）→ 多模型对比表 → 融合/调参 → 特征重要性解释 → 误差分析。

## 3.4 表格分类与不平衡

**基线**：Logistic / 随机森林；主模型 XGB/LGB。
**不平衡**：类权重、SMOTE/SMOTEABAG、欠采样、代价敏感、Focal；比较 2–3 种策略。
**指标**：Acc、Macro-F1、少数类 Recall、AUC、Cohen's Kappa；业务约束满足率（如“严重超额≤3%”）。
**论文写法**：先给业务约束 → 标注规则 → 分类模型 → 不平衡策略对比 → 混淆矩阵与少数类分析。

## 3.5 时间序列

**基线**：ARIMA/SARIMA（ADF 检验、AIC 定阶）、指数平滑（Holt-Winters）、Prophet。
**改进**：XGBoost/LightGBM（滞后/滚动/日历特征）、LSTM/GRU；按 1-WMAPE 加权集成；节日/促销因子修正。
**分层**：按品类/仓库/区域聚类后分群预测，再汇总（自顶向下/自底向上）。
**指标**：MAPE、1-WMAPE、RMSE、RMSSE；同时报“完整期/评价期”。
**论文写法**：序列分解图 → 异常/节日处理 → 单模型 vs 集成 → 预测对比图 → 误差分布。

## 3.6 运筹优化

**建模**：决策变量（0-1/整数/连续）、目标（成本/收益/利用率）、硬约束（必须满足）与软约束（惩罚项）。
**求解**：PuLP+CBC、LINGO、OR-Tools、Gurobi（若有 license）；贪心/模拟退火/PSO/NSGA-III 用于大规模或多目标。
**验证**：约束逐条回算、目标值复算、与基线策略对比、Gap/收敛曲线。
**论文写法**：业务抽象 → 变量/约束/目标公式 → 求解流程 → 方案表与轨迹/分布图 → 灵敏度（需求±5%、容量±5%）。
**真实参照**：2022 A 派单 α=0.78/β=0.025/γ=0.195，6 位小数；2024 分仓 NSGA-III/SA/PSO。

## 3.7 无监督/风险标注

**规则法**：按业务金额分位数分层 → 档内差额分位 → 阈值（线性/幂函数拟合，R² 选优）。
**学习法**：孤立森林 + One-Class SVM 构造边界；或 KMeans 聚类 + 业务约束。
**约束**：合理诉求≥85%、严重超额≤3%（2025 B 官方约束）；输出比例与密集度验证。
**论文写法**：为什么无标签 → 规则/边界设计 → 约束满足 → 与人工规则对比 → 下游任务增益。

## 3.8 题型混合

- 先做“单模型能跑通”的最小闭环，再做“多模型对比”，最后做“融合/改进”。
- 每加一个模块，必须有**单独的消融行**；没有增益就撤掉，不要为了“看起来复杂”保留。
- 论文中的每个方法都要能回答：“它解决了哪条难点？没有它会怎样？”
