## 7.2 结果文件格式

**分类**：`image_id,prediction,probability`
- probability 写**正类概率**（如 P(COVID)），不是 max softmax；
- 每张测试图一行；image_id 用完整文件名。

**检测**：`image_id,class_id,x_center,y_center,width,height`
- 坐标为 **0–1 归一化**；中心点+宽高（YOLO 格式）；
- 无检测的图是否要留空行，按赛题说明。

**分配/优化**：`id,serviceStartTime,auntId`（无表头）
**分批决策**：`currentTime,id,serviceStartTime,auntId,retainable`（压单：-1/-1/1）

模板在 `assets/result_templates/`。

## 7.4 PDF 元数据清理

```python
import pymupdf as fitz
d = fitz.open("论文.pdf")
d.set_metadata({"author": "", "creator": "", "producer": "", "title": "",
                "subject": "", "keywords": ""})
d.xref_set_key(d.pdf_catalog(), "Metadata", "null")
d.save("论文_clean.pdf", garbage=4, deflate=True, clean=True)
```

正文没写身份、属性里带邮箱，同样违规。

## 7.6 四条“可能取消资格”红线

1. 赛道与内容不符；
2. 程序不能运行 / 结果与论文不符；
3. 出现身份信息（含 PDF 元数据、代码路径）；
4. 不符合论文格式规范（页数、首页、匿名）。

最后 3 小时只查这四条，不再改内容。

## 7.7 官方六大答卷问题（提交前再读一遍）

> 数据预处理没有章法；问题理解不明确；模型条件约简不符合实际；只注重展示方法，不注重问题解决；结论不验证实际、不讨论；程序跑不通。

逐条对应到论文与代码，任何一条成立都可能扣分。完整清单见 `assets/checklists.md`。
