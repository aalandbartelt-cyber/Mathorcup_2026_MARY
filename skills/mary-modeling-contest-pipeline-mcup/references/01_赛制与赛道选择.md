# 01 赛制与赛道选择

## 1.1 赛事结构（2025 实测 + 2026 官方口径）

- 形式：MathorCup 大数据竞赛，分 **赛道 A（视觉）** 与 **赛道 B（表格/业务）**，两个赛道独立评奖；含初赛、复赛与答辩。
- 提交：论文 PDF + 结果文件 + 承诺书；支撑材料可选。
- 时间：2026 第七届预计 **2026-10-23 18:00** 开赛（官网 saikr.com/vse/bigdata2026，以当届通知为准）。
- 2025 赛道 A：初赛三类残损（dent/hole/rusty）分类+检测/分割+评估；复赛升级为 **7 类残损**，并要求按官方 `ImageSets` 划分训练/验证。
- 2025 赛道 B：物流理赔风险——Q1 按业务规则划分风险等级，Q2 预测赔付金额（服务上限 300 单），复赛加入不平衡处理。
- 2026 官方练习：练习1 TMDb 观影（表格 EDA + 多目标回归）；练习2 COVID CT（图像二分类 + 577 张批量预测）。

## 1.2 A/B 赛道怎么选

| 维度 | 赛道 A（视觉） | 赛道 B（表格/业务） |
|---|---|---|
| 数据 | 图像/视频，非结构化 | CSV/Excel/JSON，结构化 |
| 技术栈 | PyTorch/ultralytics、OpenCV、迁移学习 | pandas/sklearn/XGB/LGB、统计检验、优化 |
| 算力 | 需要 GPU（本地 5070 Ti 或 A100） | CPU 可跑，GPU 加速有限 |
| 主要难点 | 小目标、类别不平衡、复杂背景、数据增强 | 缺失/异常、特征工程、业务约束、不平衡 |
| 论文写法 | 模型结构图 + 训练曲线 + 检测/分割结果 | 因素量化 + 模型对比 + 业务解释 |
| 风险 | 训练不收敛、显存不足、数据泄漏 | 口径错、约束漏、过拟合 |

**决策树**：
1. 数据是否以图像为主？是 → A；否 → 2。
2. 是否有 GPU 且团队会深度学习？是 → A 也可；否 → B。
3. 题目是否要求“因素分析 + 预测 + 建议”？是 → B。
4. 两条都能做时，选**能做出可验证结果**、且团队已有代码模板的那条。

## 1.3 赛事参数模板（开赛 10 分钟填完）

见 `SKILL.md §0`。四个决定是否违规的参数必须从官方原文抄：赛道、正文页数、首页结构、匿名范围。

## 1.4 官方格式红线（2025 规范）

1. 赛道与内容不符 → **取消评奖资格**。
2. 第 1 页：题目、摘要、关键词；第 2 页：目录；正文从目录后开始，页脚居中阿拉伯数字从 1 编号。
3. **不能有页眉**；不能出现身份/学校信息；中文；**正文 ≤30 页**，附录不限页数。
4. 参考文献：正文方括号编号；书籍标页码；按引用顺序列；书/期刊/网页三种格式。
5. 附录必须提供软件名称、命令、全部源程序；源程序保存至获奖名单公布。
6. 提交 PDF 命名 `#****.pdf`；承诺书签名；支撑材料 `#****附件.rar`（可选）。
7. 结果文件按赛题要求（2025 A 为 `test_result.csv`，字段 `image_id,class_id,x_center,y_center,width,height`）。

## 1.5 时间轴

**标准 7 天（官方讲座口径）**
- 第 1–2 天：读题、数据探索、确定技术路线与指标
- 第 3–5 天：建模、实验、迭代（先基线再改进）
- 第 6–7 天：论文、代码整理、提交检查

**压缩 4 天**
- D1：读题 + 数据对账 + baseline；写问题分析与预处理
- D2：主力实验 + 对比/消融
- D3：评估 + 出图 + 结果文件
- D4：论文成稿 + 提交检查（上午写完摘要，下午只查格式）

## 1.6 选题后的第一件事

把题面拆成四块，写进 `选题结论.md`：

```
【已知】数据、字段、单位、约束
【要求】逐字抄每问的“请……”，标注输出格式
【隐含】题面没写但业务上必须的（如“每图最多取 4 个”“比例约束”）
【陷阱】泄漏、口径、类别不平衡、坐标归一化、划分方式
```

每问用一句话写“本题要求回答什么、输出什么、用什么指标”，后续所有实验都围绕这句话。
