# 05 出图规范（R / ggplot2 首选）

> 纪律：**Python 算，R 画；接口是 CSV，不是内存。** 风格依据：40 篇优秀论文 615 张图表实测。
> 主题与函数在 `assets/r_theme_mcup.R`，项目内通常放 `scripts/plot_style.R`。

## 5.1 全局风格（实测结论）

| 指标 | 结果 | 采用 |
|---|---|---|
| 白底占比 | 0.75–0.91 | 白底 |
| 宽高比 | 集中 1.5（3:2） | `figsize 6×4 in` |
| 配色 | Excel 15 篇、seaborn 9、matplotlib 8；17/40 篇黑白为主 | 四色循环 + 灰度可辨 |
| 网格/边框 | 多数无网格、黑细框 | 无网格、0.5pt 黑框 |
| 字体 | 中文宋体、英文/数字 Times | SimSun + Times 字形 |

## 5.2 主题与四类图

```r
source("scripts/plot_style.R")

# 通用图
p <- ggplot(df, aes(x, y)) + theme_mcup(legend = "br")   # br/tr/bl/none/right
save_paper(p, "figures/fig1.png")                        # 300 dpi

# 四类高频图
plot_confusion_matrix(cm, c("dent","hole","rusty"), file = "figures/cm.png")
plot_pr_curves(list(dent = list(recall=r, precision=p, ap=.804),
                    all  = list(recall=r, precision=p, ap=.810)),
               file = "figures/pr.png")
plot_corr_heatmap(cor_mat, file = "figures/corr.png")     # hot + 全格数值
plot_feature_importance(names, values, file = "figures/imp.png")
```

`theme_mcup(mode="paper"|"sans", base_size=10, legend="br"|"tr"|"bl"|"none"|"right", title_family=NULL)`：
- `legend="right"` 用于保留 colorbar（混淆矩阵/热力图）；
- `title_family="SimHei"` 仅在需要图标题用黑体时使用，正文/刻度仍宋体。

## 5.3 各图型的视觉惯例

| 图型 | 配色 | 线条/标记 | 图例/标注 |
|---|---|---|---|
| 训练曲线 | 四色（蓝橙绿红） | 0.7pt 实线，无标记 | 图内右下，无边框 |
| PR 曲线 | 类色细线 + 总曲线深蓝粗线 | 0.55 / 1.15pt | 图内左下，图例带 AP |
| 混淆矩阵 | Blues（原始）/ Reds（归一化） | 白格线分隔 | 每格数值；深色格白字 |
| 相关性热力图 | hot（负深正浅） | — | 全格 2 位小数；细 colorbar |
| 特征重要性 | 逐条冷暖色（红→蓝） | 横向降序 | 末端数值 |
| Grad-CAM | jet | — | 右侧 0.2–1.0 colorbar |
| 流程图 | PPT 浅蓝/浅绿填充 | 3D 箭头 | 虚线容器、竖排中文 |

## 5.5 图件质检

| # | 检查 | 不合格表现 |
|---|---|---|
| 1 | 中文无方块 | 出现 □□□ |
| 2 | 数字与英文为 Times 字形 | 与正文不一致 |
| 3 | 无网格、黑细框 | 灰网格/粗黑边 |
| 4 | 图例不压数据 | 压住曲线拐点 |
| 5 | 轴标题含单位 | 只有“准确率” |
| 6 | 缩到 70% 仍可读 | 需放大才看清 |
| 7 | 黑白打印可区分 | 两条曲线灰度相同 |
| 8 | 图能独立回答问题 | 看完不知道结论 |

## 5.6 反模式

- 混用第二个绘图后端（matplotlib + ggplot 拼在一篇里，风格会打架）；
- 图例带粗边框/底色（显脏）；
- 混淆矩阵旋转 45° 且类名短（可用水平）；
- hot 配色负值区全黑且不标数值（打印丢信息）；
- 3D/彩虹色（打印失真）；
- 中文与 `$...$` mathtext 混排（对方框字，改用 Unicode 上标）。

## 5.7 Python 保底

仅当 R 环境异常时：

```python
import sys; sys.path.insert(0, "scripts")
import plot_style as ps
ps.set_style("m杯")
ps.plot_confusion_matrix(cm, ["dent","hole","rusty"], save_path="figures/cm.png")
```

两版规范一致，但日常固定 R；不要把两套图混进同一篇论文。
