# 02 工程与数据契约

## 2.1 目录骨架

```
<赛季根>/
├── 00_赛题与规则/        题面 PDF、赛事参数.md、选题结论.md
├── 01_数据/              原始数据（只读）、划分文件、对账表.md
├── 02_代码/              scripts/（训练/推理/评估/绘图入口）
├── 03_结果/              result.csv / metrics.json / 实验记录
├── 04_图表/              figures/（300dpi PNG）
├── 05_论文/              论文.tex 或 .docx、figures 副本、参考文献
├── 06_交付/              论文.pdf、结果文件、支撑材料.zip（只进不出）
├── docs/collab/          AI 协作信箱（见 08）
└── _archive/             旧方案、zip 快照、实验废弃版本
```

一键建骨架：`python scripts/new_mcup_project.py --root <赛季根> --track A`。

## 2.2 命名契约

| 对象 | 规则 | 示例 |
|---|---|---|
| 结果文件 | 按赛题原名，只留一份最终版 | `03_结果/result_detection.csv` |
| 实验 ID | `E001` 递增 | `E007` |
| 图 | `fig_<主题>_<序号>.png` | `fig_confusion_01.png` |
| 模型权重 | `<模型>_<数据>_<日期>.pt` | `yolov8s_ct_20261024.pt` |
| 提交物 | `#****.pdf`、`#****附件.rar` | `A2500001.pdf` |

同名多版本是事故源：旧版本一律进 `_archive/`，结果目录只留最终版。

## 2.3 数据对账表（开赛 2 小时内完成）

```markdown

| 缺失率 |  |  |  |
| 划分方式 |  |  |  |
| 泄漏风险 |  |  |  |
```

**CV 必查**：
- 格式（png/jpg）、颜色模式（RGB/RGBA/L）→ 统一 `convert("RGB")`
- 尺寸分布 → 统一 resize；极端长宽比是否裁剪
- 文件名特殊字符（`%0/%1`、空格）→ 用 pathlib，CSV 保留原名
- 同源多帧（同前缀/同患者/同视频）→ **按前缀分组划分**，防泄漏

**表格必查**：
- 缺失率与成因（随机/业务相关）；零值是否代表“未知”
- 目标分布（长尾 → log1p；类别不平衡 → 权重/重采样）
- 训练集与预测集字段是否一致；类别编码映射
- 时间字段的时区/单位；金额单位与精度

## 2.4 数据划分

| 场景 | 做法 |
|---|---|
| 普通分类/回归 | 分层 8:2 或 5 折交叉验证 |
| 图像同源多帧 | GroupShuffleSplit，按文件名前缀分组 |
| 时序 | 按时间切分（禁止随机打乱） |
| 官方给定 ImageSets | **严格按官方文件**，不要自行重划（2025 复赛 A 要求） |

## 2.5 结果文件模板

见 `assets/result_templates/`：

- `result_classification.csv`：`image_id,prediction,probability`（probability 写正类概率）
- `result_detection.csv`：`image_id,class_id,x_center,y_center,width,height`（归一化 0–1）
- `result_assignment.txt`：`id,serviceStartTime,auntId`（无表头，2022 A 格式）
- `result_assignment_batch.txt`：`currentTime,id,serviceStartTime,auntId,retainable`（压单：-1/-1/1）

## 2.6 Git 与资产

- 代码/文档/模板入库；数据、权重、参考材料不入库（`.gitignore`）。
- 提交信息：`feat: ...` / `fix: ...` / `collab(MSG-ID): ...`。
- 每次实验后记录：配置、指标、产物路径（`docs/experiment_log.md`）。
- 环境快照：`Rscript scripts/session_info.R` → `docs/env_r.txt`；`pip freeze > docs/env_py.txt`。

## 2.7 常见数据事故

| 事故 | 症状 | 处理 |
|---|---|---|
| 训练/验证同源 | 验证指标异常高，测试崩 | 按前缀分组重划 |
| 坐标像素/归一化混用 | 检测框全错、校验报错 | 统一 0–1；用校验脚本 |
| 零值当真实值 | ROI/增长率爆炸 | 视为缺失，剔除或插值 |
| 类别编码错位 | 预测类别整体偏移 | 固定映射表，写入 README |
| 测试集多/少文件 | 提交行数不对 | 与目录文件名集合双向核对 |
