# 04 实验与评估

## 4.1 评估六维（问题 3 直接套）

| 维度 | 内容 | 指标/做法 |
|---|---|---|
| 准确性 | 模型预测对不对 | 分类 Acc/P/R/F1；检测 mAP@0.5/0.95、各类 AP；分割 Dice/IoU；回归 R²/RMSE/MAE/MAPE |
| 鲁棒性 | 扰动下是否稳定 | 高斯噪声、亮度±30%、遮挡、雨污渍；报告指标保持率 |
| 效率 | 能否部署 | 单图耗时、FPS、参数量、FLOPs |
| 泛化性 | 换数据是否可用 | 新样本/跨划分验证；随机划分 vs 分组划分对比 |
| 可解释性 | 为什么这样判 | 特征重要性、SHAP、Grad-CAM、雷达图 |
| 模块有效性 | 改进是否有用 | 消融实验（基线 / +A / +A+B） |

## 4.2 指标选择（别用错）

| 题型 | 主指标 | 辅助 | 不要只报 |
|---|---|---|---|
| 二分类（不平衡） | F1、Recall、AUC | Acc、混淆矩阵 | Acc（会被多数类掩盖） |
| 多分类 | Macro-F1、各类 P/R | 混淆矩阵、Kappa | 总体 Acc |
| 检测 | mAP@0.5、mAP@0.5:0.95 | 各类 AP、P-R 曲线、IoU | 检测框数量 |
| 分割 | Dice、mIoU | 像素准确率 | 仅像素准确率 |
| 回归 | R²、RMSE | MAE、MAPE、残差图 | 仅 R² |
| 时序 | MAPE、1-WMAPE | RMSE、预测对比图 | 仅 RMSE |
| 优化 | 目标值、约束满足 | Gap、收敛曲线、方案对比 | 仅“更优” |

## 4.4 对比实验

- 同任务 3–4 个模型，**同一划分、同一增强、同一轮数**；
- 给出选型理由（精度/速度/资源权衡），不只写“最好”；
- 记录参数量与推理时间，支撑“效率”维度。

## 4.6 误差分析与失败案例

- 混淆矩阵指出易混类别及原因（光照、纹理相似、小目标）；
- 给出 2–3 个误检/漏检样例图，说明边界、遮挡、尺度因素；
- 提出针对性改进方向（与“研究展望”呼应）。
- 官方六大问题之一是“结论不验证实际、不讨论”——每问结果后必须有一段“合理性/局限”。

## 4.7 数字一致性（提交前必做）

1. 摘要每个数字 → 正文对应表/图 → 结果文件，三方一致；
2. 同一指标全篇同一口径（是否含背景类、是否加权、IoU 阈值）；
3. 百分比与小数不混用；单位统一；
4. 若发现原文/前稿数字矛盾，**以自己最新结果为准并统一替换**。

**真实反例**：某优秀论文摘要 mAP 90.1%，其表 5 为 46.3%；另一篇融合模型 0.9664 低于单模型 0.9694 却称最优——引用时必须核对。

## 4.8 评估章节写作模板

```
N.1 评估设计：维度、数据、指标、对比对象
N.2 准确性：主表 + 混淆矩阵/PR + 文字解读（现象、数字、原因）
N.3 鲁棒性：扰动设置 + 保持率 + 结论
N.4 效率：参数量、单图耗时、FPS
N.5 消融/对比：表格 + 增量说明
N.6 局限：失败案例、数据限制、未来改进
```
