# 06 论文写作与摘要

## 6.1 官方结构（硬约束）

| 页 | 内容 |
|---|---|
| 第 1 页 | 题目 + 摘要 + 关键词 |
| 第 2 页 | 目录 |
| 正文 | 从目录后开始，页脚居中阿拉伯数字从 1；**≤30 页** |
| 参考文献 | 正文之后，单独起页 |
| 附录 | 页数不限；软件名称、命令、**全部源程序** |

不允许：页眉、身份/学校信息、英文正文（除非赛题要求）。

## 6.2 正文骨架

```
一、问题重述        1.1 背景  1.2 目标任务（逐字抄题面要求）
二、问题分析        2.1/2.2/2.3 针对问题一/二/三：任务本质→难点→对策
三、模型假设        3–6 条，围绕数据质量与场景
四、符号说明        表格式，10–20 行
五、数据预处理      数据概览→缺失/异常→编码/特征→增强→划分
六、问题一模型的建立与求解
七、问题二模型的建立与求解
八、问题三模型的建立与求解
九、模型评估        六维/消融/对比/误差分析
十、模型评价与推广  优点 3–4、缺点 2–3、推广 2–3
参考文献
附录
```

每问内部固定五段：**任务本质 → 难点 → 模型建立 → 求解 → 结果与分析**。

## 6.3 摘要四段式（最重要）

```
第1段：背景 1–2 句 + 本文总体方案 1 句
第2段：针对问题一，方法 + 关键设置 + 指标数字
第3段：针对问题二，方法 + 关键设置 + 指标数字
第4段：针对问题三，评估/系统/策略 + 关键结论数字
关键词：技术领域；具体模型；应用对象（3–8 个，分号分隔）
```

**要求**：
- 每问一段，每段至少 2 个具体数字；
- 数字必须与正文表格一致；
- 不写“效果良好”，写“mAP@0.5=0.809、F1=0.728”；
- 不出现图号/表号/参考文献；
- 题面点名的每条结论都要在摘要出现。

**真实示例**（2025-1）：
> 针对问题二，提出了改进型 YOLOv11 集装箱缺陷检测模型……最终模型取得 Precision=0.817、Recall=0.750、mAP@0.5=0.809、mAP@0.5:0.95=0.628……平均 IoU=0.863。

## 6.4 每问写作模板

```
N.1 问题分析
  本题要求……（一句话任务）
  难点有三：其一……其二……其三……
  针对上述难点，本文采用……
N.2 模型建立
  结构/公式/符号，只讲方法，不放结果
N.3 模型求解
  数据、参数、训练配置、评价指标
N.4 结果与分析
  表格/图 + “现象+数字+原因”三段式
N.5 验证（可选）
  对照实验/误差分析/业务解释
```

## 6.5 图表与公式

- 图题在图下、表题在表上；编号连续；正文必须引用（“如图 X 所示”）。
- 表：三线表，无竖线；数值 2–4 位小数；消融表行=模型、列=指标。
- 公式：每个符号首次出现处定义；编号连续；不要“公式堆砌无解释”。
- 图表突出结论与比较，不堆无关信息。

## 6.6 参考文献

- 15–30 篇，与方法链对应；正文方括号编号；
- 书籍标页码；期刊标卷期页码；网页标访问日期；
- 正文引用与列表双向对应，无僵尸文献。

## 6.7 30 页预算

| 部分 | 建议页数 |
|---|---|
| 首页摘要 | 1 |
| 目录 | 1 |
| 问题重述+分析 | 3–4 |
| 假设+符号 | 1–2 |
| 数据预处理 | 3–4 |
| 每问模型（3 问） | 各 3–5 |
| 模型评估 | 3–4 |
| 评价与推广 | 1–2 |
| 参考文献 | 1–2 |
| 合计（正文） | ≤30 |

页数超限时：先压图高（6×4 → 6×3.2），再合并重复表，最后才删内容。

## 6.8 常见写作问题（官方六大问题对应）

1. 预处理没章法 → 写成“步骤表+每步行数变化”；
2. 问题理解不明确 → 每问开头写“本题要求回答……”；
3. 约简不符合实际 → 假设后写“放宽会怎样”；
4. 只展示方法 → 每个模型对应一条难点；
5. 结论不验证 → 每问结果后有“合理性/局限”；
6. 程序跑不通 → 附录代码与仓库一致，README 可复现。
