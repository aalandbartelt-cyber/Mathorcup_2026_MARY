# 检查清单（MathorCup 大数据竞赛）

## A. 官方六大答卷问题（提交前逐条）

| # | 官方问题 | 自查（打勾） | 验证方式 |
|---|---|---|---|
| 1 | 数据预处理没有章法，不按需求处理 | 清洗步骤表（每步行数变化+理由） | 论文预处理节 5–8 步且有数字 |
| 2 | 问题理解不明确 | 每问写明边界、输出格式、自定假设 | 问题分析每问一段“本题要求回答……” |
| 3 | 模型条件约简不符合实际 | 假设可辩护，简化说明代价 | 每条假设后写“若放宽会怎样” |
| 4 | 只注重展示方法 | 方法与难点一一对应 | 每个模型能回答“解决哪条难点” |
| 5 | 结论不验证实际、不讨论 | 误差分析/失败案例/业务解释 | 每问结果后一段“合理性/局限” |
| 6 | 程序跑不通 | 干净环境可复现，输出与论文一致 | 提交前重跑全流程 |

## B. 提交前 20 项

- [ ] 赛道与内容一致
- [ ] 第 1 页摘要+关键词；第 2 页目录；正文页码从 1
- [ ] 正文 ≤30 页；无页眉；无身份信息
- [ ] 摘要数字与正文/表格一致
- [ ] 每问有方法+结果+验证
- [ ] 图表编号连续、正文引用、图题在下表题在上
- [ ] 消融/对比至少一组
- [ ] 参考文献 15–30 篇、双向对应
- [ ] 附录含软件名、命令、全部源码
- [ ] 代码在干净环境按 README 跑通
- [ ] 结果文件字段/顺序/坐标格式正确
- [ ] 结果行数与测试集文件集合一致
- [ ] 类别 id 映射正确
- [ ] 无重复/缺失预测（按赛题要求）
- [ ] PDF 元数据已清空
- [ ] 承诺书已签名
- [ ] 支撑材料与附录清单一致
- [ ] 文件名符合 `#****.pdf`
- [ ] 提交系统已选对赛道并上传
- [ ] 本地完整备份

## C. 图表 QA

- [ ] 中文无方块
- [ ] 数字/英文 Times 字形
- [ ] 无网格、黑细框
- [ ] 图例不压数据
- [ ] 轴标题含单位
- [ ] 缩到 70% 仍可读
- [ ] 黑白打印可区分
- [ ] 图能独立回答问题

## D. 数据对账

- [ ] 文件数与题面一致（差异已记录）
- [ ] 图像模式统一 RGB；尺寸已 resize
- [ ] 同源多帧按前缀分组，未跨训练/验证
- [ ] 表格缺失/零值/异常已处理并记录
- [ ] 训练集与预测集字段一致
- [ ] 坐标/单位/类别映射已固定并写入 README
